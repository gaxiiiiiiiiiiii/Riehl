2.2 補足 — 米田の補題を別の例で見る

§2.2 の解説（S2_2_Yoneda.html）にある例2.2.1（ω 上の図式）・例2.2.2（BG 上の図式）を補うために書いた、本書にない例。番号は本と揃わないので A・B・C と呼ぶ。定理2.2.4（米田の補題）と系2.2.8（米田埋め込みの充満忠実性）の主張はそのまま使う。

見たいことは二つ

定理2.2.4 の内容は、写像

evid : Hom(C(c,−), F) → F(c),　α ↦ αc(idc)

が全単射だ、という一文に尽きる。全単射であることは二つの主張に分かれる。

  • (i) 単射性（決まってしまう） — α は値 αc(idc) ∈ F(c) ひとつで完全に決まる。他の成分 αx は自然性から強制される
  • (ii) 全射性（自由に選べる） — 逆に F(c) のどの要素を選んでも、それを実現する α が存在する。自然性はそれ以上の制約を課さない

例2.2.1 と例2.2.2 は、この二つを具体的な圏で確かめたものだった。以下の三つも役割は同じで、確かめる舞台だけが違う。どれも定理2.2.4 を先に認めてしまわず、手で (i) と (ii) を出してから米田の補題と突き合わせる形で書く。

例A — C = Set、c = 1（自然変換を数え上げる）

舞台を Set に取り、表現対象を一点集合 1 = {∗} にする。全単射 Set(1,X) ≅ X（f ↦ f(∗)）は X について自然だから、1 が表現する関手は恒等関手 Id そのものと思ってよい。

行き先の関手として共変べき集合関手 P を取る。問いはこうなる: 自然変換 α : Id ⇒ P は何個あるか。言い換えれば、集合 X の要素 x に部分集合 αX(x) ⊆ X を、X について自然な仕方で割り当てる方法は何通りあるか。

米田の補題に頼らず手で解く。自然性の四角形を、射 f : 1 → X について書く。

Set(1,f) は「f を後から合成する」操作だから、左上の唯一の元 id1 を右上の f に送る。したがって id1 を右下まで二通りに追うと

αX(f) = P(f)(α1(id1))

を得る。つまり α は A := α1(id1) ⊆ 1 ひとつで完全に決まる——これが (i) である。Set(1,X) ≅ X の下で f を要素 x ∈ X と読み替えれば、αX(x) = x̂[A]。A の候補は ∅ と {∗} の二つしかないので、答えは二つしかありえない:

  • A = ∅ のとき αX(x) = ∅（どの要素にも空集合を割り当てる）
  • A = {∗} のとき αX(x) = {x}（要素を、それだけからなる部分集合に送る）

そして両方とも実際に自然である。確かめるべきは P(h)(∅) = ∅ と P(h)({x}) = {h(x)} で、どちらも成り立つ。これが (ii)、A としてどちらを選んでも本当に自然変換になる、ということである。米田の補題が予告するとおり、答えの個数は P(1) の要素数 2 に一致した。

行き先を替えれば数も替わる。List(1) は長さだけが情報の列 [∗, …, ∗] 全体で、ℕ と同一視できる。よって自然変換 Id ⇒ List はちょうど可算個あり、n 番目は x ↦ [x, x, …, x]（n 個）である。F(1) が自然変換の全体をそのまま測っている。

この例の値打ちは、定理2.2.4 の証明の骨格——恒等射の行き先を追うと残りが全部決まる——が、「一点集合からの写像で要素を名指しする」という完全に見慣れた操作だけで見えることにある。例2.2.1 で帰納法が担っていた役割を、ここでは一本の四角形が担っている。

例B — C = Set、c = 2（自然な二項演算は射影しかない）

同じ Set で、表現対象を2元集合 2 = {0,1} に替える。全単射 Set(2,X) ≅ X × X（f ↦ (f(0), f(1))）は X について自然だから、2 が表現するのは対をとる関手 X ↦ X × X である。

定理2.2.4 は Hom(Set(2,−), F) ≅ F(2) を与える。F をいくつか入れてみる。

自然変換の型米田が与える集合個数中身
X × X ⇒ XId(2) = 22二つの射影 (x0,x1) ↦ x0、(x0,x1) ↦ x1
X × X ⇒ X × XSet(2,2)4(x0,x0)、(x0,x1)、(x1,x0)、(x1,x1)
X ⇒ X × XSet(2,1) = 11対角 x ↦ (x,x)

一行目の計算を追う。F = Id なら F(2) = 2 = {0,1} で、α は α2(id2) ∈ {0,1} で決まる。実際、射 h : 2 → X に沿う自然性から αX(h) = h(α2(id2)) となり、h ↔ (x0,x1) の読み替えの下で αX(x0,x1) = xi（i = α2(id2)）。i の選び方は二つで、どちらも自然。

これは「裸の集合には、二つの射影のほかに自然な二項演算が存在しない」と読める。掛け算も、和も、二つのうち条件で一方を選ぶような操作も、集合の圏では自然になりようがない。自然であるためには X の要素について何も知らないまま定義できねばならず、手元にあるのは受け取った x0 と x1 だけだからである。三行目も同様で、X から X × X への自然な操作は対角しかない。

二行目は系2.2.8 の実例になっている。系2.2.8 は Set(2,2) ≅ Hom(Set(2,−), Set(2,−)) を主張するので、四つの自然変換は写像 σ : 2 → 2 からの前合成

(x0, x1) ↦ (xσ(0), xσ(1))

として得られるものに尽きるはずである。実際 σ を四通り（0 に潰す、恒等、入れ替え、1 に潰す）書き下すと、表の四つと過不足なく一致する。表現対象の間の射と、表現された関手の間の自然変換とが、ここでは 4 個と 4 個の照合として目で確かめられる。

例C — 有向グラフ（表現対象は「形」）

添字圏 D を、対象 E, V と平行な二本の射 σ, τ : E → V（および恒等射）だけからなる圏とする。合成すべき対が恒等射がらみしかないので、これで確かに圏になっている。

関手 X : D → Set とは何か。集合 X(E)、X(V) と、写像 X(σ), X(τ) : X(E) → X(V) の指定である。X(V) を頂点の集合、X(E) を辺の集合、X(σ)・X(τ) を辺にその始点・終点を割り当てる写像と読めば、これは有向グラフにほかならない（多重辺と自己ループを許す）。そして自然変換 X ⇒ Y は、頂点と辺の対応であって始点・終点と両立するもの、つまりグラフの準同型である。

表現された関手 D(V,−) と D(E,−) を、この読み方でグラフとして描いてみる。

  • D(V,−): 頂点集合は D(V,V) = {idV}（1元）、辺集合は D(V,E) = ∅。頂点1つ、辺なしのグラフ
  • D(E,−): 頂点集合は D(E,V) = {σ, τ}（2元）、辺集合は D(E,E) = {idE}（1元）。構造写像は D(E,σ)(idE) = σ、D(E,τ)(idE) = τ だから、唯一の辺 idE は始点 σ・終点 τ を持つ。辺1本とその両端

定理2.2.4 をこの二つの表現対象に当てはめると

Hom(D(V,−), X) ≅ X(V),　Hom(D(E,−), X) ≅ X(E)

日本語にすれば、点グラフから X への準同型は X の頂点そのもの、辺グラフから X への準同型は X の辺そのものである。

ここで初めて「表現された関手は形であり、そこから出る自然変換はX の中に置かれたその形の図形である」という読みが出る。(i)（α は αc(idc) で決まる）は「図形の置き方は代表元の行き先だけで決まる」ということであり、(ii)（値は自由）は「X のどの辺も、辺グラフの置き方として実現される」ということである。米田埋め込みは、この読みでは「形を X に当てて探る」操作になる。

系2.2.8 もここで見える。Hom(D(V,−), D(E,−)) ≅ D(E,V) = {σ, τ} で2元。実際、点グラフを辺グラフに置く方法は「始点に置く」「終点に置く」の2通りしかない。D の射が σ, τ の2本であることと合っている（よ は反変なので、対応する射の向きは裏返る）。
