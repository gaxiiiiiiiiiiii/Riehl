2.2 米田の補題

Emily Riehl, Category Theory in Context §2.2（pp.59–66）の内容を、個人学習のために日本語で書き直した解説。番号（定理2.2.4 など）は本と揃えてある。翻訳ではなく、同じ内容を自分の言葉で再構成したもの。

Mac Lane の回想（和訳）——「米田はこの補題の由来をこう語るのを好んだ。1954〜55年頃、米田はフランスに滞在していた。パリを訪れていた Mac Lane は米田から学ぼうと、北駅（Gare du Nord）のカフェで面会を始め、話は米田の乗る列車が発車するまで続いた。そのなかで Mac Lane はこの補題を知り、のちに命名した」。補題が最初に活字になったのは Grothendieck の論文である。

この節の問い

2.1 では、関手 F : C → Set が対象 c に表現されるとは、自然同型 C(c,−) ≅ F が存在することだと定義した。例2.1.5・2.1.6 に挙がった多くの表現を本当に理解するには、この自然同型を定めるデータが何かを知る必要がある。

自然同型とは、自然変換であって各成分が同型であるものだった。そこで問いを一段ゆるめて、こう問う: 自然変換 α : C(c,−) ⇒ F を定めるデータは何か。これに答えられれば、あとは成分が同型かどうかを確かめるだけで表現の議論ができる。

この節はこの一つの問いに答える。答え（定理2.2.4）は、表現された関手 C(c,−) から出て行く自然変換の完全な分類である。C(c,−) に入って来る自然変換 β : F ⇒ C(c,−) には同種の分類がない。この非対称性については演習2.2.ii で考える。

例2.2.1 — ω 上の図式

一般論の前に、添字圏が単純な場合を手で解いてみる。まず ω。関手 F : ω → Set とは、集合の列 (Fn)n∈ω と写像 fn,n+1 : Fn → Fn+1 の列のことである（合成はつなげればよい）。

対象 k ∈ ω が表現する関手 ω(k,−) : ω → Set はどんな列か。hom 集合 ω(k,n) は「k ≤ n の証明」の集合だから、n < k のとき空集合、n ≥ k のとき一点集合である。つまり ω(k,−) は「最初の k 項が空で、それ以降はずっと一点」という列になる。

自然変換 α : ω(k,−) ⇒ F のデータは成分 αn : ω(k,n) → Fn の族で、これが自然性の条件を満たす。n < k では定義域が空なので αn は情報を持たない。n ≥ k では定義域が一点なので、αn は要素 αn ∈ Fn の指定と同じことである。

自然性の四角形は、隣り合う段について αn+1 = fn,n+1(αn) を要求する。したがって帰納法により、α 全体は最初の要素 αk ∈ Fk の選択ひとつで完全に、しかも一意に決まる。そしてこの αk は、成分 αk : ω(k,k) → Fk による恒等射 idk ∈ ω(k,k) の像にほかならない。さらに、αk としては Fk のどの要素を選んでもよい——自然性はそれ以上の制約を課さない。

例2.2.2 — BG 上の図式（G-集合）

次は正反対の形の圏、1対象圏 BG。共変関手 BG → Set は左 G-集合、反変関手 BGop → Set は右 G-集合に対応するのだった（例1.3.9）。BG の対象はひとつしかないから、共変の表現された関手もひとつしかない。それはどの G-集合か——唯一の対象の自己射集合が G 自身なので、左正則作用つきの G である（反変側は右正則作用つきの G）。

そこで G-集合 X : BG → Set への自然変換 φ : G ⇒ X を考える。例1.4.4(iv) で見たとおり、これはちょうど G-同変写像 φ : G → X のことである。φ は自然変換の唯一の成分で、同変性 φ(g·h) = g·φ(h) が自然性の条件そのものになっている。

φ を定めるには各 g に対する値 φ(g) を指定すればよいが、同変性で h = e（単位元）と置くと φ(g) = g·φ(e) が出る。つまり φ(e) ∈ X を選んだ時点で、φ の全体が強制される。しかも φ(e) はどの要素でもよい。これは G の自分自身への左作用が自由（どの点の固定部分群も自明）だからで、もし異なる k, h で k·e = h·e となり得たら、φ(g) の定義が衝突する恐れがあった。

この議論がそのまま次の命題の証明になる。

命題2.2.3. G-同変写像 G → X は、φ を φ(e) ∈ X に送る写像を介して、X の要素と全単射で対応する。

定理2.2.4 — 米田の補題

二つの例を見比べる。ω は poset で、射は「≤ の証明」しかなく自己同型を持たない。BG は逆に、圏の情報がすべて唯一の対象の自己射に載っている。これほど形の違う二つの添字圏で、答えは同じ形——自然変換は、表現対象での恒等射の像ひとつで完全に決まり、その値はどの要素でもよい——に着地した。これは偶然ではない。任意の形の図式で同じことが成り立つ、というのが圏論で最も重要な結果と言われる米田の補題である。

定理2.2.4（米田の補題）. 局所小な圏 C 上の関手 F : C → Set と対象 c ∈ C に対し、自然変換をその c 成分で恒等射において評価する写像

evid : Hom(C(c,−), F) → Fc, α ↦ αc(idc)

は全単射である。さらにこの対応は c と F の双方について自然である。

ひとつ規模の注意がある。C は局所小と仮定しただけで小さいとは限らないから、自然変換の集まり Hom(C(c,−), F) は先験的には集合をなすかどうか分からない。しかし全単射の存在が、この集まりが実際に（Fc と同じ大きさの）集合であることを保証する。

反変関手 F : Cop → Set に対する双対版の定式化は演習2.2.i に委ねられる。双対を取るのは一般の圏 C の側であって Set の側ではないことに注意する。したがって双対版もやはり「C(−,c) から出て行く自然変換」の分類になる（演習2.2.ii を参照）。

証明は二部に分かれる。まず全単射、次に自然性である。

全単射の証明. 逆写像 Ψ : Fc → Hom(C(c,−), F) を構成する。要素 x ∈ Fc から自然変換 Ψ(x) : C(c,−) ⇒ F を作りたい。そのためには各対象 d に対して成分 Ψ(x)d : C(c,d) → Fd を、すなわち各 f ∈ C(c,d) に対して値 Ψ(x)d(f) ∈ Fd を定めなければならない。

ここで鍵になるのは、f が単なる集合の要素ではなく射 f : c → d であることだ。まだ定義していない Ψ(x) の成分たちが自然であるためには、次の四角形が可換でなければならない:

恒等射 idc ∈ C(c,c) を左下回りで送ると Ψ(x)d(f)、右上回りで送ると Ff(Ψ(x)c(idc)) になる。一方、Ψ が evid の逆であるためには Ψ(x)c(idc) = x でなければならない。すると自然性が定義を強制する:

(2.2.5) Ψ(x)d(f) := Ff(x).

つまり成分の定義に選択の余地は一切なかった。残る仕事は、この強制された式が本当に自然変換を定めるかの確認である。一般の射 g : d → e（域が c とは限らない）について四角形

の可換性を見る。f ∈ C(c,d) を左下回りで送ると Ψ(x)e(gf) = F(gf)(x)、右上回りで送ると Fg(Ψ(x)d(f)) = Fg(Ff(x))。F の関手性 F(gf) = Fg∘Ff により両者は一致する。これで Ψ : Fc → Hom(C(c,−), F) が定義できた。

構成から evid(Ψ(x)) = Ψ(x)c(idc) = x、すなわち Ψ は evid の右逆である。左逆であること Ψ(evid(α)) = α を見るには、両辺の各成分が一致すること、すなわち任意の f ∈ C(c,d) について Ψ(αc(idc))d(f) = αd(f) を示せばよい。α 自身の自然性の四角形

で idc を追跡すると Ff(αc(idc)) = αd(f) を得る。定義(2.2.5)より左辺は Ψ(αc(idc))d(f) だから、示すべき等式が出た。よって Ψ は両側逆であり、evid は全単射である。□

自然性の証明. 「両変数に自然」の中身は次の二つの主張である。

関手方向。自然変換 β : F ⇒ G に対し、次が可換であること:

左下回りは α を縦合成 β·α にしてから idc で評価し、右上回りは先に評価してから βc を適用する。縦合成の定義（補題1.7.1）から (β·α)c(idc) = βc(αc(idc)) であり、これがちょうど両回りの一致である。

対象方向。射 f : c → d に対し、次が可換であること（前合成 f∗ : C(d,−) ⇒ C(c,−) との合成が誘導する写像を (f∗)∗ と書く）:

α ∈ Hom(C(c,−), F) の右上回りの像は Ff(αc(idc))。左下回りの像は (α·f∗)d(idd) で、縦合成の d 成分は合成写像 αd∘f∗d だから、idd ↦ idd·f = f ↦ αd(f) と計算できる。あとは先ほどの四角形(2.2.6)が αd(f) = Ff(αc(idc)) を与えるので、両回りは一致する。□

注意2.2.7 — 両変数の自然性を一枚の主張にする

定理の「c と F の双方に自然」を、文字どおり一つの自然同型として述べ直すことができる。まず C が小さい場合、関手圏 SetC は局所小になり（注意1.7.3）、定理2.2.4 の全単射

evid : SetC(C(c,−), F) ≅ evc(F)

は「対象 C(c,−) ∈ SetC が評価関手 evc : SetC → Set（F を Fc に送る関手）を表現する」と読める。ただしこの読み方が捉えるのは F 方向の自然性だけである。

両変数を同時に扱うには、対 (c, F) を積圏 C × SetC の対象と見て、そこからの二つの関手を比べる。一つは評価二関手 ev : C × SetC → Set、(c,F) ↦ Fc。もう一つは、埋め込み よ を（演習1.3.v により）関手 よ : C → (SetC)op と見なして hom 関手と合成した

Hom(よ(−),−) : C × SetC → SET, (c,F) ↦ Hom(C(c,−), F).

ここで行き先を SET と書いたのは規模の会計のためである。C が局所小なだけでは SetC は局所小とは限らず、自然変換の集まりが集合をなす保証が先験的にはない。しかし定理2.2.4 の全単射の証明そのものが、この特定の hom が常に集合であることを示している。よって Hom(よ(−),−) は実際には Set に値を持ち、米田の補題は「恒等射での評価が自然同型 Hom(よ(−),−) ≅ ev を定める」という一枚の主張にまとまる。

系2.2.8 — 米田埋め込み

定理2.2.4 の F は任意の集合値関手でよかった。そこで F 自身を表現された関手に特殊化すると、表現された関手の間の自然変換の完全な記述が得られる。それがこの節のもう一つの主役である。

系2.2.8（米田埋め込み）. 局所小な圏 C に対し、二つの関手

よ : C ↪ SetCop, c ↦ C(−,c), f ↦ f∗
よ : Cop ↪ SetC, c ↦ C(c,−), f ↦ f∗

はいずれも充満忠実な埋め込みを定める。

記法について: 共変・反変どちらの埋め込みも同じ記号「よ」で書く。また演習1.7.vii の観点では、この二つは別々の構成ではなく、二変数 hom 関手 C(−,−) : Cop × C → Set（定義1.3.13）の二つの化身である。射への作用 f∗・f∗（後合成・前合成）は例1.4.9 で定義したものになる。

証明. 定義1.5.7 により、示すべきは射への作用が hom 集合の間の全単射

C(c,d) → Hom(C(−,c), C(−,d)), f ↦ f∗
C(c,d) → Hom(C(d,−), C(c,−)), f ↦ f∗

を定めることである。後者を示す。定理2.2.4 で F = C(c,−)、表現対象を d と取れば、evid : Hom(C(d,−), C(c,−)) ≅ C(c,d) は同型である。f ↦ f∗ がこの同型の逆写像であることを見ればよいが、片側が既に同型だと分かっているときは右逆であることの確認だけで足りる（演習1.1.i）。実際、f : c → d から f∗ : C(d,−) ⇒ C(c,−) を作り、その d 成分 f∗d : C(d,d) → C(c,d) を idd で評価すると、idd·f = f が戻ってくる。よって よ : Cop ↪ SetC は充満忠実である。共変側は定理2.2.4 の双対から同様に従う。□

この系の意味を言い直すと: 表現された関手の間の自然変換は、表現対象の間の射とちょうど対応する。したがって局所小な圏 C は、前層の圏 SetCop のうち表現された関手が張る充満部分圏と同型であり（Cop は SetC の中の対応する部分圏と同型）、対象は「他の対象との射の網」で決まることになる。第2章冒頭に掲げられた Mazur の言葉（和訳）——「数学的対象 X は、それを取り巻く圏の中で考えるのが最もよく、X はその圏のすべての対象との関係の網によって決まる。さらに X を理解するには、X を表現する関手を直接扱うほうが適切なことさえある」——が、ここで正確な定理になる。この結果はきわめて強力で、慣習として定理2.2.4 と系2.2.8 の両方が「米田の補題」と呼ばれる。

例2.2.9 — 自然変換を数え上げる

系2.2.8 の使い方の見本。小圏をその対象集合・射集合に送る関手 ob, mor : Cat ⇒ Set は、それぞれ圏 1（1対象・恒等射のみ）と圏 2（0 → 1 の walking arrow）に表現されるのだった（例2.1.5(ix)(x)）。

両者の間には、すぐに見つかる自然な写像が三つある: 対象をその恒等射に送る ob ⇒ mor、射をその域に送る mor ⇒ ob、余域に送る mor ⇒ ob。これで全部だろうか。

表現との自然同型 Cat(1,−) ≅ ob、Cat(2,−) ≅ mor を経由すれば、ob と mor の間の自然変換は表現された関手の間の自然変換であり、系2.2.8 により表現対象 1 と 2 の間の Cat の射から生じるものに限る。1 と 2 の間の関手はちょうど三つ——2 → 1 がひとつ（すべて潰す。これが「恒等射に送る」に対応）、1 → 2 がふたつ（0 を選ぶか 1 を選ぶか。これが「域・余域に送る」に対応。表現対象の間の射と自然変換とで向きが逆になることに注意）——だから、先の三つで尽きている。

系2.2.10 — 行演算は行列の左乗算である

節の締めは、埋め込みの充満性の圏論の外への応用二つ。さらにパラダイム的な第三の応用が命題2.3.10 に控えている。

系2.2.10. n 行の行列に対するどんな行演算も、ある n × n 行列の左乗算で与えられる。その行列は、単位行列に当の行演算を施したものである。

証明. 圏 MatR を思い出す。対象は正整数、射 m → n は成分が単位的環 R に属する n × m 行列（n 行 m 列）、合成は行列の積である。表現された関手 Hom(−, n) の像に現れる要素は、ちょうど n 行の行列たちである。

初等線形代数の行演算——たとえば「第 i 行を第 i 行と第 j 行の和で置き換える」——は、列数 m ごとに写像 Hom(m, n) → Hom(m, n) を与え、これらは Hom(−, n) の自然な自己変換をなす。ここでの自然性とは前合成（右からの行列乗算）と可換なことであり、それは右乗算の線形性から従う。

すると系2.2.8（充満性）により、この自然変換はある射 n → n、すなわちある n × n 行列の左乗算から生じるのでなければならない。さらに定理2.2.4 はその行列を特定してくれる: 自然変換は恒等射での評価、つまり単位行列 idn に行演算を施した行列で決まる。□

系2.2.11 — Cayley の定理

もう一つの応用は、古典的な結果である。

系2.2.11（Cayley の定理）. 任意の群は、ある置換群の部分群と同型である。

証明. 群 G を1対象圏 BG と見る。例2.2.2 で見たとおり、共変米田埋め込み よ : BG ↪ SetBGop の像にある唯一の対象は、右正則作用つきの右 G-集合 G である。系2.2.8 によれば、この G-集合の G-同変な自己準同型は、G の固定した元の左乗算で与えられるものに限る。とくに、同変な自己準同型はすべて自己同型である——これは補題なしには自明でない事実だ。

こうして米田埋め込みは、G と「右 G-集合 G の自己同型群」の間の同型を定める。仕上げに忠実な忘却関手 U : SetBGop → Set と合成すれば、G は集合 G の自己同型群（＝置換群）のある部分群と同型になる。□

節末問題

原文は英語。以下は和訳・言い換え。

  • 2.2.i — 定理2.2.4 の双対を定式化し、証明せよ。すなわち反変関手 F : Cop → Set への自然変換 C(−,c) ⇒ F を特徴づけよ。
  • 2.2.ii — 米田の補題が「任意の集合値関手から表現された関手への自然変換 F ⇒ C(−,c)」の分類には双対化しない理由を説明せよ。
  • 2.2.iii — 例2.2.1 で論じたように、ω 型の図式は可算個の対象と射の列で決まる。米田埋め込み よ : ω ↪ Setωop をこの流儀で（ωop 添字の関手の族と自然変換の族として）記述せよ。そのうえで、米田の補題に訴えずに、よ が充満忠実であることを直接証明せよ。
  • 2.2.iv — 圏をその同型射の集合に送る関手 iso : Cat → Set は mor : Cat → Set の部分関手である。米田の補題を使って、対応するモニックな自然変換を誘導するような、表現対象の間の関手（I と 2 の間）を定めよ。
  • 2.2.v — 米田の補題により、反変冪集合関手 P : Setop → Set の自然な自己変換は、表現対象 Ω = {⊥, ⊤} の自己写像と全単射で対応する。Hom(Ω,Ω) の4つの元それぞれに対応する P の自然な自己変換を記述せよ。これらのうち、共変冪集合関手の自然な自己変換を誘導するものはあるか。
  • 2.2.vi — 単位区間 I = [0,1] ⊂ ℝ の自己同相と、道の関手 Path : Top → Set（例2.1.5(xiv)）の自然な自己同型——reparameterization と呼ぶ——の関係を、米田の補題を使って説明せよ。
  • 2.2.vii — (i) 米田の補題を使って、忘却関手 U : Top → Set の自然な自己変換をすべて特徴づけよ。さらにそれを精密化して、恒等関手 idTop の自然な自己変換をすべて特徴づけよ。すべての空間 X に対して定まる連続写像の自然な族 αX : X → X で、恒等写像ばかりではないものは存在するか。(ii) 同じことを U : Vectk → Set と idVectk について行え。線形変換の自然な族 βV : V → V で、恒等写像ばかりではないものは存在するか。
