Emily Riehl, Category Theory in Context §2.3（pp.66–72）の内容を、個人学習のために日本語で書き直した解説。番号（命題2.3.1 など）は本と揃えてある。翻訳ではなく、同じ内容を自分の言葉で再構成したもの。

この節の問い

2.2 の米田の補題は、表現された関手から出て行く自然変換を完全に分類した。この節ではそれを2つの方向に使う。ひとつは、表現可能関手はその表現対象を（同型を除いて、しかも正準的に）決定するという基本定理（命題2.3.1・系2.3.2）。もうひとつは、表現のデータ——自然同型ひとつぶん——を関手のたった1つの要素に圧縮する語彙（定義2.3.3 の普遍要素）で、これにより「テンソル積とは何か」「群環とは何か」といった問いに、構成を経由せず普遍性で答えられるようになる。

出発点はこうである。局所小な圏 C で対象 x ≅ y が同型なら、hom 関手も C(−,x) ≅ C(−,y)、C(x,−) ≅ C(y,−) と同型になる。これは米田埋め込みが関手であることの帰結にすぎない（補題1.2.3 が「同型は representably に定義できる」と予告していた事実である）。この節の最初の主張は、米田の補題がその逆を与えるということだ。hom 関手の側の自然同型から、C の中の同型を明示的に組み立てられる。

命題2.3.1 — 同型と表現可能同型

命題2.3.1. 局所小な圏 C の対象 x, y について、次の3つのデータは等価である。
  1. C における同型 x ≅ y
  2. 圏 SetCop における同型 C(−,x) ≅ C(−,y)
  3. 圏 SetC における同型 C(y,−) ≅ C(x,−)

(iii) で x と y の順序が入れ替わることに注意。共変側の埋め込みは よ : Cop ↪ SetC なので、向きが1回ひっくり返る。

証明. 埋め込み よ : C ↪ SetCop と よ : Cop ↪ SetC は充満忠実（系2.2.8）であり、充満忠実関手は同型を保存・反映・創出する（演習1.5.iv）。これで (i)⇔(ii) と (i)⇔(iii) が出て証明は終わりだが、自然同型 α : C(−,x) ≅ C(−,y) から C の同型を明示的に組み立てる手続きも見ておく価値がある。

定理2.2.4（の反変版）により、α は表現対象での恒等射の像で決まる。α の x 成分に idx を入れて射 αx(idx) : x → y を、逆向き α−1 の y 成分に idy を入れて射 α−1y(idy) : y → x を得る。この2つが互いに逆であることを、自然性の四角形2枚で確認する。

この四角形で idx ∈ C(x,x) を追う。右回り（上→右）では、まず αx(idx) になり、前合成で αx(idx)·α−1y(idy) に着く。左回り（左→下）では、まず idx·α−1y(idy) = α−1y(idy) になり、αy で送られて αy(α−1y(idy)) = idy に着く。両者が等しいから

αx(idx) · α−1y(idy) = idy.

同じ要領でこちらの四角形で idy を追うと α−1y(idy) · αx(idx) = idx が出る。よって2つの射は互いに逆で、同型 x ≅ y を定める。□

系2.3.2 — 表現対象の一意性

系2.3.2. 圏 C の対象 x と y が同じ関手を表現するなら、x ≅ y である。さらに、2つの表現のデータと可換になる同型 x ≅ y はただ一つ存在する。

証明. 共通の関手 F : Cop → Set の表現 α : C(−,x) ≅ F と β : C(−,y) ≅ F があるとする。縦合成 β−1·α : C(−,x) ≅ C(−,y) は表現可能同型だから、命題2.3.1 により同型 f : x ≅ y を定める。しかも、次の図式を可換にする同型はこの f に限る。米田埋め込みが忠実だから、f∗ = β−1·α を満たす射 f は一意だからである。□

x と y の間の同型そのものは何本もあってよい。主張の要点は、選んだ表現と両立するものが1本しかないことである。この正準性のおかげで、表現可能関手の表現対象は「the representing object」と定冠詞で呼ばれる。圏論での「the」は常にこの意味——同型を除いて一意、しかも比較の同型まで正準に決まる——で使われる。

定義2.3.3 — 要素と普遍要素

米田の補題は、表現のデータをさらに圧縮した記述も与える。自然同型ひとつぶんのデータが、関手の要素1つに置き換わる。

定義2.3.3. 圏 C で添字づけられた（共変または反変の）集合値関手 F の要素とは、対象 c ∈ C と要素 x ∈ Fc の組をいう。要素 (c, x) が普遍要素であるとは、米田の補題が定める自然変換——共変なら Ψ(x) : C(c,−) ⇒ F、反変なら Ψ(x) : C(−,c) ⇒ F——が自然同型であることをいう。このとき c は F を表現し、Ψ(x) がその表現を定める。

定理2.2.4 により、自然変換 C(c,−) ⇒ F の全体は Fc の要素と1対1に対応するのだった。だから「表現＝対象 c と自然同型の組」というデータは「対象 c と、Ψ(x) が同型になるような要素 x ∈ Fc の組」と言い換えられる。例2.1.5・2.1.6 に挙げた表現はすべてこの形で記述し直せる（演習2.3.i）。以下、原型的な例を順に見る。

例2.3.4 — 多項式環 ℤ[x]

忘却関手 U : Ring → Set は多項式環 ℤ[x] に表現されるのだった（例2.1.5(v)）。表現

(2.3.5) Ring(ℤ[x], R) ≅ UR

の普遍要素は、変数 x ∈ ℤ[x] である。米田の補題の証明のとおり、同型 (2.3.5) は環準同型 φ : ℤ[x] → R を要素 φ(x) ∈ R で評価する写像として与えられる。「ℤ[x] からの環準同型は x の行き先だけで自由に決まる」という馴染みの事実が、この表現の中身である。

例2.3.6 — 冪集合と Ω

反変冪集合関手 P : Setop → Set は2元集合 Ω = {⊤, ⊥} に表現されるのだった（例2.1.6(i)）。表現

Set(A, Ω) ≅ P(A)

の普遍要素は、部分集合 {⊤} ∈ PΩ である。要素 ⊤ ∈ Ω ではないことに注意——普遍要素は関手の値 PΩ の要素でなければならない。同型は関数 f : A → Ω を逆像 f−1(⊤) ∈ P(A) に送る写像として与えられる。部分集合と特性関数の対応である。

例2.3.7 — G-トルソー

関手 E : BG → Set、すなわち左 G-集合 E が表現可能であることは、左 G-集合の同型 G ≅ E が存在することと同値である（BG の対象は1つで、それが表現する関手は左正則作用の G だった）。このとき G の E への作用は自由（どの点の固定部分群も自明）かつ推移的（どの点の軌道も全体）で、E は空でない。逆に、空でない自由かつ推移的な左 G-集合は表現可能である。この逆の証明は例2.4.10 で与えられる。

米田の補題によれば、表現のデータ、すなわち特定の同型 G ≅ E は、普遍要素 e ∈ E ——単位元 e ∈ G の像——の選択ひとつで決まる。つまり表現可能な左 G-集合とは、単位元を忘れた群である。表現可能な G-集合は G-トルソーと呼ばれる。

例を挙げる。加法群 ℝn のトルソーが n 次元アフィン空間 𝔸n である。𝔸n は「原点を選んでいない n 次元空間の点の集まり」で、ℝn の元をベクトルと見れば作用は平行移動である。この作用は自由（零でないベクトルはすべての点を動かす）かつ推移的（どの2点も、一方を他方へ運ぶベクトルがちょうど1本ある——2点の「差」が取れる）。原点 o ∈ 𝔸n を1つ選ぶことが座標系 ℝn ≅ 𝔸n を定めることであり、この o が普遍要素である。他の点 p の座標は、x⃗·o = p となる唯一のベクトル x⃗ ∈ ℝn として決まる。

例2.3.8 — テンソル積

k-ベクトル空間 V, W を固定し、関手

Bilin(V, W; −) : Vectk → Set

を考える。ベクトル空間 U を、双線型写像 V × W → U の集合に送る関手である。双線型写像 f : V × W → U とは2変数の関数であって、各 v ∈ V に対し f(v,−) : W → U が線型、各 w ∈ W に対し f(−,w) : V → U が線型であるもの。カリー化すれば、線型写像 f : V → Hom(W,U)（または f : W → Hom(V,U)）と言っても同じである。

この関手の表現が、テンソル積 V ⊗k W の定義である。すなわちテンソル積とは、U について自然な同型

(2.3.9) Vectk(V ⊗k W, U) ≅ Bilin(V, W; U)

を備えたベクトル空間のことをいう。

脚注11 — この同型は U だけでなく V と W についても自然である。命題4.4.6 で扱う。

定理2.2.4 により、自然同型 (2.3.9) は Bilin(V, W; V ⊗k W) の普遍要素、すなわち1本の双線型写像 ⊗ : V × W → V ⊗k W で決まる。これを普遍双線型写像と呼ぶ。テンソル積は「V × W からの双線型写像を備えたベクトル空間のうち普遍的なもの」である。

この「普遍的」の中身を米田の補題で展開する。同型 (2.3.9) は双線型写像 f : V × W → U と線型写像 f̄ : V ⊗k W → U を同一視する。f̄ の誘導する自然性の四角形を見る。

idV⊗W ∈ Vectk(V⊗W, V⊗W) をこの四角形で追う。上→右では、まず普遍要素 ⊗ に送られ（恒等射の像が普遍要素、というのが定理2.2.4 の対応だった）、次に f̄ との合成 f̄·⊗ に着く。左→下では、まず f̄·id = f̄ になり、次に (2.3.9) で f̄ に対応する双線型写像、すなわち f に着く。両者が等しいから f = f̄·⊗。つまり任意の双線型写像 f は、普遍双線型写像 ⊗ を経由して、線型写像 f̄ でただ一通りに分解する。

同型 (2.3.9) の実装は「⊗ と線型写像の合成」だった、ということでもある。この普遍性は、例2.4.12(iii) で記述されるある圏において普遍双線型写像が始対象である、という形にも言い換えられる。

さらに、この普遍性はテンソル積の構成まで復元する。V ⊗k W が存在したとすると、⊗ の像として v ⊗ w ∈ V ⊗k W という形のベクトルが得られ、ベクトル空間である以上その張る部分空間 ⟨v ⊗ w⟩ も含む。⊗ が双線型だから、これらのベクトルは双線型関係式を満たす。

脚注12 — 双線型写像の像はそれ自体では部分空間にならないので、span を取る必要がある。

実は V ⊗k W はこの部分空間 ⟨v ⊗ w⟩ に一致する。商写像 Q : V⊗W → V⊗W / ⟨v ⊗ w⟩ を考えると、Q を ⊗ と合成した双線型写像は零である。ところが零線型写像 0 : V⊗W → V⊗W / ⟨v ⊗ w⟩ も ⊗ との合成が零だから、分解の一意性（いま示した普遍性）より Q = 0。Q は全射なので商は零空間、すなわち V ⊗k W = ⟨v ⊗ w⟩ である。こうして「v ⊗ w たちが生成し、双線型関係式で割る」という通常の構成的定義が、普遍性だけから回復される。

命題2.3.10 — V ⊗ W ≅ W ⊗ V

テンソル積の普遍性は、対象を同型を除いて特徴づけるだけでなく、基底を一切選ばずに性質を証明する道具になる。締めくくりにその見本を2つ——同型の存在（命題2.3.10）と、その同型の明示的な記述（注意2.3.12）——を見る。

命題2.3.10. 任意の k-ベクトル空間 V, W に対し、V ⊗k W ≅ W ⊗k V。

証明. 系2.3.2 により、関手 Bilin(V,W;−) と Bilin(W,V;−) が自然同型であることを示せば足りる。双線型写像 f : V × W → U を、f̂(w,v) ≔ f(v,w) で定まる f̂ : W × V → U に送れば、U ごとの全単射 Bilin(V,W;U) ≅ Bilin(W,V;U) が得られ、これは U について自然である。表現の自然同型とつなげば

(2.3.11) Vectk(V⊗W, −) ≅ Bilin(V,W;−) ≅ Bilin(W,V;−) ≅ Vectk(W⊗V, −)

と、2つの表現された関手が自然同型になる。命題2.3.1（共変版）により、この自然同型は表現対象の同型 V ⊗k W ≅ W ⊗k V から生じる。□

注意2.3.12 — 同型を明示的に取り出す

命題2.3.1 は存在を言うだけでなく、同型を具体的に計算する手続きでもある。(2.3.11) の合成同型で idV⊗W の像を追えばよい。

Vectk(V⊗W, V⊗W) ≅ Bilin(V,W; V⊗W) ≅ Bilin(W,V; V⊗W) ≅ Vectk(W⊗V, V⊗W)

まず idV⊗W は普遍双線型写像 ⊗ : V×W → V⊗W に送られる（例2.3.8 で見た対応）。次の同型で、変数を入れ替えた双線型写像

W × V → V × W → V ⊗k W, (w,v) ↦ (v,w) ↦ v ⊗ w

に送られる。最後の同型は ⊗ : W×V → W⊗V の普遍性による分解だから、結果はこの双線型写像を分解する唯一の線型写像 φ : W ⊗k V → V ⊗k W である。

この φ が求める線型同型で、(2.3.11) は φ との前合成として実装される。図の可換性を w ⊗ v で読めば φ(w ⊗ v) = v ⊗ w。期待どおりの「成分の入れ替え」である。

例2.3.13 — 群環

群 G を固定し、関手

Group(G, (−)×) : Ring → Set

を考える。単位的環 R を、G から R の単元群 R× への群準同型の集合に送る関手である。この関手の表現が群環 ℤ[G] の普遍性を表す。米田の補題により、自然同型

Ring(ℤ[G], −) ≅ Group(G, (−)×)

は1本の群準同型 η : G → ℤ[G]×（普遍要素）で符号化される。対応の中身は、環準同型 φ : ℤ[G] → R が単元群の間の群準同型 φ× : ℤ[G]× → R× を誘導するので、η と前合成して群準同型 φ×·η : G → R× を得る、というものである。

脚注13 — 係数を任意の可換単位環 K に替えた群環 K[G] にも同様の普遍性がある。その場合は圏 Ring を K-代数の圏に置き換える。
