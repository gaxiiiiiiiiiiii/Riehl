2. この節の物語

p.59 エピグラフは Mac Lane の回想（和訳）: 「米田はこの補題の起源をこう語るのを好んだ——1954〜55年頃、フランス滞在中の米田に、 パリを訪れていた Mac Lane が北駅のカフェで面会を求め、話は米田の列車が発車するまで 続いた。そのなかで Mac Lane はこの補題を知り、のちに命名した」。

  • pp.59–60 出発点は 2.1 の表現の理解: 「自然同型 C(c,−) ≅ F を定めるにはどんなデータが要るか」。問いはより一般の 自然変換 α : C(c,−) ⇒ F に広げられる。
  • p.60 例2.2.1（ω 上の図式）と例2.2.2（BG 上の G-set）が ウォームアップ。読み方: 成分の族のうちどこが自由に選べて、自然性がどこを強制するかを 手で追う。
  • p.61 命題2.2.3 がウォームアップの結論: G-同変写像 G → X は ϕ ↦ ϕ(e) で X の要素と一対一。
  • p.61 定理2.2.4（米田の補題）: ev_id が全単射で、 c と F の双方に自然。「C が locally small なだけでも Hom(C(c,−),F) が 実際に集合になる」という規模の注意も本文にある。
  • pp.61–62 全単射の証明。逆写像 Ψ の成分が自然性の四角形 （図式(2.2.6)）から強制されて式(2.2.5)に至る過程が核心。
  • pp.62–63 自然性の証明。関手方向（β : F ⇒ G）と 対象方向（f : c → d）の 2 枚の四角形に分かれる。
  • pp.63–64 注意2.2.7: C が small のとき C(c,−) は 評価関手 ev_c を表現する、という読み替えと、C × Set^C 上の自然同型としての定式化。 Set に収まらない場合の SET への言及。
  • p.64 系2.2.8（米田埋め込み）: よ は充満忠実。 証明は「f ↦ f* が ev_id の右逆」を見るだけ（演習1.1.i の手筋）。
  • p.65 例2.2.9（ob と mor）。読み方: 系2.2.8 を 「表現対象の間の射を数えて自然変換の在庫を調べる」使い方の見本として読む。
  • pp.65–66 締めは充満性の応用が二つ: 系2.2.10（行演算は行列の左乗算）と系2.2.11（Cayley の定理）。
  • p.66 節末問題 2.2.i–vii。

4. 形式化のズレの背景

  • Set の翻訳 — 本の「locally small な C 上の Set 値関手」は F : C ⥤ Type v₁。注意2.2.7 の SET（集合とは限らない規模）は、 Mathlib では uliftFunctor で Type (max u₁ v₁) に 持ち上げて処理される（coyonedaLemma : coyonedaPairing ≅ coyonedaEvaluation）。 なお現行 Mathlib では Type 圏の hom は素の関数ではなく関数を包む構造体で、 関数を hom と見なすには ↾f（TypeCat.ofHom）を使う （Recap の yoneda に現れる）。要素への適用 α.app c (𝟙 c) は coercion がそのまま通る。
  • 定理2.2.4 の分割 — 本の主張（和訳）は「ev_id : Hom(C(c,−),F) → Fc は 全単射で、対応は c と F の双方に自然」。Mathlib は coyonedaEquiv 一本＋補題群にまとめるが、演習では (1) Ψ の構成 (2) 右逆 (3) 左逆 (4) F 方向の自然性 (5) c 方向の自然性 の 5 本に分割した。規約「構成と性質に分ける」 に加え、本の証明の分割（全単射 → 自然性）に一致させるため。
  • myΨ の sorry 範囲（この節の決定） — data ごと丸ごと sorry にする（Ψ 方式）。補題の核心が「自然性が成分の式を強制する」 過程そのもので、式(2.2.5)を書き渡すと演習が消えるため。1.7 の 「data は渡して naturality だけ sorry」とは逆の選択。
  • 命題2.2.3 — 本の主張（和訳）は「G-同変写像 G → X は、ϕ を ϕ(e) に送る 写像を介して X の要素と全単射で対応する」。どの写像が全単射かまで主張に含めるため、 Equiv ではなく Function.Bijective (fun ϕ => ϕ 1) で述べた。 Mathlib の対応物 MulActionHom.End.equivMulOpposite は X = M （モノイド一般）の特殊形で、値が反対モノイド Mᵐᵒᵖ に落ちる。
  • 系2.2.8 — 「full and faithful embeddings」を、共変・反変 × 充満・忠実の 4 つの結論に分けて置いた。
  • 系2.2.10 — Mathlib の Mat R は対象が有限型・射 m ⟶ n が m×n 行列で、本の Mat_R（対象は正整数・射 m → n が n×m 行列）の転置。よって本の 「行演算＝左乗算」は「列演算＝右乗算」の形で形式化した。「単位行列に演算を施した 行列」は α.app (op n) (𝟙 n) が受け持つ。この statement 自体の Mathlib 対応物はない。
  • 系2.2.11 — 「任意の群は置換群の部分群と同型」を存在文 ∃ X H, Nonempty (G ≃* H) に言い換えた。Mathlib の Equiv.Perm.subgroupOfMulAction は忠実な作用一般への一般化 （X = G が本の場合）。
  • 演習2.2.iii — ω は ℕ の順序圏（Preorder.smallCategory）で、 hom は ULift (PLift (k ≤ n)) に化ける。statement が暗黙に使う この instance は冒頭 Recap に写した（二重登録を避けるため def として）。「ωᵒᵖ 添字の族として記述する」 前半は形式化せず、充満・忠実の後半のみ置いた。Mathlib には一般の系2.2.8 の インスタンスしかない（本問は ω への特殊化を直接証明で求める）。
  • コメントのみの節末問題 — 2.2.ii・2.2.vi は説明問題。2.2.v・2.2.vii は 特徴づけの主張の形自体が答えの一部になる（演習1.5.vii と同じ扱い）。2.2.iv は walking isomorphism の圏 I が Mathlib になく、「表現対象の間の関手が自然変換を 誘導する」構図の再現も重い。

5. 次節への接続

  • 2.3 普遍性と普遍要素 — 冒頭が逆向きの問い「表現可能な同型から対象の同型を 取り出せるか」で開き、米田の補題がその往復を与える。充満性の第三の応用として 命題2.3.10 が予告されている（p.65）。
  • 2.4 要素の圏 — category of elements のもう一つの定義を米田の補題が供給する。
  • 3章 極限 — 錐・極限は表現可能性の言葉で定義され（3.1–3.2）、 yoneda・coyoneda と系2.2.8 の充満忠実性が土台になる。
  • 4章 随伴 — 随伴の unit・counit の対応や随伴関手の一意性（4.2 以降）は 米田埋め込みの充満忠実性で回る。
