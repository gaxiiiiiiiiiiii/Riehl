2.2 米田の補題 — Companion

この文書は §2.2 pp.59–66 を一本の論証として辿る地図です。以下の各ユニットは本文の論理の一区切りに対応し、それぞれ「なぜここに置かれるか」「何を主張するか」「演習ファイルでどう現れるか」を一体で書いています。演習ファイルは Riehl/Ch2_Yoneda/Yoneda.lean。

節を駆動する問い

読む範囲: 節の冒頭から例2.2.1 の直前まで p.59

2.1 で「F は c に表現される」を、自然同型 C(c,−) ≅ F が存在すること、と定義しました。しかしそれを実際に示すには、自然同型を一つ書き下ろさなければなりません。自然同型とは「自然変換であって、成分がすべて同型であるもの」ですから、一段弱い問い——自然変換 α : C(c,−) ⇒ F を定めるデータは何か——に答えれば、残るのは成分が同型かどうかの確認です。

§2.2 はこの一つの問いだけを立て、答え（定理2.2.4）を得たあとは、その答えを特殊化し応用して節を閉じます。本文が明示するとおり、この問いは表現可能関手 C(c,−) から出る自然変換についてのものです。C(c,−) へ入る自然変換 β : F ⇒ C(c,−) には同じ答えがありません。その非対称性がそのまま演習2.2.ii になります。

ユニット1 ウォームアップ — 形の違う二つの圏で同じ現象を見る

読む範囲: 例2.2.1・例2.2.2・命題2.2.3 pp.60–61

役割。一般論に入る前に、性質が両極端な二つの添字圏で問いを手で解きます。ω は poset で、射は不等式の証明でしかなく、恒等射以外の自己射を持ちません。BG は対象がただ一つで、圏の情報がすべて自己射（＝群の元）に載っています。共通点のほとんどない二つで同じ答えが出ることが、「答えは添字圏の形によらない」という予想の根拠になります。

主張。例2.2.1（ω）では、hom 集合 ω(k,n) が空集合か一点集合のどちらかなので、自然変換 α : ω(k,−) ⇒ F のデータは n ≥ k の各段の要素に集約され、自然性がそれらを隣の段どうしで結びます。結果として α は α_k(id_k) ∈ F_k という一つの要素で完全に決まり、しかも F_k のどの要素を選ぶことも許されます。例2.2.2（BG）では、G-集合 X への自然変換 φ : G ⇒ X はちょうど同変写像 φ : G → X であり（例1.4.4(iv)）、自然性は同変性 φ(g·h) = g·φ(h) という一本の条件に凝縮します。命題2.2.3 はこちら側の結論で、「同変写像 G → X は、φ を φ(e) に送る写像を介して X の要素と一対一に対応する」。二つの例は同じ形——単位射の像ひとつで決まり、その値には制約がない——に着地します。

形式化。Part A。本文中の例は載せない方針なので、statement になるのは命題2.2.3 だけです（例2.2.1・2.2.2 は本文の側で手を動かす対象）。BG 上の G-集合は [MulAction G X]、その間の自然変換は同変写像 G →[G] X に翻訳されます（MulActionHom の写しは Recap にあります）。「どの写像が全単射なのか」まで主張に含めたいので、Equiv ではなく Function.Bijective (fun ϕ => ϕ 1) の形で述べました。Mathlib の対応物 MulActionHom.End.equivMulOpposite は X = M（モノイドの自分自身への作用）に特殊化した形で、しかも値が反対モノイド Mᵐᵒᵖ に落ちるため、対応は部分的です。

ユニット2 定理2.2.4（米田の補題）

読む範囲: 定理2.2.4 の statement p.61 を読んだ時点で myΨ に入れます。証明の二部（全単射・自然性）は pp.61–63

役割。ユニット1 の予想を、任意の locally small な圏 C について確定させます。ここが節の中心で、以降のすべては本定理の特殊化か応用です。

主張。二つあります。(1) 自然変換をその表現対象の恒等射で評価する写像 ev_id : Hom(C(c,−),F) → Fc, α ↦ α_c(id_c) は全単射である。(2) この対応は c と F の双方に自然である。なぜ (2) まで主張するのか——(1) だけなら「両辺の要素の数が等しい」という話で終わってしまい、対応が canonical であることを言えません。埋め込み よ が関手として振る舞うこと（系2.2.8）も、2.3 で表現対象が同型を除いて決まることも、この対応が c と F の変化と可換であることに依存します。本文が付ける規模の注意も定理の一部として効きます。C は locally small でしかないので Hom(C(c,−),F) は先験的には集合とは限りませんが、全単射の存在がそれを集合だと保証します。

本文の証明は、問いの立て方をそのままなぞる順で進みます。逆写像 Ψ の成分は、自然性の四角形（図式(2.2.6)）に従うことを要求した時点で選択の余地なく決まってしまい、続くのは、そうやって強制された式(2.2.5)が本当に自然変換を与えるかどうかの確認です。

形式化。Part B の5本——myΨ の構成、それが ev_id の右逆であること、左逆であること、F 方向の自然性、c 方向の自然性。Mathlib はこれを coyonedaEquiv 一本と補題群（coyonedaEquiv_comp・coyonedaEquiv_naturality）にまとめますが、「構成と、それが満たす性質を分ける」という規約と、本文の証明の分割（全単射 → 自然性）に合わせて5本にしました。myΨ は型だけを書いて data ごと丸ごと sorry にしてあります。1.7 で data を渡して proof obligation だけを sorry にしたのとは逆の選択で、この節では「成分の式が強制される」過程の追体験が演習の核心だからです。本の Set 値関手は、hom と同じ宇宙の Type v₁ 値関手 F : C ⥤ Type v₁ に翻訳します。

ユニット3 注意2.2.7 — 「両変数に自然」を一枚の主張にする

読む範囲: 注意2.2.7 pp.63–64

役割。ここは補題の内容を足す場所ではなく、定理2.2.4 の後半（両変数の自然性）を精密化する場所です。「c と F の双方に自然」を文字どおり一つの自然同型として述べるには、その自然変換が住む舞台を用意しなければなりません。すなわち、積圏 C × Set^C を域とする二つの関手——(c,F) を Fc に送る評価関手 ev と、(c,F) を Hom(C(c,−),F) に送る Hom(よ(−),−)——です。同時に規模の会計も必要になります。C が small なら Set^C は locally small ですが（注意1.7.3）、C が locally small なだけでは Set^C はそうとは限らないので、本文は行き先を SET と書き分けます。C が small な場合には、C(c,−) が評価関手 ev_c : Set^C → Set を表現する、という読み替えもここで得られます。

形式化。Part B の末尾に注記のみを置き、statement は置いていません。対応する Mathlib の宣言は、Hom(よ(−),−) にあたる coyonedaPairing、ev にあたる coyonedaEvaluation（どちらも C × (C ⥤ Type v₁) 上の関手）と、両者の自然同型 coyonedaLemma です。本文の SET の但し書きは、Mathlib では値を Type (max u₁ v₁) へ持ち上げる uliftFunctor が受け持っています。

ユニット4 系2.2.8（米田埋め込み）— 定理を関手そのものに向ける

読む範囲: 系2.2.8 p.64

役割。定理2.2.4 では F を自由に取れます。そこで F を、それ自身が表現された関手 C(c,−) に特殊化し、表現対象のほうを d に取ります。すると Hom(C(d,−), C(c,−)) ≅ C(c,d) となり、これは「よ の射への作用 f ↦ f* が hom 集合の間の全単射である」——つまり定義1.5.7 の意味で よ : Cᵒᵖ ↪ Set^C が充満忠実である——という文にほかなりません（共変側の Hom(C(−,c), C(−,d)) ≅ C(c,d) は、定理2.2.4 の双対から同様に出ます）。したがって C は前層の圏 Set^(Cᵒᵖ) の充満部分圏と同一視でき、対象は「他の対象との射の網」によって決まります。章冒頭の Mazur の言葉（和訳）——「数学的対象 X は、それを取り巻く圏の中で考えるのが最もよく、X はその圏のすべての対象との関係の網によって決まる」——が、ここで正確な定理になります。2.3 の「普遍性は対象を同型を除いて決める」の源泉もこの系です。

主張。共変米田埋め込み よ : C ↪ Set^(Cᵒᵖ)（c ↦ C(−,c)）と反変米田埋め込み よ : Cᵒᵖ ↪ Set^C（c ↦ C(c,−)）は、いずれも充満忠実な埋め込みである。この二つは別々の構成ではなく、二変数 hom 関手 C(−,−) : Cᵒᵖ × C → Set（定義1.3.13）の二つの化身です（演習1.7.vii）。射への作用は例1.4.9 の後合成 f₊ と前合成 f* が担います。

形式化。Part C の4本（共変・反変 × 充満・忠実）。一つの主張に複数の結論が含まれるときは結論ごとに演習を分ける規約によります。Mathlib の対応物は Yoneda.yoneda_full・Yoneda.yoneda_faithful・Coyoneda.coyoneda_full・Coyoneda.coyoneda_faithful。なお Mathlib の coyoneda は独立に定義されておらず yoneda.flip として得られており、演習1.7.vii の見方がそのまま実装になっています（両者の写しは Recap にあります）。

ユニット5 充満性の応用 — 同じ論法を圏を替えて回す

読む範囲: 例2.2.9・系2.2.10・系2.2.11 pp.65–66

役割。系2.2.8 の実用形は「表現可能関手の間の自然変換の在庫＝表現対象の間の射の在庫」です。左辺は数えにくく右辺は数えやすいことが多いので、自然変換の完全なリストが手に入ります。ここでは同じ論法を、圏を取り替えて三度回します。抽象的な主定理が圏論の外で具体的な歯を持つことの実演でもあります。

主張。例2.2.9 は数え上げの見本です。ob, mor : Cat ⇒ Set はそれぞれ 1 と 2 に表現されるので（例2.1.5(ix)(x)）、両者の間の自然変換は 1 と 2 の間の射と対応します。Cat における 1 と 2 の間の関手はちょうど三つ（1 → 2 が二つ、2 → 1 が一つ）で、最初に手で見つけた三つの自然変換——対象をその恒等射に送る ob ⇒ mor と、射をその域・余域に送る二つの mor ⇒ ob——がそれで尽きていることが分かります。系2.2.10 は Mat_R で回した場合で、「n 行の行列に対する行演算はどれもある n×n 行列の左乗算であり、その行列は単位行列に同じ行演算を施して得られる」。前半が系2.2.8（充満性）の担当、行列を特定する後半が定理2.2.4 の担当です。系2.2.11 は BG で回した場合の Cayley の定理「任意の群は置換群の部分群と同型」。命題2.2.3 で X = G と置いた形——右 G-集合 G の同変自己準同型は左乗算に限る（本文は系2.2.8 経由で述べます）——が証明の中核になります。

形式化。Part D の2本。例2.2.9 は例なので statement は置きません。系2.2.10 は Mathlib に対応物がなく、また Mathlib の Mat R は対象が有限型・射 m ⟶ n が m×n 行列で、本の Mat_R（対象は正整数・射 m → n が n×m 行列）の転置になっています。そのため本の「行演算＝左乗算」は「列演算＝右乗算」の向きで書きました。「単位行列に演算を施した行列」の役は α.app (op n) (𝟙 n) が務めます。系2.2.11 は「置換群の部分群と同型」を存在文 ∃ X H, Nonempty (G ≃* H) に言い換えました。Mathlib の Equiv.Perm.subgroupOfMulAction は忠実な作用一般への一般化で、X = G が本の場合にあたります。

ユニット6 節末問題の取捨

読む範囲: 節を読み終えてから p.66

役割。七問のうち Lean の statement にして意味があるのは、定理の双対（2.2.i）と ω での直接証明（2.2.iii）の二つです。残りは説明を求める問題か、「特徴づけを述べること」自体が答えになる問題で、statement を書くと答えを渡してしまいます。

形式化。2.2.i は Part B と同じ5分割で Part E に置きました（myΨop の構成、右逆、左逆、関手方向・対象方向の自然性。Mathlib 側は yonedaEquiv・yonedaEquiv_comp・yonedaEquiv_naturality）。本文が注意するとおり、双対化されるのは一般の圏 C であって Set ではないので、双対もやはり C(−,c) から出る自然変換の分類になります。2.2.iii は「よ : ω ↪ Set^(ωᵒᵖ) を ωᵒᵖ 添字の族として記述せよ」という前半を落とし、米田の補題に訴えない充満性・忠実性の直接証明だけを、ω = ℕ の順序圏として置きました（statement が暗黙に使う Preorder.smallCategory は Recap に写してあります。hom は ULift (PLift (k ≤ n)) に化けます）。残りはコメントのみです。2.2.ii と 2.2.vi は説明問題。2.2.v と 2.2.vii は特徴づけの主張の形そのものが答えの一部になるため置きません（演習1.5.vii と同じ扱い）。2.2.iv は walking isomorphism の圏 I が Mathlib になく、表現対象の間の関手から自然変換を誘導する構図の再現も重いので、問題文だけを残しました。

次節への接続

2.3 は冒頭の問いに戻ります。表現に伴うデータとは何かを普遍要素の言葉で言い換え、「表現可能関手は自分の表現対象を決める」を証明する節です。その最初の結果である命題2.3.1 は、x ≅ y と C(−,x) ≅ C(−,y) と C(y,−) ≅ C(x,−) の三つが等価なデータであることを述べ、証明の道具は系2.2.8 の充満忠実性と演習1.5.iv（充満忠実な関手は同型を反映し創出する）です。p.65 で予告される「充満性の第三の応用」は命題2.3.10（V ⊗_k W ≅ W ⊗_k V）。3章以降は極限も随伴も表現可能性の言葉で述べられるので、定理2.2.4 と系2.2.8 はそこで繰り返し呼ばれます。
