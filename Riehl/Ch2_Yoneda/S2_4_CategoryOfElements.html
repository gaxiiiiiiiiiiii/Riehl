2.4 要素の圏

Emily Riehl, Category Theory in Context §2.4（pp.72–78）の内容を、個人学習のために日本語で書き直した解説。番号（命題2.4.8 など）は本と揃えてある。翻訳ではなく、同じ内容を自分の言葉で再構成したもの。

「普遍要素は普遍要素である（universal elements are universal elements）」——本節の主結果、命題2.4.8 に Riehl 自身が付けた見出し。定義2.3.3 で導入した「普遍要素」が、始対象・終対象という伝統的な意味でも確かに「普遍」であることを言っている。

この節の問い

対象 c ∈ C の普遍性には二つの向きがある。射が入って来る型の普遍性は、反変関手 F と表現 C(−,c) ≅ F によって表される。射が出て行く型の普遍性は、共変関手 F と表現 C(c,−) ≅ F によって表される。一つの対象が両方をもつこともある。系2.3.2 により、どちらの普遍性も c を同型を除いて決める——しかも、指定した表現と可換になる同型がただ一つだけ、という正準な意味で決める。

こうした文脈で「c は、… を満たす x を備えた C の普遍対象である」という言い方をする。この言い回しが主張しているのは、x ∈ Fc が定義2.3.3 の意味での普遍要素だということ、つまり米田の補題の下で x が表現の自然同型を分類する要素だ、ということである。

ここで疑問が残る。この「普遍」という語は、伝統的な意味——ある圏の始対象・終対象であること——と本当に一致しているのか。本節はそれを証明する。舞台となる圏は要素の圏 ∫F で、表現可能関手 F のデータだけから正準に作られる。主結果の命題2.4.8 は、あらゆる普遍性が「変数の向きに応じて始対象または終対象を定めること」として理解できると述べる。これは 2.1 の終わりに残した問い——表現可能関手の語る普遍性は、始対象・終対象という最初のパラダイムとどう関係するのか——への答えである。

要素の圏はもう一つの問いにも答える。与えられた集合値関手 F が表現可能かどうかをどう判定するか。命題2.4.8 は、要素 x ∈ Fc が単なる自然変換ではなく自然同型を定めるのはいつか、を特徴づける形にもなっている。

定義2.4.1 — 共変関手の要素の圏

定義2.4.1. 共変関手 F : C → Set の要素の圏 ∫F は、
  • 対象が F の要素、すなわち c ∈ C と x ∈ Fc の組 (c, x)
  • (c, x) から (c′, x′) への射が、C の射 f : c → c′ であって Ff(x) = x′ を満たすもの
である。要素の圏には明らかな忘却関手 Π : ∫F → C がある。

恒等射と合成は C から受け継ぐ。合成が定義できるのは F の関手性による。f : (c,x) → (c′,x′) と g : (c′,x′) → (c″,x″) なら F(g·f)(x) = Fg(Ff(x)) = Fg(x′) = x″ なので、g·f はちゃんと (c,x) → (c″,x″) の射になる。恒等射については Fidc(x) = x。

射の条件 Ff(x) = x′ は「x を f に沿って押し出すと x′ になる」と読める。とくに、域 (c,x) と C の射 f : c → c′ を決めれば、余域は (c′, Ff(x)) と一意に定まる——この観察が後の命題2.4.14 の鍵になる。

傍注 — 共変関手の要素の圏からの忘却関手は、要素をその台となる C の対象に、要素の間の射をその台となる C の射に送る。

定義2.4.2 — 反変関手の要素の圏

反変関手 F : Cop → Set については、定義2.4.1 を単純に双対化しない。F を Cop 上の共変関手と見て定義2.4.1 を適用すると、射影関手の行き先が Cop になってしまう。そこで ∫F は、そうして得られる圏の反対圏と定める。共変・反変どちらの場合も、要素の圏には C への正準な忘却関手 Π : ∫F → C があるようにする、というのがこの規約であり、それが定義2.4.1・2.4.2 の両方で射の向きを決めている。明示的に書けば次のとおり。

定義2.4.2. 反変関手 F : Cop → Set の要素の圏 ∫F は、
  • 対象が F の要素、すなわち c ∈ C と x ∈ Fc の組 (c, x)
  • (c, x) から (c′, x′) への射が、C の射 f : c → c′ であって Ff(x′) = x を満たすもの
である。要素の圏には明らかな忘却関手 Π : ∫F → C がある。

反変だから Ff : Fc′ → Fc であり、条件は「x′ を f に沿って引き戻すと x になる」と読める。押し出しか引き戻しかの違いはあるが、どちらの場合も射 f : (c,x) → (c′,x′) の台は C の射 c → c′ であって、Π は共変関手になる。

傍注 — 反変関手の要素の圏からの忘却関手も、要素をその台となる C の対象に、要素の間の射をその台となる C の射に送る。反変関手の要素の圏に対する上の規約は、この忘却関手が共変になることを含意している。

例2.4.3 — n-彩色つきグラフ

関手 n-Color : Graphop → Set は、グラフをその頂点の n-彩色（隣接する頂点に同じ色を割り当てない色分け）全体の集合に送るのだった。要素の圏 ∫n-Color の対象は、グラフと選ばれた n-彩色の組、すなわち n-彩色されたグラフである。

射はどうなるか。定義2.4.2 により、(G, χ) から (G′, χ′) への射はグラフ準同型 φ : G → G′ であって、χ′ を φ で引き戻したものが χ になるもの、すなわち各頂点 v で χ′(φ(v)) = χ(v) を満たすものである。これは「G の紫の頂点は G′ の紫の頂点に行く」——つまり彩色を保つ——という条件にほかならない。まとめると、∫n-Color は n-彩色されたグラフと彩色を保つグラフ準同型の圏である。

例2.4.4 — 点つき対象の圏

具体圏 C（忠実な忘却関手 U : C → Set を備えた圏）に対し、∫U の対象は、指定された対象 c ∈ C の台集合の要素 x ∈ Uc である。射は、選ばれた要素を保つような C の射である。すでに個別の場合に使ってきた記法を拡張して、この圏を C∗ と書き、C の点つき対象の圏と呼ぶ。

例2.4.5 — 依存和と依存積

C が離散圏（恒等射しかない圏）のとき、関手 F : C → Set は添字づけられた集合族 (Fc)c∈C を符号化しているにすぎない。このとき ∫F も離散圏になり、その対象の集合は

Σc∈C Fc

である。射影 Π : Σc∈CFc → C は、c ∈ C 上のファイバーがちょうど Fc になるように定まる。この集合 Σc∈CFc を族 (Fc)c∈C の依存和と呼ぶ。その要素は依存対 (c, x)——添字となる対象 c ∈ C と、それに応じた集合の要素 x ∈ Fc の組——である。

関連する依存積 Πc∈CFc は、関手 Π : Σc∈CFc → C の切断（section）全体の集合として定義される。切断とは s : C → Σc∈CFc であって Π·s = id となるもの、つまり各 c に対して Fc の要素を1つずつ選ぶ規則である。その要素は依存関数 f、すなわち各 c ∈ C に対して要素 f(c) ∈ Fc を指定するものである。

依存和の要素が依存対、依存積の要素が依存関数。要素の圏の言葉で言えば、前者は ∫F の対象、後者は射影 Π の切断である。

例2.4.6 — スライス圏 c/C と C/c

表現された共変関手 C(c,−) の要素の圏を考える。対象は C の射 f : c → x、つまり域が c の射である。f : c → x から g : c → y への射は、定義2.4.1 により h : x → y であって h·f = g を満たすもの、すなわち「c の下で」三角形を可換にする射である。

この圏には別名がある。演習1.1.iii で導入された、対象 c ∈ C の下のスライス圏 c/C である。忘却関手 Π : c/C → C は、射 f : c → x をその余域 x に送り、可換三角形を「c の向かい側の辺」h に送る。

双対に、∫C(−,c) は対象 c ∈ C の上のスライス圏 C/c である。対象は余域が c の射 f : x → c、f から g : y → c への射は h : x → y であって g·h = f を満たすもの、すなわち「c の上で」三角形を可換にする射である。

忘却関手 Π : C/c → C はこちらでは域への射影である。

なお C(−,c) ≅ Cop(c,−) : Cop → Set である。実際、C(−,c) を Cop 上の共変関手と見てその要素の圏を作ったもの c/(Cop) は、反変関手 C(−,c) の要素の圏の反対圏 (C/c)op と同型になる（演習1.2.i）。定義2.4.2 が「反対圏を取る」と決めたのは、まさにこの関係を利用している。

補題2.4.7 — コンマ圏としての要素の圏

米田の補題は、要素の圏のもう一つの定義を与える。

補題2.4.7. 関手 F : Cop → Set の要素の圏は、コンマ圏と同型である:

∫F ≅ よ↓F.

ここでコンマ圏は、米田埋め込み よ : C → SetCop と対象 F : 1 → SetCop に関して定義される。

コンマ圏の定義（演習1.3.vi）を思い出すと、よ↓F の対象は組 (c ∈ C, α : C(−,c) ⇒ F)——表現された関手から F への自然変換——であり、(c,α) から (c′,α′) への射は f : c → c′ であって α′·f∗ = α を満たすものである（F 側の成分は 1 の恒等射しかない）。

この同型は ∫F と よ↓F から C への正準な射影と可換になる（演習1.3.vi）。共変関手についての双対版は演習2.4.i に、別のコンマ圏による特徴づけは演習2.4.ii に委ねられる。

証明. まず対象について。米田の補題により、要素 x ∈ Fc は自然変換 Ψ(x) : C(−,c) ⇒ F と1対1に対応する。これが ∫F の対象と よ↓F の対象の間の全単射を与える。

次にこの対象の間の全単射を充満忠実な関手に延長する。∫F における (c,x) から (c′,x′) への射は、Ff(x′) = x を満たす f : c → c′ であった。米田の補題（というより米田埋め込みの関手性）により、f には自然変換 f∗ : C(−,c) ⇒ C(−,c′) が対応する。これが よ↓F において Ψ(x) から Ψ(x′) への射であるためには、次の自然変換の三角形が可換でなければならない。

ここで定理2.2.4 の自然性が効く。要素から自然変換を作る構成 Ψ は c ∈ C について自然だった。この自然性を射 f : c → c′ に適用すると、要素 Ff(x′) ∈ Fc について

Ψ(Ff(x′)) = Ψ(x′)·f∗

が成り立つ。したがって三角形の可換性 Ψ(x′)·f∗ = Ψ(x) は Ψ(Ff(x′)) = Ψ(x) と同値であり、Ψ が全単射だから Ff(x′) = x と同値である。これは ∫F における射の定義そのものである。よって射の対応も全単射で、同型が得られた。□

命題2.4.8 — 普遍要素は始対象・終対象である

要素の圏の重要な使い道は、あらゆる普遍性を「あるデータ——定義2.3.3 の普遍要素——が、適切な圏、すなわち表現可能関手の要素の圏において始対象または終対象を定める」という形に符号化できると示すことである。

命題2.4.8（普遍要素は普遍要素である）. 共変関手 F : C → Set と要素 x ∈ Fc について、x が普遍要素であることと、対象 (c,x) ∈ ∫F が始対象であることは同値である。したがって F が表現可能であることと、その要素の圏が始対象をもつことは同値である。

双対に、反変関手 F : Cop → Set と要素 x ∈ Fc について、x が普遍要素であることと (c,x) ∈ ∫F が終対象であることは同値である。したがって F が表現可能であることと、その要素の圏が終対象をもつことは同値である。

証明の前に、この特徴づけの見通しを述べる。まず条件が必要であることは既知の道具で分かる。自然同型 C(c,−) ≅ F は圏の同型 ∫F ≅ ∫C(c,−) ≅ c/C を誘導し（演習2.4.viii と例2.4.6）、c/C には始対象がある——恒等射 idc がそれである。よって F が表現可能なら ∫F は始対象をもつ。

脚注14 — 演習2.4.iii が注意するように、c/C の始対象は idc だけとは限らない。

驚くべきは逆のほう、すなわち ∫F に始対象があれば F の表現可能性が従う、という点である。鍵は例によって米田の補題、それも定理2.2.4 の形のものである。

脚注15 — 主張も証明の方針も出そろったので、まず自分で議論を組み立ててみることを本文は勧めている。

証明. 定義2.3.3 により、x ∈ Fc が普遍要素であるとは、米田の補題が定める自然変換 Ψ(x) : C(c,−) ⇒ F が自然同型であることだった。定義1.4.3 により、自然変換が自然同型であることは、すべての d ∈ C について成分 Ψ(x)d : C(c,d) → Fd が同型であること、すなわち全単射であることと同値である。

したがって、x ∈ Fc が普遍要素であることは

すべての d ∈ C とすべての y ∈ Fd に対し、Ψ(x)d(f) = y となる f : c → d がただ一つ存在する

ことと同値である。米田の補題の証明における構成では Ψ(x)d(f) ≔ Ff(x) だったから、これは

すべての d ∈ C とすべての y ∈ Fd に対し、Ff(x) = y となる f : c → d がただ一つ存在する

と言い換えられる。そして Ff(x) = y という条件は、f が ∫F における射 (c,x) → (d,y) であることの定義そのものである。つまりこの主張は「∫F のすべての対象 (d,y) に対して、射 (c,x) → (d,y) がただ一つ存在する」と述べている。よって x ∈ Fc が普遍要素であることと (c,x) ∈ ∫F が始対象であることは同値である。□

命題2.4.9 — 表現たちのなす部分圏

表現は集合論の伝統的な意味では一意でないが、圏論的に適切な意味では一意である。

命題2.4.9. 任意の関手 F : C → Set について、∫F のうち F の表現たちが張る充満部分圏は、空であるか、可縮亜群であるかのいずれかである。

証明. F が表現可能でなければ表現は一つもなく、この部分圏は空である。そうでなければ、命題2.4.8 により F の表現は ∫F の始対象を定める。補題1.6.16（の始対象版）により、始対象たちが張る部分圏は空か可縮亜群である。すなわち、どの二つの始対象の間にもちょうど一本の（同型）射がある。□

「表現は同型を除いて一意」という系2.3.2 の主張が、ここでは「表現たちのなす圏は可縮である」という形になる。可縮亜群とは終圏 1 と圏同値な圏、明示的には空でなくどの hom にもちょうど1本の射がある圏だから、対象がいくつあっても「本質的に一点」である。

例2.4.10 — G-集合と作用亜群

左 G-集合 X : BG → Set の要素の圏は、例1.5.19 の作用亜群 X//G と同型である。BG の対象は一つだけなので ∫X の対象は X の要素 x そのもの、射 g : x → y は g·x = y を満たす群の元 g ∈ G である。すべての射が可逆だから、これは亜群になる。

例2.3.7 で見たように、X が表現可能なら X のどの要素も普遍要素として選べる。したがって「表現たちが張る充満部分圏」は ∫X 全体であり、命題2.4.9 から次が従う: X が表現可能であることと、∫X ≅ X//G が可縮亜群であることは同値。

これを使って、例2.3.7 で保留にした主張——空でない自由かつ推移的な左 G-集合は表現可能である——を証明する。G の X への作用が自由かつ推移的なら、任意の要素の組 x, y ∈ X に対し g·x = y となる g ∈ G がただ一つ存在する（推移性が存在を、自由性が一意性を与える）。これは作用亜群 X//G、すなわち要素の圏 ∫X のどの hom にもちょうど1本の射があるということである。X は空でないから、これらの圏は可縮亜群であり、X は表現可能である。

例2.4.11 — 離散力学系

例2.1.1 で導入した離散力学系——集合 X と自己写像 f : X → X と特別な要素 x0 ∈ X の組——の圏は、忘却関手 U : End → Set の要素の圏である。ここで End は自己写像を備えた集合の圏で、その射は (2.1.2) と同様の図式を可換にする関数、すなわち自己写像と可換な関数である。∫U の対象は「自己写像つきの集合と、その台集合の要素」だから、まさに離散力学系である。

この関手 U は対象 (ℕ, s : ℕ → ℕ) に表現され、その表現は普遍要素 0 ∈ ℕ で与えられる。命題2.4.8 により、例2.1.1 で観察した普遍性——(ℕ, s, 0) が普遍的な離散力学系であること、すなわち離散力学系の圏の始対象であること——が従う。

例2.4.12 — 要素の圏いろいろ

2.1・2.3 で見た表現たちを、要素の圏の言葉で読み直す。

(i) 反変冪集合関手. 対象は部分集合を選んだ集合、すなわち組 A′ ⊆ A である。射 f : (A′ ⊆ A) → (B′ ⊆ B) は関数 f : A → B であって f−1(B′) = A′ を満たすもの（反変なので引き戻しの条件）。例2.1.6(i) の表現に対応する終対象は、2元集合 Ω ≔ {⊤, ⊥} と、その中の一点部分集合 {⊤} ⊂ Ω である。これが部分集合を備えた普遍的な集合である: どんな A′ ⊆ A に対しても h−1(⊤) = A′ となる関数 h : A → Ω がただ一つ存在する（特性関数）。なお {⊤} ⊂ Ω は唯一の終対象ではない。{⊥} ⊂ Ω とも、2元集合の他のどの一点部分集合とも同型である。

脚注16 — 集合のトポスにおいて {⊤} ⊂ Ω は部分対象分類子（subobject classifier）と呼ばれる。§E.4 参照。

(ii) ベクトル空間の忘却関手. ∫U（U : Vectk → Set）の対象は、ある k-ベクトル空間 V の中のベクトル v である。射 (V,v) → (W,w) は v を w に送る線型写像 T : V → W。U を表現するベクトル空間 k と普遍要素 1 ∈ k の組は始対象を定めるが、それだけではない。零でないスカラー c ∈ k は線型同型 c·− : k → k を定めるから、c ≠ 0 なる組 (k, c) もまた始対象である。より一般に、1次元ベクトル空間 V と零でないベクトル v の組はすべて始対象を定める。

(iii) 双線型写像. ∫Bilin(V,W;−) の対象は、k-ベクトル空間 U を余域とする双線型写像 f : V × W → U である。射は線型写像 T : U → U′ であって、関数の図式

を可換にするもの、すなわち双線型写像 f′ が f と線型写像 T の合成であるようなものである。例2.3.8 で述べた普遍双線型写像 ⊗ : V × W → V ⊗k W の普遍性は、まさに ⊗ がこの圏の始対象であるという主張である。

(iv) 群の n 個の元. 関手 U(−)n : Group → Set の要素の圏の対象は、群 G と n 個の元 g1, …, gn ∈ G の組である。射 (g1,…,gn ∈ G) → (h1,…,hn ∈ H) は、すべての i について φ(gi) = hi を満たす準同型 φ : G → H である。n 個の元を備えた普遍的な群を Fn と書く。これは指定された元 x1, …, xn ∈ Fn をもち、任意の g1, …, gn ∈ G に対して φ(xi) = gi となる群準同型 φ : Fn → G がただ一つ存在する、という普遍性をもつ。n 個の生成元 x1, …, xn 上の自由群がこの性質をもつ: Fn のすべての元は xi とその逆元の積だから n 個の像 φ(xi) ∈ G が φ 全体を決め、しかも xi の間に関係式がないから G の元の選び方に制約がない。

(v) 双対ベクトル. 関手 U(−)∗ : Vectkop → Set の要素の圏の対象は、ベクトル空間とその双対ベクトルの組、すなわち余域が k の線型写像 f : V → k にほかならない。f : V → k から g : W → k への射は、f = g·T を満たす線型写像 T : V → W である。したがってこの要素の圏はスライス圏 Vectk/k と同型である（例2.4.6 のとおり）。恒等射 idk : k → k は終対象、つまり普遍的な双対ベクトルであり、零でない定数によるスカラー倍も同様である。

(vi) 環の元. ∫U（U : Ring → Set）の対象は、単位的環 R とその元 r ∈ R の組で、射は選ばれた元を保つ環準同型である。始対象は x ∈ ℤ[x] である。要素の圏において、対象 x ∈ ℤ[x] は恒等射でない自己射をもたない——始対象は決してもたない。しかし環の圏における ℤ[x] は自己射をたくさんもつ: 普遍性 Ring(ℤ[x],−) ≅ U により、写像 ℤ[x] → ℤ[x] は整数係数多項式 p(x) ∈ ℤ[x] で分類される。系2.2.8 により、U : Ring → Set の自然な自己射はすべてこの形の成分をもたねばならない。すなわち、環の忘却関手の自然な自己射の成分は、整数係数多項式 p を用いた写像 p(x) : R → R, r ↦ p(r) である。

定義2.4.13 — 離散左ファイブレーション・離散右ファイブレーション

どんな圏 E も要素の圏として現れる。一点集合を値とする定数関手 Δ∗ : E → Set を取ればよく、この関手の表現は E の始対象を定める。しかし面白い例は、いま見てきたもののように、E が別の圏 C で添字づけられた関手の要素の圏になっていて、射影関手 Π : E → C で結ばれている場合に現れる。要素の圏から出るこの射影関手には特別な性質があり、実はその性質が射影関手を特徴づけてしまう。

定義2.4.13. 関手 Π : E → C が離散左ファイブレーションであるとは、C の任意の射 f : c → c′ と、域の対象 c の任意の持ち上げ e ∈ E に対して、e を域とし f を持ち上げる E の射がただ一つ存在することをいう。双対に、Π : E → C が離散右ファイブレーションであるとは、任意の射 f : c → c′ と余域の対象 c′ の任意の持ち上げ e′ ∈ E に対して、e′ を余域とし f を持ち上げる E の射がただ一つ存在することをいう。

ここで「c の持ち上げ」とは Πe = c となる対象 e のこと、「f の持ち上げ」とは Π で f に送られる E の射のことである。左は「域を指定すれば持ち上げが一意」、右は「余域を指定すれば持ち上げが一意」と覚えられる。

この性質は持ち上げ図式で書ける。関手 Π : E → C が離散左ファイブレーションであるとは、下の実線の可換四角形が与えられたとき、両方の三角形を可換にする破線の射がただ一つ存在することをいう。関手 1 → E は E の対象の選択、関手 2 → C は C の射の選択であり、0 : 1 → 2 は 2 の対象 0（射の始点側）を選ぶ関手である。

離散右ファイブレーションの持ち上げ図式は、左辺を 1 : 1 → 2、すなわち 2 の対象 1（射の終点側）を選ぶ関手に取り替えたものである。今度は f の余域の持ち上げ e′ が与えられている。

命題2.4.14 — 要素の圏による特徴づけ

命題2.4.14. 要素の圏の構成は充満忠実関手

∫− : SetC → CAT/C, ∫− : SetCop → CAT/C

を定める。その本質的像は、共変な C-添字関手の場合には離散左ファイブレーションのなす充満部分圏であり、反変な C-添字関手の場合には離散右ファイブレーションのなす充満部分圏である。

とくに、要素の圏から出る射影関手 Π : ∫F → C は、F が共変なら離散左ファイブレーション、反変なら離散右ファイブレーションである。命題2.4.14 はさらに、この性質が要素の圏の構成から得られる関手を特徴づけると主張している。また充満忠実性により、自然変換 α : F ⇒ G は C 上の関手 ∫α : ∫F → ∫G と同一視できる。

証明. 要素の圏の構成が充満忠実関手になることは演習2.4.viii に委ね、共変関手の場合の離散左ファイブレーションによる特徴づけを示す。

まず、共変関手 F : C → Set から定まる射影 Π : ∫F → C が離散左ファイブレーションであることを見る。C の射 f : c → c′ と、その域の持ち上げ (c,x) ∈ ∫F が与えられたとする。定義2.4.1 により、域が (c,x) で f を持ち上げる射は余域が (c′, Ff(x)) でなければならず、逆にこの f : (c,x) → (c′, Ff(x)) は確かに ∫F の射である。よって持ち上げはただ一つ存在する。

逆に、Π : E → C が離散左ファイブレーションだとする。関手 F : C → Set を次のように定義する。対象 c ∈ C には、c を持ち上げる E の対象からなる集合 Fc を対応させる。射 f : c → c′ には、関数 Ff : Fc → Fc′ を、c を持ち上げる対象 e ∈ Fc を「e を域として f を持ち上げる唯一の射の余域」に送るものとして定義する。

脚注17 — 実は c 上のファイバー Ec、すなわち Π が c に送る対象と idc に送る射からなる部分圏は、離散圏である。演習2.4.ix。

この対応が関手であること、すなわち F が恒等射と合成を保つことを確かめる。どちらも「域を指定した持ち上げの一意性」から従う。射 f : c → c′ と g : c′ → c″ に対して Fg·Ff = F(g·f) を示すには、c を持ち上げる対象 e で両辺の値が一致することを見ればよい。右辺は e を、e を域として g·f を持ち上げる唯一の射の余域に送る。左辺は e をまず、e を域として f を持ち上げる唯一の射の余域 Ff(e) に送り、次に Ff(e) を域として g を持ち上げる唯一の射の余域に送る。この二つの射を E で合成したものは e を域とする g·f の持ち上げだから、一意性によりさきほどの射と同じものであり、余域 F(g·f)(e) と Fg(Ff(e)) は等しい。恒等射の場合も同様、というよりもっと易しい。

こうして離散左ファイブレーション Π : E → C から関手 F : C → Set が構成できた。この F の要素の圏を取ると、また離散左ファイブレーション Π : ∫F → C が得られ、各 c ∈ C 上の対象は構成から E の c 上の対象と同型である。両者の射は「C 上の離散左ファイブレーションの域である」という事実から一意に決まるので、C 上で E ≅ ∫F である。□

節の締め — 次章への問い

普遍性による定義は、これから先の章で重要な主題として繰り返し現れる。その予告として、次の問いを置いておく。局所小な圏 C の二つの対象 A, B を固定し、関手

C(A,−) × C(B,−) : C → Set

を定義する。これは対象 X を、集合 C(A,X) × C(B,X)——射 a : A → X と b : B → X の組全体——に送る。この関手が表現可能であるとは、どういうことだろうか。
