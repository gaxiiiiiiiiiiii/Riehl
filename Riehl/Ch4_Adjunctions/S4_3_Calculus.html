節の導入

節の冒頭には J. Peter May の論文「Picard groups, Grothendieck rings, and Burnside rings of categories」からの引用が置かれている。圏論的代数の目的はおそらく、形式的なものが形式的に形式的であると示すことである、という一節である。

この節は、随伴関手についての基本的な計算規則を導入する。示すのは次の 4 つである。随伴は一意な自然同型を除いて一意である。随伴は合成でき、ひげ付けできる。任意の圏同値は随伴同値に取り替えることができ、そのとき互いに逆な圏同値は、左右どちらの向きにも随伴になる。さらに、随伴による転置を、個々の射から自然変換へ拡張する。この拡張で対応する一対の自然変換をメイト（mates）という。

これらの結果には、どれも複数の流儀の証明がある。§4.1 の定義から出発する証明と、§4.2 の定義から出発する証明である。§4.1 の定義は米田の補題を使う議論によく合う。§4.2 の定義による証明は、圏のなす 2-圏の内部での図式による推論になる。つまり、対象である圏、射である関手、射の間の射である自然変換と、§1.7 で述べた水平合成と垂直合成だけを使って、構文的に証明できる。本書の関心は結果と同じだけ証明の技法にもあるので、両方の流儀の証明を与える。どちらの流儀の推論も、より一般的な状況に移せる。この節の結果は「形式的圏論」（formal category theory）の一部と見るのがよい。

命題4.3.1 — 随伴の一意性

命題4.3.1. F と F′ がともに G の左随伴ならば F ≅ F′ である。さらに、自然同型 θ : F ≅ F′ であって、2 つの随伴の単位および余単位と可換なもの、すなわち次の 2 つの三角形を可換にするものが、ただ 1 つ存在する。

命題4.3.3 — 随伴の合成

命題4.3.3. 随伴 F ⊣ G（F : C ⇄ D : G）と F′ ⊣ G′（F′ : D ⇄ E : G′）が与えられたとき、合成 F′F は合成 GG′ の左随伴である。

証明 1. 自然同型

E(F′Fc, e) ≅ D(Fc, G′e) ≅ C(c, GG′e)

がある。1 つ目は F′ ⊣ G′ で定義され、2 つ目は F ⊣ G で定義される。□

証明 2. F ⊣ G の単位と余単位を η, ε、F′ ⊣ G′ の単位と余単位を η′, ε′ と書く。この 2 つの随伴のデータから定義できる F′F ⊣ GG′ の単位と余単位として、自然なものは次だけである。

この 2 つは、恒等射 1F′Fc と 1GG′e を証明 1 の自然同型で送って得られる自然変換と一致する。たとえば 1F′Fc は、1 つ目の同型で η′Fc : Fc → G′F′Fc に送られ、2 つ目の同型で G(η′Fc) ∘ ηc に送られる。三角等式の証明は図式を追う計算で、本文は読者に委ねている（演習4.3.i）。□

命題4.3.4 — 三角等式の合成が可逆な場合

命題4.3.4. 向かい合う関手 F : C ⇄ D : G と自然変換 η : idC ⇒ GF, ε : FG ⇒ idD について、三角等式の左辺にあたる 2 つの合成

φ ≔ εF ⋅ Fη : F ⇒ FGF ⇒ F　　ψ ≔ Gε ⋅ ηG : G ⇒ GFG ⇒ G

がどちらも可逆であるとする。このとき F ⊣ G であり、η を単位に選ぶことも、ε を余単位に選ぶこともできる。

三角等式は φ = 1F と ψ = 1G を要求する。この命題の仮定はそれより弱く、φ と ψ が同型であることだけである。結論では、η を単位に選んだときの余単位は ε とは限らず、ε を余単位に選んだときの単位は η とは限らない。

証明 1. 自然変換 η と ε は、式 (4.2.8) と (4.2.9) により、次の図式の実線の写像を定める。どれも c と d について自然である。

左から上への実線と下から右への実線は、f : Fc → d を Gf ∘ ηc に送る写像 (4.2.8) である。上から下への実線は、g : c → Gd を εd ∘ Fg に送る写像 (4.2.9) である。

破線は、隣り合う 2 本の実線の合成である。米田の補題により、合成 D(Fc, d) → D(Fc, d) は、ある自然変換 φ : F ⇒ F の成分を前に合成する写像で、合成 C(c, Gd) → C(c, Gd) は、ある自然変換 ψ : G ⇒ G の成分を後ろに合成する写像である。その成分は、恒等射 1Fc と 1Gd の像である。この像は、主張の φ と ψ の成分に一致する。実際、ε の自然性と η の自然性から

εd ∘ F(Gf ∘ ηc) = εd ∘ FGf ∘ Fηc = f ∘ εFc ∘ Fηc = f ∘ φc

G(εd ∘ Fg) ∘ ηc = Gεd ∘ GFg ∘ ηc = Gεd ∘ ηGd ∘ g = ψd ∘ g

である。図式 (4.3.5) の破線に (φc)∗ と (ψd)∗ と書いたのはこのためである。

仮定により φ と ψ は自然同型だから、2 本の破線の写像は可逆である。同型の「2-of-6 性質」は、合成できる 3 本の射 f, g, h について、gf と hg が同型ならば f, g, h と hgf がすべて同型である、という性質である6。これを 3 本の実線に使うと、3 本の実線と点線はすべて自然同型である。したがって、定理4.2.7(iii) により η から、定理4.2.7(iv) により ε から、随伴 F ⊣ G のデータが定まる。□

6 補題6.4.2 を見よ。補題1.2.11 と演習1.2.vi を使って直接証明することもできる。gf が同型ならば g は右逆を持ち、hg が同型ならば g は左逆を持つので、g は同型である。すると f = g−1 ∘ gf と h = hg ∘ g−1 も同型である。

証明 2. 同型 ψ−1 を ε か η のどちらかに吸収させて定義し直す。どちらに吸収させても同じように進むので、ε のほうを取り替える。取り替えた後の一対の自然変換が、随伴 F ⊣ G の単位と余単位になることを示す。

ε′ ≔ ε ⋅ Fψ−1 : FG ⇒ FG ⇒ idD と置く。まず、次の図式が可換である。

左の四角形は η の自然性である。射 ψ−1d : Gd → Gd に η の自然性を使うと GF(ψ−1d) ∘ ηGd = ηGd ∘ ψ−1d である。右の三角形は ψ の定義 ψ = Gε ⋅ ηG である。上段の合成は Gε ⋅ GFψ−1 ⋅ ηG = Gε′ ⋅ ηG で、下を回る合成は ψ ⋅ ψ−1 = 1G である。これで三角等式の 1 つ Gε′ ⋅ ηG = 1G が示された。

次に、次の図式が可換である。

4 つの部分がそれぞれ可換である。

  • 左上の四角形 FGFη ⋅ Fη = FηGF ⋅ Fη は、η の自然性を射 ηc : c → GFc に使った等式 GF(ηc) ∘ ηc = ηGFc ∘ ηc に F を適用したものである。
  • 右上の四角形 Fη ⋅ εF = εFGF ⋅ FGFη は、ε の自然性を射 F(ηc) : Fc → FGFc に使ったものである。
  • 右下の四角形 ε′F ⋅ εFGF = εF ⋅ FGε′F は、ε の自然性を射 ε′Fc : FGFc → Fc に使ったものである。
  • 左下の三角形 FGε′F ⋅ FηGF = 1FGF は、すでに示した三角等式 Gε′ ⋅ ηG = 1G の d = Fc での成分に F を適用したものである。

上段と右列をたどる合成は ε′F ⋅ Fη ⋅ εF ⋅ Fη = ε′F ⋅ Fη ⋅ φ である。左列、斜めの恒等変換、下段をたどる合成は εF ⋅ Fη = φ である。図式が可換だから ε′F ⋅ Fη ⋅ φ = φ で、同型 φ を消去すると ε′F ⋅ Fη = 1F である。これがもう 1 つの三角等式である。□

系4.3.6 — 随伴同値

命題4.3.4 の仮定が満たされる状況の 1 つは、η と ε がどちらも自然同型である場合である。

系4.3.6. 任意の圏同値

F : C ⇄ D : G　　η : idC ≅ GF　　ε : FG ≅ idD

は、自然同型が三角等式を満たす随伴同値（adjoint equivalence）に取り替えることができる。そのためには、最初に指定された自然同型のどちらか一方を、新しい単位または余単位に置き換えればよい。

η と ε が自然同型ならば φ = εF ⋅ Fη と ψ = Gε ⋅ ηG も自然同型だから、命題4.3.4 が使える。命題4.3.4 の証明 2 で作った ε′ = ε ⋅ Fψ−1 は、自然同型の合成だから自然同型である。

圏同値の定義は対称的で、η の代わりに ε−1 を、ε の代わりに η−1 を使うと、F と G の役割が入れ替わる。このことから、圏同値 F : C → D は左随伴とも右随伴とも見なせる。実際、F の逆にあたる圏同値 G : D → C をどう選んでも、G は F の左随伴であり、右随伴でもある。

命題4.3.7 — 関手圏の間の随伴

命題4.3.7. 随伴 F ⊣ G（F : C ⇄ D : G）が与えられたとき、任意の小圏 J について、F と G を後ろに合成する関手は随伴関手の対

F∗ : CJ ⇄ DJ : G∗　　F∗ ⊣ G∗

をなす。また、任意の局所小圏 E について、F と G を前に合成する関手も随伴

G∗ : EC ⇄ ED : F∗　　G∗ ⊣ F∗

をなす7。

後ろに合成する場合は F∗ が左随伴のままである。前に合成する場合は左右が入れ替わり、G∗ が左随伴になる。

7 C と D が小圏でなければ、これらの関手圏は局所小とは限らない。関手圏が局所小であることを気にしないなら、J が小圏であるという仮定は外せる。

この節のほかの結果と同じく、定義4.1.1 からも定義4.2.5 からも証明できる。本文はその詳細を節末問題に回し、代わりに 3 つ目の証明の概略を述べる。

証明の概略. 定義4.2.5 から、随伴は定義1.7.8 の 2-圏 CAT の内部で定義できることが分かる。随伴は、一対の対象、一対の 1-射、一対の 2-射であって、ある合成の関係を満たすものからなる。2-関手（2-functor）とは 2-圏の間の射で、対象、1-射、2-射の対応であって、すべての階層で合成と恒等射を保つものである。関手は可換図式を保つという補題1.6.5 には 2 次元版があり、2-関手は「2 次元の図式」を保つ。随伴はその一例である。大きさの問題を無視すれば、命題4.3.7 は、任意の小圏 J と局所小圏 E について

(−)J : CAT → CAT　　E(−) : Catop → CAT

が 2-関手であるという事実からただちに従う。E(−) は 1-射の向きを逆にするので、前に合成する場合は左右が入れ替わる。□

命題4.3.8 — メイト

Remark 4.3.9 — 2 つの流儀の証明の適用範囲

Remark 4.3.9. 命題4.3.1、4.3.3、4.3.4、4.3.7、4.3.8 と系4.3.6 の「構文的な」証明は、Cat の代わりに任意の 2-圏の内部で定義された随伴に、そのまま当てはまる。

このことは、Cat にしか当てはまらない「米田流の」証明よりも、構文的な証明を選ぶ理由になりそうに見える。しかし §3.5 と同様の議論を使えば、米田流の証明も Cat から一般の 2-圏へ持ち上げられる。一般の圏の極限と余極限が、Set の極限によって表現可能性を通じて定義されるのと同じように、2-圏の中の随伴と圏同値も、米田の補題により、Cat の中の随伴と圏同値によって表現可能性を通じて定義される。この推論は、§2.3 の冒頭で触れた圏論研究者の冗談「すべての定理は米田である」を裏づけている。

節末問題

  • 4.3.i — 三角等式を確かめて、命題4.3.3 の 2 つ目の証明を完成させよ。
  • 4.3.ii — 随伴の単位と余単位を使って、命題4.3.7 を証明せよ。
  • 4.3.iii — hom 集合の間の自然な全単射を使って、命題4.3.7 の前半、すなわち随伴 F ⊣ G が後ろに合成することで随伴 F∗ ⊣ G∗ を誘導することを証明せよ。演習3.2.v が役に立つかもしれない。
  • 4.3.iv — 命題4.3.1 の自然同型 θ を、一対の随伴 F ⊣ G と F′ ⊣ G′ に関する 1G のメイトとして解釈し直せ。
  • 4.3.v — 左随伴の間の自然変換が同型であることと、その共役である右随伴の間の自然変換が同型であることが、同値であることを示せ。また、自然同型のメイトが同型とは限らないことを示す例を見つけよ。
  • 4.3.vi — メイトの対応が、次の 2 つと可換であることを示せ。
    1. 関手の水平合成と、四角形の水平な貼り合わせ。
    2. 随伴の垂直合成と、四角形の垂直な貼り合わせ。
  • 4.3.vii — 演習4.3.vi の結果を演習3.6.v の設定で解釈せよ。すなわち、対象が圏、水平な射が関手、垂直な射が随伴、四角形がメイトの対である二重圏（double category）があることを示せ9。

9 別の解釈もできる。演習4.3.vi の結果は、対象、水平な射、垂直な射が同じである一対の二重圏の間の同型を定める。一方の二重圏の四角形は α♯ の形の自然変換で、もう一方の二重圏の四角形は α♭ の形の自然変換である [KS74, 2.2]。
