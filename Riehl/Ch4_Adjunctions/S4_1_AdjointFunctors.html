第4章の導入 — 自由構成と随伴

ベクトル空間は、集合にベクトルの加法 v + w と、体 𝕜 の各スカラー k による乗法 k ⋅ v を与え、いくつかの公理を課したものである。ベクトル空間からその台集合への対応は関手的で、線形写像をその台となる写像に送る忘却関手 U : Vect𝕜 → Set がある。

逆向きに、集合 S からベクトル空間を作ることを考える。S をそのままベクトルの集合にすることは、濃度の制約で不可能なことがあり、可能でも S に加法を自然に定める方法がない。自然なのは、S の要素を基底にすることである。ベクトルは有限な形式和

k1 ⋅ s1 + ⋯ + kn ⋅ sn　（ki ∈ 𝕜, si ∈ S, n ≥ 0）

である1。こうして得られる、次元が S の濃度に等しいベクトル空間 𝕜[S] を、集合 S 上の自由ベクトル空間と呼ぶ。この構成は関手 𝕜[−] : Set → Vect𝕜 を定める。写像 f : S → T は、基底の要素を f で送ることで線形写像 𝕜[f] : 𝕜[S] → 𝕜[T] を誘導する。

自由構成は数学の至るところにある。集合上の自由群と自由アーベル群、集合上またはアーベル群上の自由環、アーベル群上の自由加群、箙上の自由圏などである。普遍的な構成の候補が競合することもある。集合上の自由箙は、頂点の各順序対の間に矢を 1 本持つべきか、持たないべきか。集合上の自由位相空間は、開集合をできるだけ多く持つべきか、少なく持つべきか。候補がないこともある。「自由体」は存在しない。これらすべてを整理する概念が、Kan の導入した随伴である。

自由ベクトル空間関手 𝕜[−] : Set → Vect𝕜 の普遍性は、それが忘却関手 U : Vect𝕜 → Set の左随伴であることとして述べられる。すなわち、線形写像 𝕜[S] → V は写像 S → U(V) と自然に対応する。線形写像は基底 S ⊂ 𝕜[S] の行き先で決まるからである。米田の補題により、この普遍性から 𝕜[−] の射への作用を定めることもできる。忘却関手 U : Vect𝕜 → Set は右随伴を持たないので、ここでは自由構成の候補は競合しない2。

この章では随伴関手の一般論を、抽象的に、また多くの例を通して調べる。随伴の同値な 2 つの定義を §4.1 と §4.2 で与える。§4.3 では随伴の基本的な計算法則を、米田の補題を使う証明と、圏の 2-圏の中での証明の 2 通りで示す。§4.4 では反変関手の対の間の随伴と、n 変数関手の (n + 1) 個組の間の随伴を扱う。2 変数の随伴は、Kan が観察したテンソル積と hom の双対性を表す。§4.5 では、右随伴関手は極限を保ち、左随伴関手は余極限を保つことを示す。多くの忘却関手が右随伴であることが、極限が余極限より作りやすい理由である。§4.6 では、X × Y → Z と X → ZY が自然に対応するというカルテシアン閉の性質を、各スライス圏 C/X で持つ圏を調べる。§4.7 では、関手が随伴を持つための十分条件を与える。

1 有限な形式和とは、正確には有限台の関数 φ : S → 𝕜 のことで、式 Σs∈S φ(s)s に対応する。項の並べ替え、同じ項の係数の足し合わせによる統合、係数 0 の項の追加と削除で移り合う形式和は同一視される。

2 忘却関手の右随伴は、余自由（cofree）構成と呼ばれることがある。

定義4.1.1 — 随伴 I

随伴とは、向かい合う一対の関手 F : C ⇄ D : G であって、特別な関係にあるものである。関係の内容は、Fc から d への射と c から Gd への射が自然に 1 対 1 に対応する、ということである。

定義4.1.1（随伴 I）. 随伴とは、一対の関手 F : C → D と G : D → C に、各 c ∈ C と d ∈ D について指定された同型

(4.1.2)　D(Fc, d) ≅ C(c, Gd)

であって両変数について自然なものを添えたものである。このとき F は G の左随伴、G は F の右随伴であるという。全単射 (4.1.2) で対応する射どうしを、互いの転置（transpose）、または随伴する射（adjunct）という3。

転置の記法として、左随伴の像を始域とする射 Fc → d に ♯ を、右随伴の像を終域とする射 c → Gd に ♭ を付ける。f♯ : Fc → d の転置が f♭ : c → Gd である。

3 当面は転置の対を (−)♯ と (−)♭ で区別するが、実際には (−)† や (−)̂ のような 1 つの記号で、対のどちらを飾るかを決めずに転置を表すのが便利なことが多い。

自然性の内容

定義4.1.1 の自然性は、同型 (4.1.2) の族が、hom 双関手を制限した 2 つの関手 Cop × D → SET の間の自然同型をなすことをいう。値は、hom 集合が大きくなりうるので SET に取る。

D についての自然性. D の任意の射 k : d → d′ について、左の hom 集合の四角形が SET で可換である。

四角形の可換性を射の言葉にすると次になる。任意の f♯ : Fc → d と k : d → d′ について、合成 k ∘ f♯ : Fc → d′ の転置は、f♭ : c → Gd と Gk : Gd → Gd′ の合成である。

(k ∘ f♯)♭ = Gk ∘ f♭

C についての自然性. 双対に、C の任意の射 h : c′ → c について、左の四角形が SET で可換である。

射の言葉では、f♯ ∘ Fh : Fc′ → d の転置は、h : c′ → c と f♭ : c → Gd の合成である。

(f♯ ∘ Fh)♭ = f♭ ∘ h

補題4.1.3 — 自然性と転置した四角形

自然性は、2 つの等式で述べるよりも、1 つの四角形の可換性がその転置した四角形の可換性と同値である、という形で使うほうが便利なことが多い。

補題4.1.3. 一対の関手 F : C ⇄ D : G と、すべての c ∈ C, d ∈ D について指定された同型 D(Fc, d) ≅ C(c, Gd) を考える。この同型の族が自然であることは、次と同値である。始域と終域が下のとおりの任意の射について、

(4.1.4)

左の四角形が D で可換であることと、右の転置した四角形が C で可換であることが同値である。

証明は演習4.1.i とする。左の四角形の縦の射は、左側が左随伴 F の像、右側が任意の射 k である。転置すると、左側は任意の射 h、右側は右随伴 G の像 Gk になる。横の射は互いの転置である。

記法4.1.5 — 記号 ⊣

記法4.1.5. Kan に従い、向かい合う一対の関手が随伴であることを記号 ⊣ で表す。F ⊣ G、G ⊢ F、および次の図はいずれも、F : C → D が G : D → C の左随伴であることを主張する。

この記法の便利さは、複数の随伴関手が関わる場面で現れる。

例4.1.6 — 離散位相と密着位相

忘却関手 U : Top → Set は左随伴と右随伴を両方持つ。

左随伴は、集合 S から位相空間を作り、その空間から他の空間 T への連続写像が写像 S → U(T) と自然に全単射で対応するようにするものである。S 上の離散位相がこの普遍性を持つ。離散空間を D(S) と書くと、任意の写像 S → U(T) は連続写像 D(S) → T を定める。

右随伴は、集合 S から位相空間を作り、T からその空間への連続写像が写像 U(T) → S と自然に全単射で対応するようにするものである。S 上の密着位相がこの普遍性を持つ。密着空間を I(S) と書くと、任意の写像 U(T) → S は連続写像 T → I(S) を定める。自然同型

Top(D(S), T) ≅ Set(S, U(T))　と　Set(U(T), S) ≅ Top(T, I(S))

は、離散、忘却、密着の 3 つの関手が一対の随伴をなすことを主張する。

3 つの関手 F, G, H が一対の随伴 F ⊣ G と G ⊣ H を定めるとき、このデータをまとめて随伴三つ組（adjoint triple）と呼ぶ。

ガロア接続と例4.1.7–4.1.9

前順序集合の間の随伴を（単調）ガロア接続（Galois connection）と呼ぶ。演習1.3.ii で見たように、前順序集合 A, B の間の関手 F : A → B, G : B → A は順序を保つ写像にほかならない。随伴 F ⊣ G は、すべての a ∈ A と b ∈ B について

Fa ≤ b　⇔　a ≤ Gb

が成り立つことを主張する。この文脈では F を下随伴（lower adjoint）、G を上随伴（upper adjoint）と呼ぶ。hom 集合は空か 1 点なので、全単射 (4.1.2) は両辺の真偽が一致することに尽き、自然性は自動的に成り立つ。

例4.1.7. 通常の順序 ≤ を持つ半順序集合の包含 ℤ ↪ ℝ は、左随伴と右随伴を両方持つ。それぞれ天井関数と床関数である。

整数 n と実数 r について、n ≤ r ⇔ n ≤ ⌊r⌋ である。ここで ⌊r⌋ は r 以下の最大の整数である。この関数は順序を保ち、包含 ℤ ↪ ℝ の右随伴である関手 ⌊−⌋ : ℝ → ℤ を定める。双対に、r ≤ n ⇔ ⌈r⌉ ≤ n である。ここで ⌈r⌉ は r 以上の最小の整数である。この関数は包含の左随伴である関手 ⌈−⌉ : ℝ → ℤ を定める。こうして随伴三つ組 ⌈−⌉ ⊣ (ℤ ↪ ℝ) ⊣ ⌊−⌋ が得られる。

例4.1.8. 集合の間の写像 f : A → B を考える。A の部分集合全体と B の部分集合全体は包含で順序づけられた半順序集合 PA, PB をなす。f は順像関手 f∗ : PA → PB と逆像関手 f−1 : PB → PA を誘導し、逆像は順像の右随伴である。すなわち A′ ⊂ A と B′ ⊂ B について f(A′) ⊂ B′ ⇔ A′ ⊂ f−1(B′) である。

逆像関手はさらに右随伴 f! を持つ。f! は部分集合 A′ ⊂ A を、ファイバーが A′ に丸ごと含まれる B の要素の集合に送る。この定義で B′ ⊂ f!(A′) ⇔ f−1(B′) ⊂ A′ が成り立つ。これらは随伴三つ組 f∗ ⊣ f−1 ⊣ f! を定める。

例4.1.9. 述語（predicate）または命題関数とは、真理値の集合 Ω ≔ {⊥, ⊤} への関数 p : X → Ω である。述語は、自由変数 x ∈ X を含み X の各要素で真偽の定まる論理式と考えられる。ΩX は X 上の述語の集合である。Ω には論理的含意で定まる半順序 ⊥ ≤ ⊤ を入れ、ΩX には点ごとの順序を入れる。p ≤ q とは、すべての x ∈ X について p(x) ≤ q(x)、すなわちすべての x について p(x) が q(x) を含意することである。

全称量化と存在量化は関手 ∀X, ∃X : ΩX ⇉ Ω を定める。∀X p = ⊤ ⇔ すべての x ∈ X で p(x) = ⊤、∃X p = ⊤ ⇔ ある x ∈ X で p(x) = ⊤ である。定数関手 ΔX : Ω → ΩX もあり、これらは随伴三つ組 ∃X ⊣ ΔX ⊣ ∀X を定める。実際、ΩX と P(X) の圏同値を介して、この随伴三つ組は例4.1.8 を写像 ! : X → ∗ に適用した特別な場合である。

例4.1.10 — 自由 ⊣ 忘却

大きく重要な随伴の族として、「自由 ⊣ 忘却」の形の随伴 F : S ⇄ A : U がある。忘却関手 U : A → S が右随伴、自由関手 F が左随伴である。S の対象の上に A の型の普遍的な対象を構成でき、その構成が忘却関手 U : A → S の左随伴を定めるとき、この関係を表すために「普遍的」の代わりに「自由」という語を使う。忘却関手の左随伴が右随伴より多く現れるのは、実際に出会う普遍性の向きによる。忘却関手の右随伴を定める「余自由」構成は比較的少ない。

次の忘却関手は左随伴を持ち、「自由」構成を定める。

  1. U : Set∗ → Set。左随伴は集合 X を、基点を自由に添えた点つき集合 X+ ≔ X ⊔ {X} に送る。
  2. U : Monoid → Set。集合 X 上の自由モノイドは、空リストを含む X の要素の有限リストの集合 ∐n≥0 X×n である。
  3. U : Ring → Ab。乗法の構造を忘れる。アーベル群 A 上の自由環は ⨁n≥0 A⊗n である。演習5.1.i は (ii) と (iii) の関係を調べる。定義1.6.3 で見たように、環はアーベル群の圏のモノイドである。
  4. U : Ab → Set。集合 X 上の自由アーベル群は、X の要素の整数係数の有限な形式和の集合 ℤ[X] ≔ ⨁X ℤ である。
  5. U : RMod → Set。集合 X 上の自由 R-加群は R[X] ≔ ⨁X R である。特別な場合が集合上の自由 𝕜-ベクトル空間で、章の導入で考えた U : Vect𝕜 → Set の左随伴を定める。
  6. U : Ring → Set。忘却関手の左随伴どうしを合成して（命題4.3.3）、集合 X 上の自由環は、集合上の自由アーベル群の上の自由モノイド ⨁n≥0 (⨁X ℤ)⊗n である。
  7. U : CRing → Set。集合 X 上の自由可換環は、X の要素を変数とする整数係数の多項式の環である。
  8. (−)× : Ring → Group。環をその単元群に送る。群 G 上の自由環は群環 ℤ[G] = ⨁G ℤ で、要素は群の要素の有限な形式和、乗法は群演算を双線形に延ばしたものである。
  9. U : Group → Set。集合上の自由群は例4.2.4 と例4.7.6 で詳しく述べる。
  10. I : Ab ↪ CMonoid。アーベル群の、可換モノイドの圏への包含。左随伴 Gr は可換モノイド (M, +, 0) をその群完備化、またはグロタンディーク群に送る。集合としては Gr(M, +, 0) は M × M を、ある c ∈ M について a + b′ + c = a′ + b + c となるとき (a, b) ≃ (a′, b′) とする関係で割った商である。
  11. I : Group ↪ Monoid。左随伴はモノイドの「群完備化」を、その台集合上の自由群を、モノイドの乗法と単位から生じる関係で割った商として構成する。
  12. 環準同型 φ : R → S に付随する係数制限関手 φ∗ : SMod → RMod。左随伴 S ⊗R − : RMod → SMod を係数拡大と呼ぶ。
  13. U : RMod → Ab。スカラー倍を忘れる。唯一の単位的環準同型 ! : ℤ → R が誘導する、前の例の特別な場合である。
  14. φ∗ : SetBG → SetBH。群準同型 φ : H → G に付随する関手 φ : BH → BG が誘導する、もう 1 つの係数制限関手。左随伴は誘導（induction）とも呼ばれ、(xii) と同様に記述できる。

これらの自由 ⊣ 忘却随伴はいずれもモナド的随伴の例である。モナド的随伴は §5.5 の主題である。

例4.1.11 — フロベニウス相互律

例4.1.11（フロベニウス相互律）. 例4.1.10(xiv) は一般化できる。例6.2.11 は、完備かつ余完備な任意の圏 C と任意の群準同型 φ : H → G について、制限関手 φ∗ : CBG → CBH が左随伴と右随伴を両方持つことを示す。

最もよく考えられるのは部分群の包含 H ⊂ G の場合で、このとき左随伴を誘導（induction）indGH、右随伴を余誘導（coinduction）coindGH と呼ぶ。C を Vect𝕜 に取ると、H-表現の圏 Vect𝕜BH と G-表現の圏 Vect𝕜BG の間の随伴 indGH ⊣ resGH は、表現論の文献でフロベニウス相互律と呼ばれる。

例4.1.12 — 体の忘却関手は随伴を持たない

例4.1.12. 体の代数的構造を忘れる関手

U : Field → Ring,　U : Field → Ab,　(−)× : Field → Ab,　U : Field → Set

はどれも左随伴も右随伴も持たない。

左随伴が存在しないことは次のように分かる。これらの終域の圏には、ℤ から任意の標数の体への射がある。標数の異なる体の間に体の準同型はないので、左随伴があるとしてその ℤ での値を定めることができない。同様の議論で右随伴も存在しないことが示せる。

例4.1.13 — 箙上の自由圏

例4.1.13. 忘却関手 U : Cat → Quiver は左随伴 F を持ち、箙上の自由圏を定める。

箙 Q は、頂点の集合 V、矢の集合 A、各矢の始点と終点を定める 2 つの関数 s, t : A ⇉ V からなる。Q 上の自由圏は V を対象の集合とし、射は矢の有限な有向道で、長さ 0 の道が恒等射である。合成は道の連結である。

随伴は、関手 F(Q) → C と箙の射 Q → U(C) の間の自然な全単射を与える。関手 F(Q) → C、あるいは同じことだが箙の射 Q → U(C) は、C の中の可換性の条件のない図式を定める。箙は合成を持たないからである。そのような図式のデータは、Q の頂点と矢の像で一意に決まる。これらの矢は圏 F(Q) の中で、自明でない分解を持たない原子的な射である。たとえば例1.1.4(iv) で述べたように、圏 ω は、自然数で添字づけられた頂点と各 n ∈ ω についての辺 n → n + 1 を持つ箙の上の自由圏である。随伴により、ω で添字づけられた図式は、順序数からその後続への原子的な矢の像だけを指定すれば定まる。

例4.1.14 — 順序数の圏の間の随伴の列

例4.1.14. n ≥ 0 について、箙 0 → 1 → 2 → ⋯ → n が自由に生成する順序数の圏を 𝕟 + 𝟙 と書く。0 ≤ i ≤ n について、i ∈ 𝕟 + 𝟙 だけが像に入らない単射的な関手 di : 𝕟 → 𝕟 + 𝟙 がある。0 ≤ i < n について、i ∈ 𝕟 だけが 2 つの逆像を持つ全射的な関手 si : 𝕟 + 𝟙 → 𝕟 がある。これらは 2n + 1 個の随伴の列

dn ⊣ sn−1 ⊣ dn−1 ⊣ sn−2 ⊣ ⋯ ⊣ s0 ⊣ d0

をなす。したがって、任意の有限の長さの随伴関手の列が存在する。𝕟 と 𝕟 + 𝟙 は半順序集合なので、各随伴はガロア接続 di(a) ≤ b ⇔ a ≤ si−1(b) などとして確かめられる。

例4.1.15 — 亜群の圏の包含

例4.1.15. 包含 Groupoid ↪ Cat は左随伴と右随伴を両方持つ。

右随伴は圏をその極大部分亜群（補題1.1.14）に送る。関手は同型を保つので、亜群 G を始域とする関手 G → C の像は、C の極大部分亜群を必ず一意に通る。

左随伴は圏の射を「形式的に可逆にする」もので、対応する category of fractions を構成する。C の category of fractions は、C の台となる箙と Cop の台となる箙を共通の離散部分圏 ob C に沿って貼り合わせた箙の上の自由圏の商として構成できる。対象は C の対象で、射は C の射の有限なジグザグ（向きが交互する射の列）である。ジグザグには関係を課し、たとえば a →f b と b ←f a を続けたジグザグ a → b ← a、および b ← a → b を恒等射と同一視する。詳しくは [Bor94a, §5.2] にある。
