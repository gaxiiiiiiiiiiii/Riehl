Emily Riehl, Category Theory in Context §4.2（pp.139–144）の内容を、個人学習のために日本語で書き直した解説。番号（補題4.2.2 など）は本と揃えてある。翻訳ではなく、同じ内容を自分の言葉で再構成したもの。

節の導入 — 恒等射の転置

節の冒頭には Mac Lane『圏論の基礎』からの引用が置かれている。普遍的な構成は数学の至るところに、与えられた関手への普遍射として、与えられた関手からの普遍射として、あるいは集合値関手の普遍元として、さまざまな姿で現れる、という一節である。

随伴は、向かい合う一対の関手 F : C ⇄ D : G と、指定された自然同型

(4.2.1)　D(Fc, d) ≅ C(c, Gd)

からなるのであった。c ∈ C を固定すると、(4.2.1) は対象 Fc ∈ D が関手 C(c, G−) : D → Set を表現することを述べている。米田の補題により、自然同型 D(Fc, −) ≅ C(c, G−) は集合 C(c, GFc) の 1 つの元で決まる。その元は、d = Fc での同型 D(Fc, Fc) ≅ C(c, GFc) で恒等射 1Fc が対応する先、すなわち 1Fc の転置である。これを ηc : c → GFc と書く。転置の自然性から、射 ηc の族は自然変換 η : idC ⇒ GF の成分になる。これが補題4.2.2 である。

補題4.2.2 — 単位

補題4.2.2. 随伴 F ⊣ G が与えられたとき、c での成分 ηc : c → GFc を恒等射 1Fc の転置と定めると、自然変換 η : idC ⇒ GF が得られる。これを随伴の単位（unit）という。

証明. η が自然であるとは、C の任意の射 f : c → c′ について、下の左の四角形が可換であることである。

補題4.1.3 は、D の四角形 k ∘ f♯ = g♯ ∘ Fh が可換であることと、各辺のうち Fc → d の形の 2 本を転置に置き換えた C の四角形 Gk ∘ f♭ = g♭ ∘ h が可換であることが同値である、と述べていた。左の四角形は、C の四角形として h = f、f♭ = ηc、g♭ = ηc′、Gk = GFf の場合にあたる。ηc は 1Fc の転置、ηc′ は 1Fc′ の転置で、k = Ff だから、対応する D の四角形は右の四角形である。右の四角形は、どちらの回り方でも Ff になるので可換である。したがって補題4.1.3 により左の四角形も可換である。□

補題4.2.3 — 余単位

双対に、d ∈ D を固定すると、(4.2.1) は対象 Gd ∈ C が関手 D(F−, d) : Cop → Set を表現することを述べている。米田の補題により、自然同型 C(−, Gd) ≅ D(F−, d) は集合 D(FGd, d) の 1 つの元で決まる。その元は恒等射 1Gd の転置で、これを εd : FGd → d と書く。補題4.2.2 の双対により、射 εd の族は自然変換になる。

補題4.2.3. 随伴 F ⊣ G が与えられたとき、d での成分 εd : FGd → d を恒等射 1Gd の転置と定めると、自然変換 ε : FG ⇒ idD が得られる。これを随伴の余単位（counit）という。

証明は補題4.2.2 の双対である。D の射 k : d → d′ について、ε の自然性の四角形 k ∘ εd = εd′ ∘ FGk は D の四角形であり、これを転置した C の四角形は、上辺と下辺が恒等射 1Gd, 1Gd′、縦の射がどちらも Gk の四角形で、可換である。

例4.2.4 — 自由群の単位と余単位

例4.2.4. 忘却関手 U : Group → Set の左随伴 F は、集合 S 上の自由群を与える。

群 F(S) の元は、S の元 s と形式的な逆元 s−1 を「文字」とする有限な「語」を、ある関係で割ったものである。空の語が単位元で、積は語の連結である。関係は、特に s s−1 と s−1 s を空の語と同一視する。

単位の、集合 S での成分は、元 s ∈ S を 1 文字の語 s に送る写像 ηS : S → UF(S) である。余単位の、群 G での成分は、G の元とその形式的な逆元を文字とする語を、G の積・逆元・単位元で解釈して得られる積に送る群準同型 εG : FU(G) → G である5。

定義2.3.3 の用語でいえば、単位と余単位の成分は、次の自然同型を特徴づける普遍元である。

Group(F(S), −) ≅ Set(S, U(−))　↭　ηS ∈ Set(S, UF(S))

Set(−, U(G)) ≅ Group(F(−), G)　↭　εG ∈ Group(FU(G), G)

命題2.4.8 により、単位と余単位の成分は互いに双対な普遍性を持つ。その内容は定理4.2.7 の (v) と (vi) で述べる。これは §4.7 の議論で大きな役割を果たす。

5 例4.1.10 に挙げたほかの多くの随伴についても、単位がある種の「1 元からなるもの」への写像を定め、余単位がある種の「評価」準同型を定める、という同様の記述ができる。

単位と余単位から随伴を復元する

補題4.2.2 と 4.2.3 により、どの随伴も単位と余単位を持つ。逆に、向かい合う関手 F : C ⇄ D : G について、自然同型 (4.2.1) のデータは、自然変換 η : idC ⇒ GF だけからでも、自然変換 ε : FG ⇒ idD だけからでも復元できる。ただし、その成分が適切な普遍性を持つ（適切な表現可能関手の普遍元である）ことが条件である。

自然変換 η からは自然変換 D(F−, −) ⇒ C(−, G−) が定まり、自然変換 ε からは自然変換 C(−, G−) ⇒ D(F−, −) が定まる。η と ε についての互いに双対な 2 つの両立条件があれば、この 2 つの自然変換は互いに逆になり、F と G が随伴関手になる。つまり、随伴の概念を次のように定義し直せる。

定義4.2.5 — 随伴 II

定義4.2.5（随伴 II）. 随伴とは、向かい合う一対の関手 F : C ⇄ D : G に、自然変換 η : idC ⇒ GF と ε : FG ⇒ idD であって次の三角等式（triangle identities）を満たすものを添えたものである。

εF ⋅ Fη = 1F　　Gε ⋅ ηG = 1G

左の三角形は関手圏 DC の図式が可換であることを、右の三角形は双対な図式が関手圏 CD で可換であることを述べている。自然変換 Fη, εF, ηG, Gε はひげ付け（Remark 1.7.6）で定義される。成分は記法のとおりで、Gε の d での成分は G(εd)、εF の c での成分は εFc である。したがって三角等式を成分で書くと、すべての c ∈ C と d ∈ D について

εFc ∘ F(ηc) = 1Fc　　G(εd) ∘ ηGd = 1Gd

である。この 2 つの条件は、§1.7 の流儀で、圏の 2-圏の中の等式としても表せる（(6.5.4)）。

Remark 4.2.6. 三角等式は合わせて「余単位は、移し替えを除いて、単位の左逆である」と述べている。

単位の成分 ηc : c → GFc は C の射、余単位の成分 εd : FGd → d は D の射で、合成できないので、文字どおりの逆にはなりえない。しかし単位に F を適用すると D の射 Fηc : Fc → FGFc が得られ、その左逆が εFc である。余単位に G を適用すると C の射 Gεd : GFGd → Gd が得られ、その右逆が ηGd である。

定理4.2.7 — 随伴の同値な記述

随伴の 2 つの定義を統一するには、定義4.1.1 のデータが定義4.2.5 のデータを決め、逆に後者が前者を決めることを示せばよい。

定理4.2.7. 一対の関手 F : C ⇄ D : G について、随伴 F ⊣ G のデータは、次のどれによっても同値に与えられる。
  1. すべての c ∈ C と d ∈ D についての同型 D(Fc, d) ≅ C(c, Gd) の自然な族。
  2. 自然変換 η : idC ⇒ GF と ε : FG ⇒ idD であって、Gε ⋅ ηG = 1G と εF ⋅ Fη = 1F を満たすもの。
  3. 自然変換 η : idC ⇒ GF であって、f♯ : Fc → d を f♭ ≔ Gf♯ ∘ ηc : c → GFc → Gd に送る写像 (4.2.8) が、すべての c ∈ C と d ∈ D について同型であるもの。
  4. 自然変換 ε : FG ⇒ idD であって、g♭ : c → Gd を g♯ ≔ εd ∘ Fg♭ : Fc → FGd → d に送る写像 (4.2.9) が、すべての c ∈ C と d ∈ D について同型であるもの。
  5. 自然変換 η : idC ⇒ GF であって、すべての c ∈ C について、成分 ηc : c → GFc がコンマ圏 c ↓ G の始対象であるもの。
  6. 自然変換 ε : FG ⇒ idD であって、すべての d ∈ D について、成分 εd : FGd → d がコンマ圏 F ↓ d の終対象であるもの。

(iii) の写像 (4.2.8) は、G の射への作用と ηc の前合成の合成である。

(iv) の写像 (4.2.9) は、F の射への作用と εd の後合成の合成である。

(v) の「ηc が c ↓ G の始対象である」を展開すると次になる。任意の d ∈ D と射 g : c → Gd に対して、D の射 k : Fc → d であって Gk ∘ ηc = g を満たすものがただ 1 つ存在する。(vi) の「εd が F ↓ d の終対象である」は、任意の c ∈ C と射 f : Fc → d に対して、C の射 h : c → Gd であって εd ∘ Fh = f を満たすものがただ 1 つ存在する、ということである。

どの記述も、データと条件からなる。(ii)–(vi) のデータは、単位と余単位の一方または両方である。条件は、それぞれ、三角等式、自然変換 D(F−, −) ⇒ C(−, G−) または C(−, G−) ⇒ D(F−, −) の可逆性、単位の成分が始対象であること、余単位の成分が終対象であること、である。(i) では、データは一対の自然変換 D(F−, −) ⇒ C(−, G−) と C(−, G−) ⇒ D(F−, −) で、条件はこの 2 つが互いに逆であることである。(i) と (ii) は明示的なデータを 2 つずつ持つが、どちらの場合も条件も 2 つある。

定理4.2.7 の証明

(iii) ⇔ (v) と (iv) ⇔ (vi). 各 c ∈ C について、ηc が同型 (4.2.8) を誘導するという条件と、ηc が c ↓ G の始対象であるという条件が同値であることを示せばよい。これは表現可能関手の理論から従う。(4.2.8) がすべての d ∈ D について同型であるとは、ηc ∈ C(c, GFc) が関手 C(c, G−) : D → Set の普遍元であるということである。命題2.4.8 により、これは ηc がこの関手の元の圏の始対象であることと同値である。関手 C(c, G−) の元の圏は、対象が d ∈ D と元 g ∈ C(c, Gd) の組、射が k : d → d′ で Gk ∘ g = g′ を満たすものだから、c ↓ G にほかならない。(iv) ⇔ (vi) は双対である。

(i) ⇒ (ii). 補題4.2.2 と 4.2.3 により、自然同型 D(Fc, d) ≅ C(c, Gd) から、成分が恒等射の転置である自然変換 η : idC ⇒ GF と ε : FG ⇒ idD が得られる。残るのは三角等式である。

まず εFc ∘ Fηc = 1Fc を示す。これは下の左の四角形（D の中）の可換性である。補題4.1.3 の D の四角形 k ∘ f♯ = g♯ ∘ Fh で、h = ηc : c → GFc、f♯ = 1Fc、k = 1Fc、g♯ = εFc : FGFc → Fc と取ったものにあたる。転置は f♭ = ηc（1Fc の転置）、g♭ = 1GFc（εFc は 1GFc の転置）だから、転置した C の四角形は右の四角形である。右の四角形は、どちらの回り方でも ηc になるので可換である。

次に Gεd ∘ ηGd = 1Gd を示す。これは下の左の四角形（C の中）の可換性である。補題4.1.3 の C の四角形 Gk ∘ f♭ = g♭ ∘ h で、h = 1Gd、f♭ = ηGd : Gd → GFGd、k = εd、g♭ = 1Gd と取ったものにあたる。転置は f♯ = 1FGd、g♯ = εd だから、対応する D の四角形は右の四角形で、どちらの回り方でも εd になるので可換である。

自然変換の垂直合成は成分ごとの合成で定義される（補題1.7.1）ので、すべての c, d でこの 2 つの等式が成り立つことが、三角等式 εF ⋅ Fη = 1F と Gε ⋅ ηG = 1G である。

(ii) ⇒ (iii) と (ii) ⇒ (iv). 三角等式から、(4.2.8) と (4.2.9) の 2 つの操作が互いに逆であることを示す。そうすれば (4.2.8) も (4.2.9) も同型である。

f♯ : Fc → d に (4.2.8) を適用すると Gf♯ ∘ ηc で、これに (4.2.9) を適用すると εd ∘ F(Gf♯ ∘ ηc) = εd ∘ FGf♯ ∘ Fηc である。これは下の図式の上段の合成である。

右の四角形 εd ∘ FGf♯ = f♯ ∘ εFc は、ε の f♯ : Fc → d についての自然性である。左の三角形 εFc ∘ Fηc = 1Fc は三角等式の一方である。したがって上段の合成は f♯ ∘ εFc ∘ Fηc = f♯ に等しい。

双対に、g♭ : c → Gd に (4.2.9) を適用すると εd ∘ Fg♭ で、これに (4.2.8) を適用すると G(εd ∘ Fg♭) ∘ ηc = Gεd ∘ GFg♭ ∘ ηc である。これは下の図式の上段の合成である。

左の四角形 GFg♭ ∘ ηc = ηGd ∘ g♭ は、η の g♭ : c → Gd についての自然性である。右の三角形 Gεd ∘ ηGd = 1Gd は三角等式のもう一方である。したがって上段の合成は Gεd ∘ ηGd ∘ g♭ = g♭ に等しい。

(iii) ⇒ (i) と (iv) ⇒ (i). (4.2.8) で定義される写像の族は、c と d について自然である。d についての自然性は、k : d → d′ について G(k ∘ f♯) ∘ ηc = Gk ∘ (Gf♯ ∘ ηc) で、G の関手性である。c についての自然性は、h : c′ → c について G(f♯ ∘ Fh) ∘ ηc′ = Gf♯ ∘ GFh ∘ ηc′ = Gf♯ ∘ ηc ∘ h で、G の関手性と η の自然性である。(iii) はその各成分が可逆だと仮定しているので、自然同型 D(Fc, d) ≅ C(c, Gd) が得られる。(4.2.9) についても同様である。以上で、(i)–(vi) のどのデータからも F ⊣ G が得られることが示された。

構成が互いに逆であること. 最後に、これらの構成が互いに逆であることを確かめる。

(i) の自然な全単射 D(Fc, d) ≅ C(c, Gd) から始める。転置を f♯ ↭ f♭ と書く。ηc ≔ (1Fc)♭ と定めて (ii) の自然変換を得て、そこから (4.2.8) により、f♯ の新しい転置を Gf♯ ∘ (1Fc)♭ と定めた。もとの全単射の d についての自然性 (k ∘ f♯)♭ = Gk ∘ f♭ を、k = f♯ と 1Fc に適用すると、Gf♯ ∘ (1Fc)♭ = (f♯ ∘ 1Fc)♭ = f♭ である。したがって新しい転置の式は、もとの転置を復元する。

逆に、(ii) の単位と余単位から始める。(4.2.8) と (4.2.9) で転置を定義し、そこから成分が恒等射の転置である自然変換 idC ⇒ GF と FG ⇒ idD を得る。(4.2.8) と (4.2.9) の式から、(1Fc)♭ = G1Fc ∘ ηc = ηc、(1Gd)♯ = εd ∘ F1Gd = εd だから、もとの一対の自然変換が復元される。□

系4.2.10 — ガロア接続の不動点公式

単位と余単位が存在するということだけから、半順序集合の間のガロア接続について次の不動点公式が得られる。

系4.2.10. A と B が半順序集合で、F : A → B と G : B → A が F ⊣ G なるガロア接続をなすならば、F と G は次の不動点公式を満たす。

FGF = F　　GFG = G

証明. 半順序集合を圏と見ると、射 x → y は x ≤ y のときちょうど 1 本あり、そうでなければ存在しない。単位の成分 ηa は a ≤ GF(a) を、余単位の成分 εb は FG(b) ≤ b を表す。三角等式 εFa ∘ Fηa = 1Fa に現れる 2 つの射 Fηa : F(a) → FGF(a) と εFa : FGF(a) → F(a) があることから、すべての a ∈ A について F(a) ≤ FGF(a) ≤ F(a) である。半順序は反対称的だから F(a) = FGF(a)、すなわち F = FGF である。もう一方の公式は双対である。□

たとえば、写像 f : A → B が誘導する、例4.1.8 の順像 ⊣ 逆像の随伴を考える。

一般の部分集合 X ⊂ A と Y ⊂ B について、包含

X ⊂ f−1(f(X))　　f(f−1(Y)) ⊂ Y

はどちらも等号とは限らない。それでも

f(X) = f(f−1(f(X)))　　f−1(f(f−1(Y))) = f−1(Y)

が成り立つ。

補題4.2.11 — 随伴から圏同値へ

単位と余単位は、随伴と圏同値の関係も取り持つ。次の補題は随伴から圏同値を構成する。逆に圏同値から随伴を構成するのが系4.3.6 である。

補題4.2.11. 任意の随伴関手の対 F : C ⇄ D : G は、単位の成分 ηc が同型であるような対象 c ∈ C の張る充満部分圏と、余単位の成分 εd が同型であるような対象 d ∈ D の張る充満部分圏の間の、圏同値に制限される。

証明. 2 つの充満部分圏の上では η と ε の成分はすべて同型だから、F と G がこれらの部分圏に制限されさえすれば、制限した η と ε が自然同型 id ≅ GF と FG ≅ id を与え、圏同値になる。したがって、F と G が部分圏を部分圏に送ることを確かめればよい。

ある c ∈ C について ηc が可逆だとする。F は同型を保つから Fηc は可逆である。三角等式 εFc ∘ Fηc = 1Fc により Fηc は εFc の右逆だから、εFc は Fηc の逆射で、可逆である。つまり Fc は D の側の部分圏に入る。双対の議論で、ある d ∈ D について εd が可逆ならば、Gεd が可逆で、三角等式 Gεd ∘ ηGd = 1Gd により ηGd も可逆である。つまり Gd は C の側の部分圏に入る。□
