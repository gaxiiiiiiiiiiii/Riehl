節の導入

節の冒頭には Saunders Mac Lane, Categories for the Working Mathematician からの引用が置かれている。よい一般論は最大の一般性を求めるのではなく、適切な一般性を求める、という一節である。

Kan が随伴関手を最初に調べた論文 [Kan58] は、反変な関手や、2 つ以上の変数を持つ関手の間の随伴の関係も扱っている。真偽の定かでない話によれば、こうした例が Kan の発見の主な動機であった。その話は、Kan がコロンビア大学のホモロジー代数のセミナーで Eilenberg に尋ねた質問として伝わっている [Mar09, §4.2]。

Kan: テンソル積が hom 関手を使って定義できることを説明されました。逆に、hom をテンソル積を使って定義することはできますか。

Eilenberg: いいえ、もちろんできません。馬鹿げています。

実際には Kan の直観が正しかった。命題4.3.1 により、随伴関手はその随伴を自然同型を除いて決める。hom の双関手をテンソル積から定義する方法は例4.4.15 で説明する。テンソル積と hom の間の随伴は、定義4.4.7 で導入する 2 変数随伴の例である。その前に、反変な随伴を扱う。

反変な随伴関手は、双対性の原理を当てはめるだけで得られる。定義4.1.1 は、関手 F : C → D と G : D → C について、c と d について自然な同型 D(Fc, d) ≅ C(c, Gd) があるとき F を G の左随伴と呼ぶものであった。この定義の双対化は 3 通りある。C を Cop に置き換えるもの、D を Dop に置き換えるもの、両方を置き換えるものである。

両方を置き換えると、元の随伴の概念に戻る。G : Dop → Cop が F : Cop → Dop の左随伴であるとは、自然同型 Cop(Gd, c) ≅ Dop(d, Fc) があることで、これは自然同型 C(c, Gd) ≅ D(Fc, d) があること、すなわち F ⊣ G と同じである。したがって、左随伴についての定理はどれも、右随伴についての双対な定理を持つ。これは随伴についての双対性の原理で、たいへん役に立つ。

残りの 2 つの双対化からは、新しい種類の随伴関手が得られる。

定義4.4.1 — 互いに左随伴、互いに右随伴

定義4.4.1. 一対の反変関手 F : Cop → D と G : Dop → C は、c と d について自然な同型

D(Fc, d) ≅ C(Gd, c)

が存在するとき互いに左随伴（mutually left adjoint）であるといい、c と d について自然な同型

D(d, Fc) ≅ C(c, Gd)

が存在するとき互いに右随伴（mutually right adjoint）であるという。

C(Gd, c) = Cop(c, Gd) だから、F と G が互いに左随伴であることは、F : Cop → D が Gop : D → Cop の左随伴であることと同じである。また D(d, Fc) = Dop(Fc, d) だから、F と G が互いに右随伴であることは、Fop : C → Dop が G : Dop → C の左随伴であることと同じである。どちらの定義も F と G の役割を入れ替えて変わらない。

定義4.2.5 は、随伴を、単位 η : idC ⇒ GF と余単位 ε : FG ⇒ idD で三角等式を満たすものとして定義した。これを双対化すると次のようになる。互いに左随伴な対 F : Cop → D, G : Dop → C は、一対の「余単位」にあたる自然変換 η : GF ⇒ idC と ε : FG ⇒ idD を備える。互いに右随伴な対 F : Cop → D, G : Dop → C は、一対の「単位」にあたる自然変換 η : idC ⇒ GF と ε : idD ⇒ FG を備える。それぞれの場合の三角等式を書き下すことは演習4.4.i に委ねられている。

前順序集合の間の互いに右随伴な対は、反単調ガロア接続（antitone Galois connection）と呼ばれることがある。

例4.4.2 — 零点集合と消える多項式

自然数 n と代数閉体 𝕜 を固定し、多項式環 𝕜[x1, …, xn] の元の集合と、ベクトル空間 𝕜n の元の集合を考える。それぞれの部分集合のなす半順序集合の間に、反変関手

V : P(𝕜[x1, …, xn])op → P(𝕜n)　と　I : P(𝕜n)op → P(𝕜[x1, …, xn])

がある。S ⊂ 𝕜[x1, …, xn] と T ⊂ 𝕜n に対して、次で定義する。

V(S) ≔ {(t1, …, tn) ∈ 𝕜n ∣ すべての f ∈ S について f(t1, …, tn) = 0}

I(T) ≔ {f ∈ 𝕜[x1, …, xn] ∣ すべての (t1, …, tn) ∈ T について f(t1, …, tn) = 0}

V と I は互いに右随伴である。それは

T ⊂ V(S)　⇔　S ⊂ I(T)

が成り立つからである。両辺はどちらも、すべての f ∈ S とすべての t ∈ T について f(t) = 0 であるという条件である。このガロア接続は現代の代数幾何学の出発点の 1 つである。

単位と余単位にあたるものは、関係

T ⊂ V(I(T))　と　S ⊂ I(V(S))

である。点の集合 T ⊂ 𝕜n が不動点である、すなわち T = V(I(T)) を満たすのは、T が 𝕜n = Spec(𝕜[x1, …, xn]) 上のザリスキー位相で閉であるとき、かつそのときに限る。ザリスキー位相は例1.3.7(iv) で導入した。多項式の集合 S ⊂ 𝕜[x1, …, xn] が不動点である、すなわち S = I(V(S)) を満たすのは、S が 𝕜[x1, …, xn] の根基イデアルであるとき、かつそのときに限る。これがヒルベルトの零点定理である。

補題4.2.11 は、随伴 F ⊣ G が、単位の成分 ηc が同型である対象 c のなす充満部分圏と、余単位の成分 εd が同型である対象 d のなす充満部分圏の間の圏同値に制限されることを述べる。これを V と I に当てはめると、𝕜n のザリスキー閉集合のなす半順序集合が、𝕜[x1, …, xn] の根基イデアルのなす半順序集合の反対と同型であることが分かる。

例4.4.3 — 構文と意味論の間のガロア接続

シグネチャ σ、すなわち関数記号、定数記号、関係記号のリストを固定する。Structσ を σ-構造の集合とする。σ-構造とは、σ の定数記号、関係記号、関数記号の解釈を備えた集合である。Axiomσ を公理の集合とする。公理とは、σ の定める一階の言語の文である。

たとえば順序体のシグネチャは、定数記号 0 と 1、2 項関数記号 + と ⋅、2 項関係記号 < からなる。この言語の構造は、指定された 2 つの定数、2 つの 2 項関数、1 つの 2 項関係を備えた任意の集合である。公理には

∀x, y, x ⋅ y = y ⋅ x　や　∀x, y, z, ((x < y) ∧ (0 < z)) → (x ⋅ z < y ⋅ z)

のような文が含まれる。1 つ目は「乗法」の関数が対称であることを主張し、2 つ目は「正」の元 0 < z を掛けることが順序関係を保つことを主張する。

σ-構造の集合 M と公理の集合 A について、A に属するどの公理も M に属するどの σ-構造でも満たされる、つまり真であるとき、M ⊨ A と書く。たとえば上の 1 つ目の文がある構造で満たされるのは、その構造での 2 項関数 ⋅ の解釈が 2 つの引数について対称であるとき、かつそのときに限る。

包含で順序を入れた半順序集合 P(Axiomσ) と P(Structσ) を圏と見る。反変関手

True in : P(Axiomσ)op → P(Structσ)　と　Satisfying : P(Structσ)op → P(Axiomσ)

がある。1 つ目は公理の集合を、それらの公理をすべて満たす σ-構造の集合に送る。公理を満たす構造をその公理のモデルという。2 つ目は σ-構造の集合を、それらの構造のすべてで満たされる公理の集合に送る。この 2 つは互いに右随伴で、構文と意味論の間のガロア接続と呼ばれるものをなす [Smi10]。

命題4.4.4 — 対象ごとの表現から随伴へ

多変数の関手に進む前に、通常の随伴にも同じように当てはまる観察を 1 つ述べる。

命題4.4.4. 関手 F : A → B について、各 b ∈ B に対して対象 Gb ∈ A と、a ∈ A について自然な同型

(4.4.5)　B(Fa, b) ≅ A(a, Gb)

が存在するとする。このとき、対応 G : ob B → ob A を関手 G : B → A に拡張して、同型の族 (4.4.5) が b ∈ B についても自然になるようにする方法が、ただ 1 つ存在する。したがって、F : A → B が、各 b ∈ B について関手

B(F−, b) : Aop → Set

の表現を指定された関手ならば、このデータから随伴 F ⊣ G が組み上がる。

双対な表現可能性の判定条件が、左随伴を持つ関手を特徴づける。すなわち、関手 G : B → A について、各 a ∈ A に対して対象 Fa ∈ B と、b ∈ B について自然な同型 B(Fa, b) ≅ A(a, Gb) が存在するならば、対応 F : ob A → ob B は、この同型の族が a についても自然になるような関手 F : A → B に一意に拡張される。

証明. 射 f : b → b′ についての (4.4.5) の自然性は、まだ定義していない射 Gf : Gb → Gb′ について、次の四角形が可換であることを要求する。

つまり、上辺、右辺、下辺をこの順に合成した写像 A(a, Gb) → A(a, Gb′) が、Gf を後ろに合成する写像 (Gf)∗ に等しいことを要求する。

この合成写像を作る 3 つの写像は、どれも a について自然である。上辺と下辺は仮定により a について自然で、右辺の f∗ は自然変換 B(F−, b) ⇒ B(F−, b′) の成分である。したがって合成写像は自然変換 A(−, Gb) ⇒ A(−, Gb′) を定める。米田の補題により、表現可能関手の間の自然変換 A(−, Gb) ⇒ A(−, Gb′) は、ただ 1 つの射 Gb → Gb′ を後ろに合成する写像として得られる。この射を Gf と定める。これで四角形は可換になり、四角形を可換にする Gf はこれに限る。

こうして定めた対応 G : mor B → mor A が関手的であることは、この定義の一意性から従う。定理1.5.9 の証明で見たのと同じ議論である。恒等射 1b については、右辺が恒等写像になるので合成写像も恒等写像で、これは 1Gb を後ろに合成する写像だから、一意性により G(1b) = 1Gb である。射 f : b → b′ と g : b′ → b″ については、f の四角形の下に g の四角形を貼り合わせる。貼り合わせた図式の右辺は g∗ ∘ f∗ = (g ∘ f)∗ で、間に挟まる b′ での同型とその逆は打ち消し合う。したがって g ∘ f についての合成写像は (Gg)∗ ∘ (Gf)∗ = (Gg ∘ Gf)∗ に等しく、一意性により G(g ∘ f) = Gg ∘ Gf である10。□

10 より簡潔に言うと、G は、関手 b ↦ B(F−, b) の米田埋め込みに沿ったただ 1 つの制限として定義される。すなわち、次の三角形が、指定された自然同型 (4.4.5) を除いて可換になるような関手である。米田埋め込みは忠実充満だから、G の射での値は、合成 b ↦ A(−, Gb) の射での値によって一意に決まる。

命題4.4.6 — 変数ごとの随伴から双関手へ

命題4.4.4 の証明に使った構成は、多変数の関手に拡張できる。

命題4.4.6. 双関手 F : A × B → C を考える。
  1. 各対象 a ∈ A について、F から得られる関手 F(a, −) : B → C が右随伴 Ga : C → B を持つならば、G(a, −) ≔ Ga を満たし、同型

    C(F(a, b), c) ≅ B(b, G(a, c))

    が 3 つの変数すべてについて自然であるような双関手 G : Aop × C → B が、ただ 1 つ存在する。
  2. 各対象 b ∈ B について、F から得られる関手 F(−, b) : A → C が右随伴 Hb : C → A を持つならば、H(b, −) ≔ Hb を満たし、同型

    C(F(a, b), c) ≅ A(a, H(b, c))

    が 3 つの変数すべてについて自然であるような双関手 H : Bop × C → A が、ただ 1 つ存在する。
  3. (i) と (ii) の仮定がどちらも成り立つとき、各 c ∈ C について、関手 G(−, c) : Aop → B と H(−, c) : Bop → A は互いに右随伴である。

(i) の同型は、a を固定したときには随伴 F(a, −) ⊣ Ga の同型で、b と c について自然である。主張は、Ga を a について束ねて、同じ同型が a についても自然になるようにできるということである。

証明. 演習4.4.ii。□

定義4.4.7 — 2 変数随伴

命題4.4.6 により、変数ごとの随伴を持つ双関手からは、次の構造が得られる。

定義4.4.7. 3 つの双関手

F : A × B → C,　　G : Aop × C → B,　　H : Bop × C → A

と、3 つの変数について自然な同型

C(F(a, b), c) ≅ B(b, G(a, c)) ≅ A(a, H(b, c))

の組を、2 変数随伴（two-variable adjunction）という。

とくに、2 変数随伴の左随伴 F が何らかのモノイダル積であるとき、変数ごとに定義される右随伴 G と H を、それぞれ F の左閉包（left closure）と右閉包（right closure）という。両方の閉包が存在するとき、F は双閉（biclosed）であるという。F : C × C → C の形の双閉な関手で、2 つの引数について自然に対称なものは、単に閉（closed）であるという。この場合には左閉包と右閉包が自然同型だからである。

例4.4.8 — 両側加群のテンソル積

環 R と S について、R-S 両側加群の圏を RModS と書く。R-S 両側加群とは、R の元による左作用と S の元による右作用が互いに可換であるものである。RModℤ ≅ RMod と ℤModS ≅ ModS が成り立つ。もう 1 つの環 T について、S 上のテンソル積は双閉な関手

⊗S : RModS × SModT → RModT

を定める。左閉包と右閉包は

RHom : RModSop × RModT → SModT　と　HomT : SModTop × RModT → RModS

である。M ∈ RModS と N ∈ RModT について、RHom(M, N) は左 R 加群の準同型 M → N の集合である。この集合は次の 3 つの構造を受け継ぐ。

  • アーベル群の構造。加法は各点ごとに定義する。
  • 左 S 加群の構造。反変な変数 M の右 S 加群の構造を通して作用させる。
  • 右 T 加群の構造。共変な変数 N の右 T 加群の構造を通して作用させる。

S の作用は前への合成で、T の作用は後ろへの合成で定義されるので、2 つの作用は可換で、RHom(M, N) は S-T 両側加群になる。右閉包も同様に定義される。

例4.4.9 — 集合の積と写像の集合

積の双関手

× : Set × Set → Set

は閉である。例2.1.6(iv) のカリー化の操作が、自然同型の族

{A × B → C} ≅ {A → CB} ≅ {B → CA}

を定めるからである。したがって、積の双関手と指数の双関手

× : Set × Set → Set　と　(−)(−) : Setop × Set → Set

は 2 変数随伴を定める。

定義4.4.10 — デカルト閉圏

定義4.4.10. デカルト閉圏（cartesian closed category）とは、有限積を持つ圏 C であって、積の双関手 − × − : C × C → C が閉であるものをいう。

Set のほかに、有限集合の圏 Fin、小圏の圏 Cat、関手圏 SetC がデカルト閉である。Cat については演習1.7.vi を見よ。SetC については次の補題で示す。

補題4.4.11 — SetC はデカルト閉

補題4.4.11. 任意の小圏 C について、関手圏 SetC はデカルト閉である。

証明. 関手 F, G : C → Set が与えられたとする。目標は、関手 GF : C → Set を定義して、すべての関手 H : C → Set について、自然変換の集合の間に H について自然な全単射

(4.4.12)　{H × F ⇒ G} ≅ {H ⇒ GF}

があるようにすることである。

GF の対象 c での値を

(4.4.13)　GF(c) ≔ {C(c, −) × F ⇒ G} ≅ {C(c, −) ⇒ GF}

と定義する。左の ≔ が定義で、右の ≅ は米田の補題による全単射である。定理2.2.4 により、自然変換 β : C(c, −) ⇒ GF は元 βc(1c) ∈ GF(c) によって一意に決まり、この元は定義により自然変換 C(c, −) × F ⇒ G である。したがって、この定義のもとで、H = C(c, −) の場合の全単射 (4.4.12) は米田の補題で与えられる。

射 f : c → d に対して、GF(f) を、自然変換 f∗ : C(d, −) ⇒ C(c, −) を前に合成する写像と定義する。すなわち、α ∈ GF(c) を α ⋅ (f∗ × 1F) ∈ GF(d) に送る。

米田の補題の自然性から、同型 (4.4.13) は c について自然である。

自然な全単射 (4.4.12) が特別な場合 (4.4.13) から従うことには形式的な理由がある。これは演習6.5.iii で扱う。ここでは、随伴による転置の式を与えて、全単射を直接示す。

はじめに、随伴 − × F ⊣ (−)F の余単位を定義する。その G ∈ SetC での成分は自然変換 ev : GF × F ⇒ G で、その成分は恒等射で値を取る写像である。

ここで γ ∈ GF(c) は自然変換 C(c, −) × F ⇒ G で、γc : C(c, c) × Fc → Gc はその c での成分、y は Fc の元である。

定理4.2.7(iv) により、自然変換 β : H ⇒ GF の随伴による転置は、β に関手 − × F を適用し、余単位の成分 ev を後ろに合成して得られる自然変換 α である。

成分で書くと、c ∈ C、x ∈ Hc、y ∈ Fc について αc(x, y) = βc(x)c(1c, y) である。

この操作が可逆であることを、逆を記述して示す。α : H × F ⇒ G が与えられたとき、その転置を次の自然変換 β : H ⇒ GF と定める。c ∈ C と x ∈ Hc に対して、βc(x) : C(c, −) × F ⇒ G は、d ∈ C での成分が、射 f : c → d と元 z ∈ Fd を元 αd((Hf)x, z) ∈ Gd に送る写像である自然変換である。

2 つの操作が互いに逆であることは次のように確かめられる。α から β を作り、β から上の三角形で自然変換を作ると、その成分は (x, y) を βc(x)c(1c, y) = αc((H1c)x, y) = αc(x, y) に送るので、α に戻る。逆に β から α を作り、α から自然変換 β′ を作ると

β′c(x)d(f, z) = αd((Hf)x, z) = βd((Hf)x)d(1d, z)

である。β の自然性により βd((Hf)x) = GF(f)(βc(x)) = βc(x) ⋅ (f∗ × 1F) で、その d での成分は (1d, z) を βc(x)d(f, z) に送る。したがって β′ = β である。□

例4.4.14 — 空間の便利な圏

位相空間の圏 Top はデカルト閉でない。しかし Steenrod の有名な論文 [Ste67] は、完備かつ余完備で、デカルト閉で、CW 複体を含む程度に大きい、位相空間の便利な圏（convenient category of topological spaces）が存在することを証明している。Steenrod の便利な圏は、ハウスドルフ空間と連続写像の圏 Haus の部分圏である。それ以前の研究者たちは、Steenrod の条件のリストを満たす「空間の便利な圏」は存在しないと論じていた。Steenrod は次のように述べている。

それらの議論は、標準的な操作の慣例どおりの定義に盲目的に従うことに基づいている。それらの定義はハウスドルフ空間の圏には適しているが、部分圏に適しているとは限らない。圏論的な観点を取れば、これらの定義を解凍して少し曲げることができる。

Steenrod が言っているのは、これから定義する部分圏 cgHaus での「積」は、定義3.1.9 の圏論的な積であるべきだということである。この積は、充満な包含 cgHaus ↪ Haus で保たれない。

cgHaus の対象はコンパクト生成ハウスドルフ空間である。ハウスドルフ空間 X がコンパクト生成であるとは、部分集合 A ⊂ X が、X の各コンパクト部分集合 K との共通部分 A ∩ K が閉であるという性質を持つならば、A 自身が X で閉であることをいう。包含 cgHaus ↪ Haus は右随伴 k : Haus → cgHaus を持ち、k 化（k-ification）と呼ばれる。空間 k(X) は X の位相を細かくしたもので、すべてのコンパクト部分集合 K との共通部分が閉であるような部分集合 A ⊂ X を、閉集合の族に加えて得られる。

cgHaus の積は、Haus の積の k 化である。これと対照的に、Haus の積は包含 Haus ↪ Top で保たれる。積の変数ごとの右随伴は、次の写像空間 Map(X, Y) の構成で与えられる。Map(X, Y) の台集合は連続写像 X → Y の集合で、位相はコンパクト開位相の k 化である。証明は [Ste67] を見よ11。

11 演習4.7.ii と命題3.6.2、命題4.5.14 により、この随伴が存在することから、cgHaus が完備かつ余完備であることが従う。

例4.4.15 — テンソル積と hom

デカルト積の右随伴ではない hom の双関手を持つ圏もある。その最も有名な例が、Kan を動かした「テンソル ⊣ hom」の随伴である。

hom の双関手

Hom : Abop × Ab → Ab

を考える。Hom(B, C) は準同型 B → C のなす群で、加法はアーベル群 C の加法を使って各点ごとに定義する12。反変な変数を固定すると、随伴

(4.4.16)　Ab(A ⊗ℤ B, C) ≅ Ab(A, Hom(B, C))

があり、これがテンソル積を定義する。この自然同型は、テンソル積の普遍性を表している。テンソル積の普遍性は、ベクトル空間の場合に例2.3.8 で述べた。Ab(A, Hom(B, C)) の元はアーベル群の準同型 φ : A → Hom(B, C) で、これは ℤ-双線型な写像 φ : A × B → C に対応する。ℤ-双線型とは、すべての a ∈ A について φ(a, −) : B → C が群準同型で、すべての b ∈ B について φ(−, b) : A → C が群準同型であることをいう。

表現対象 A ⊗ℤ B ∈ Ab を定義してしまえば、命題4.4.4 が同型 (4.4.16) を使って、このデータを関手 − ⊗ℤ B : Ab → Ab に拡張する。続いて命題4.4.6(i) が、このデータをテンソル積の双関手

⊗ℤ : Ab × Ab → Ab

に拡張し、テンソル積と hom は 2 変数随伴を定める。

Kan が予想したとおり、この過程は逆にたどれる。テンソル積の双関手 ⊗ℤ : Ab × Ab → Ab が与えられたとき、アーベル群 Hom(B, C) は、関手

(4.4.17)　Ab(− ⊗ℤ B, C) : Abop → Set,　　Ab(A, Hom(B, C)) ≅ Ab(A ⊗ℤ B, C)

の表現として定義できる。命題4.4.4 と命題4.4.6(i) により、この構成 Hom : ob Ab × ob Ab → ob Ab を双関手 Hom : Abop × Ab → Ab に拡張して、同型 (4.4.17) が A だけでなく B と C についても自然になるようにする方法が、ただ 1 つ存在する。

12 記法1.1.8 で述べたように、一般の圏で、固定した一対の対象の間の射の集まりはしばしば「Hom」と書かれる。ここでは準同型の単なる集合を「Ab」と書いている。この例では、単なる集合のほうは副次的な役割しか持たない。

例4.4.18 — ループ空間と懸垂

この例の中だけ、Top は通常の位相空間の圏ではなく、例4.4.14 で定義したデカルト閉な空間の圏を表すとする。このとき 2 変数随伴を特殊化して、随伴

が得られる。S1 ∈ Top は単位円である。空間 Map(S1, X) は X 上の自由ループ空間で、その点は空間 X の中のループである。

Top の、1 点空間 ∗ の下のスライス圏は、基点付き位相空間の便利な圏 Top∗ を定める。演習4.4.iv により、Top∗ は

∧ : Top∗ × Top∗ → Top∗　と　Map∗ : Top∗op × Top∗ → Top∗

で定義される 2 変数随伴を持つ。Map∗((X, x), (Y, y)) は、基点を保つ連続写像 (X, x) → (Y, y) のなす基点付き空間である。双関手 ∧ をスマッシュ積という。

空間

ΩX ≔ Map∗(S1, (X, x))

は (X, x) 上の基点付きループ空間である。通常の記法 ΩX では基点 x ∈ X を書かない。関手 Ω は左随伴 ΣX ≔ S1 ∧ X を持つ。これは基点付き空間 (X, x) の約懸垂を構成する関手である。こうして、基点付き位相空間の間の、ループと懸垂の随伴

Top∗(ΣX, Y) ≅ Top∗(X, ΩY)

が定まる。

閉モノイダル圏と多変数随伴

例4.4.15 と例4.4.18 は、どちらも閉モノイダル圏（closed monoidal category）の例である。閉モノイダル圏はデカルト閉圏を一般化したもので、左随伴の双関手が圏論的な積で定義されるとは限らない状況を扱う。「閉」という形容は、テンソル積の左閉包と右閉包が存在することを指す。「モノイダル」という形容は、テンソル積と、それに付随する整合的な自然同型を指す。この自然同型は §E.2 で述べられる。

定義4.4.7 は、多変数随伴の定義に一般化できる。命題4.4.6 を当てはめると、n 変数随伴は、関手 F : A1 × ⋯ × An → B であって、n 個の変数のうちどの n − 1 個を固定しても変数ごとの右随伴を持つものによって決まる。詳しくは [CGR14] を見よ。
