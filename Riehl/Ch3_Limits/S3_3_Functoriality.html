この節の問い

命題3.1.7 により、極限と余極限は、存在すれば一意な同型を除いて一意に定まる。この節では、形 J を固定したとき、J 型の図式にその極限を対応させる操作が関手になることを示し、その帰結を調べる。

関手性は標準性とは別の性質である。ある図式の極限を与える対象は一般にたくさんあり、互いに同型だが、その中の一つを選ぶ理由はふつう存在しない。極限関手を作るには、図式ごとに極限を一つ選ぶ必要がある。

命題3.3.1 — 極限関手

命題3.3.1. C がすべての J 型の極限を持つとき、各図式に極限を一つずつ選ぶと、それが関手 lim : CJ → C の対象への作用を定める。より一般に、任意の圏 C と J について、CJ の充満部分圏であって極限が存在する図式全体が張るものの上に、極限関手が定義される。

この関手は標準的に定まるものではなく、各図式に対して「その」極限とする対象を任意に選ぶことで定まる。ここで選択公理を使っている。極限と余極限を関手ではなくアナ関手（anafunctor）として扱えば、この選択は避けられる。文献 [Mak96] を参照。

証明. 各図式 F ∈ CJ について、極限 lim F と極限錐 ε : Δ(lim F) ⇒ F を一つずつ選ぶ。これで lim の対象への作用が決まる。残るのは射への作用である。

CJ の射、すなわち自然変換 α : F ⇒ G を取る。F の極限錐 ε と α を垂直に合成すると、

Δ(lim F) ⟹ε F ⟹α G

は頂点 lim F を持つ G 上の錐 α·ε になる。G について選んだ極限錐 ε : Δ(lim G) ⇒ G の普遍性により、錐 α·ε は頂点の間のただ一つの射 lim F → lim G を通して分解する。この射を lim α : lim F → lim G と定める。定義から、lim α は等式

ε·Δ(lim α) = α·ε

を満たすただ一つの射である。ここで左辺の ε は G の極限錐、右辺の ε は F の極限錐である。

引き戻しの場合に描くと次のようになる。C•→•←• の射は、二つの余スパン B →f A ←g C と B′ →f′ A′ ←g′ C′ の間の成分 αB, αA, αC の組であって、二つの四角形 αAf = f′αB と αAg = g′αC を可換にするものである。下図の実線がこのデータである。

上下の余スパンについて引き戻し P = B ×A C と P′ = B′ ×A′ C′ を選ぶ。破線がそれぞれの引き戻し錐の脚である。P から B′ と C′ への合成 αB·(P → B) と αC·(P → C) は、二つの四角形の可換性により下の余スパン上の錐をなす。P′ の普遍性から、この錐を分解する射 P → P′ がただ一つ存在する。点線で描いたこの射が、関手 lim : C•→•←• → C のこの射への作用である。

関手であることは、普遍性の一意性から従う。まず恒等射について。F の極限錐 ε : Δ(lim F) ⇒ F は、恒等射 idlim F を通して自分自身から分解する。錐 idF·ε = ε を分解する射はただ一つなので、lim(idF) = idlim F である。

次に合成について。CJ の合成可能な射の対 α : F ⇒ G, β : G ⇒ H を取る。lim α と lim β の定義から、次の自然変換の図式の二つの四角形は可換である。

上の四角形は ε·Δ(lim α) = α·ε、下の四角形は ε·Δ(lim β) = β·ε を表す。Δ は関手なので Δ(lim β)·Δ(lim α) = Δ(lim β · lim α) であり、二つの四角形を貼り合わせると

ε·Δ(lim β · lim α) = β·ε·Δ(lim α) = β·α·ε

が得られる。すなわち lim β · lim α は、頂点 lim F を持つ H 上の錐 β·α·ε を H の極限錐から分解する射である。一方、lim(β·α) は定義により同じ錐を分解する射である。分解する射はただ一つなので lim β · lim α = lim(β·α) となり、極限関手は合成を保つ。□

例3.3.2 — 弧状連結成分の関手

関手 Path : Top → Set は、空間 X を X の道の集合 Path(X) := Top(I, X) に送る。一点空間から I への二つの包含 0, 1 : ∗ ⇉ I を前合成すると、空間 X を平行な関数の対

Path(X) ≅ Top(I, X) ⇉ Top(∗, X) ≅ Point(X)

に送る関手 P : Top → Set•⇉• が得られる。二つの関数 ev0, ev1 は、道をその始点と終点に送る。この対の余等化子を取る。

この余等化子は、X の点の集合を、道で結べる二点を同一視する関係で割った商であり、X の弧状連結成分の集合 π0X である。命題3.3.1 の双対により余等化子を取る操作は関手 colim : Set•⇉• → Set を定めるので、合成

π0 := Top →P Set•⇉• →colim Set

として弧状連結成分の関手が得られる。

系3.3.3 — 自然同型は極限の同型を誘導する

命題3.3.1 の構成は、C がその形の極限や余極限をすべて持つかどうかに依存しない。二つの図式の間の自然変換は、両方の極限が存在すればその間の射を誘導し、両方の余極限が存在すればその間の射を誘導する。さらに、自然変換が自然同型なら、誘導される射は同型である。

系3.3.3. 図式の間の自然同型は、それらの極限の間、あるいは余極限の間に、存在する限り、自然に定まる同型を誘導する。

証明. 命題3.3.1 の証明は、CJ の充満部分圏であって C に極限を持つ関手全体が張るものの上に、極限関手を定義している。自然同型は CJ の同型なので、この部分圏の同型である。関手は同型を同型に送る（補題1.3.8）ので、極限関手はこの自然同型を極限の間の同型に送る。余極限についても同様である。□

Eilenberg と Mac Lane が自然性の概念を定式化した計算上の主な動機は、この結果を注意深く正しく述べることにあった。当時は極限と余極限の一般論はまだなかったが、[EM45, 21.2] は有向図式の場合の系3.3.3 を証明している。次の二つの例が示すように、系3.3.3 の仮定のうち自然性は外せない。対象ごとの同型では、極限や余極限の同型は得られない。

例3.3.4 — 対象ごとに同型だが自然に同型でない G-集合

群 G について、二つの G-集合 X, Y : BG ⇉ Set が対象ごとに同型であるのは、BG の対象がただ一つなので、それらの台集合が同型であるときである。一方、X と Y が自然同型であるのは、G-同変な同型、すなわち各 g ∈ G の作用と可換な全単射 X ≅ Y が存在するときである。後者の条件は前者より強い。

例として G = ℤ/2 を取り、二つの ℤ/2-集合を考える。2 は二元集合に ℤ/2 を自明に作用させたもの、2′ は同じ二元集合に生成元が二つの元を入れ替えるように作用させたものである。関手 Bℤ/2 → Set と見ると、2 と 2′ はどちらも二元集合なので対象ごとに同型である。しかし、生成元の作用は 2 では恒等写像、2′ では互換であり、全単射 φ : 2 → 2′ が作用と可換なら φ = 互換·φ となって φ の像が互換の固定点に入るが、互換は固定点を持たない。したがって 2 と 2′ は自然同型ではない。

関手 X : BG → Set の極限は G-固定点の集合であり（例3.2.10）、余極限は G-軌道の集合である（演習3.6.i）。二つの ℤ/2-集合については次のようになる。

  • lim 2 は二元集合、lim 2′ は空集合
  • colim 2 は二元集合、colim 2′ は一点集合

どちらの場合も、2 と 2′ の極限、余極限は同型でない。

例3.3.5 — 置換と全順序

有限集合 X に、その置換の集合 Sym(X) と全順序の集合 Ord(X) を対応させる。X が n 元集合なら、どちらも n! 個の元を持つ。これらの対応は、有限集合の間の任意の関数については関手的でないが、全単射については関手的である。全単射 σ : X → Y について、

  • Sym : Finiso → Fin は共役で作用する。置換 τ ∈ Sym(X) を στσ−1 ∈ Sym(Y) に送る
  • Ord : Finiso → Fin は移送で作用する。X 上の全順序を、σ で写した Y 上の全順序に送る

各 X について Sym(X) と Ord(X) は同型だが、この対象ごとの同型は自然ではない。実際、以下で見るように、これらの図式を制限したものの極限や余極限は同型とは限らない。

組合せ論では、関手 F : Finiso → Fin を種（species）と呼ぶ。n 元集合 n の像 F(n) を、n 上のラベル付き F-構造の集合という。n 上のラベルなし F-構造の集合は、Finiso を n 元集合 n が張る充満部分圏、すなわち n の自己同型群と見た対称群 Sn に制限し、次の図式の余極限を取って定義する。

BSn ↪ Finiso →F Fin

この余極限は、Sn が F(n) に作用するときの軌道の集合である。Sym と Ord は対象ごとに同型なので、ラベル付き Sym-構造の集合とラベル付き Ord-構造の集合は同型である。しかしラベルなしの構造は異なる。

  • n 上のラベルなし Sym-構造の集合は、Sn が Sn に共役で作用するときの軌道の集合、すなわち n 元の置換の共役類の集合である
  • n 上のラベルなし Ord-構造の集合は一点集合である。n 上の任意の二つの全順序は、ある置換で互いに移り合う

n ≥ 2 では恒等置換と互換が異なる共役類に属するので、二つの余極限は同型でない。詳しくは [Joy81] を参照。

極限の選択についての注意

選んだ極限や余極限の関手性には、いくつか注意が要る。極限は、存在すれば、極限錐の射と可換な同型を除いて一意である。これは極限が文字どおり一意であることとは違う。極限の普遍性を満たす対象がただ一つしかない場合でも、その対象の自己同型の一つ一つが異なる極限錐を与える。

さらに、命題3.3.1 の極限関手を定めるための極限の選択を、互いに両立するように行えることはまれである。例えば Freyd と Scedrov は、引き戻しを持つ任意の圏において、標準的な引き戻し四角形の「横方向」の合成（演習3.1.vi の意味での合成）が合成した長方形の標準的な引き戻しになるように標準的な引き戻しを選べることを示した。しかし、同時に「縦方向」の合成も標準的な引き戻しになるように選ぶことはできない [FS90, §1.4]。

選んだ極限の対象が等しい場合でも、極限の構成に伴うさまざまな自然同型は恒等射とは限らない。これを見るために、まず次の補題を述べる。

補題3.3.6 — 積の結合性

補題3.3.6. 二項積を持つ圏の任意の対象の三つ組 X, Y, Z について、X, Y, Z への射影と可換な自然同型

αX,Y,Z : X × (Y × Z) ≅ (X × Y) × Z

がただ一つ存在する。

証明. 演習3.3.ii。□

補題3.3.6 は、積が自然な意味で結合的であることを述べている。したがって、二項積をどのように繰り返しても n 項積が定義できる。しかし、二項積の繰り返しで定まる対象 X × (Y × Z) と (X × Y) × Z が等しい場合、例えば骨格的な圏の中でも、その間の自然同型が恒等射になるとは限らない。αX,Y,Z が恒等射になるのは、二つの繰り返し積から X, Y, Z への射影がそれぞれ等しいとき、かつそのときに限る。次の例は Isbell [Isb69] が最初に考え、clingman [cli21] が後に整理したものである。

例3.3.7 — 結合性の同型が恒等射でない例

C を可算無限集合とする。Set における C と C の二項積は可算無限なので、頂点 C を持つ積錐を一つ固定できる。

射影 π1, π2 はエピ射だが同型ではない。余域の各元上のファイバーが可算無限だからである。恒等射の対 (idC, idC) は頂点 C の錐をなすので、積の普遍性により π1δ = idC かつ π2δ = idC を満たす射 δ : C → C がただ一つ存在する。δ は π1 と π2 の共通の切断である。

この二項積錐から、頂点 C を持つ三項積錐が二通りに得られる。C × (C × C) として組むものと、(C × C) × C として組むものである。左・中央・右の C への射影は次のとおり。

左の錐の脚は (π1, π1·π2, π2·π2)、右の錐の脚は (π1·π1, π2·π1, π2) である。三つの C への射影と可換な左の錐から右の錐への射はただ一つあり、それが αC,C,C である。この射が恒等射であるためには、錐の脚がそれぞれ等しいこと、すなわち

π1 = π1·π1, π1·π2 = π2·π1, π2·π2 = π2

が必要である。第一の等式の両辺に右から δ を合成すると、π1δ = idC から idC = π1 が得られ、第三の等式から同様に π2 = idC が得られる。ところが恒等射の対 (idC, idC) は積の普遍性を持たない。C は二つ以上の元を持つので、異なる二つの射 f, g : ∗ → C があり、錐 (f, g) を分解する射 h は h = f かつ h = g を満たさなければならないからである。よって π1 = π2 = idC は成り立たず、αC,C,C は恒等射でない。11

11 clingman は、一般の圏においてこの形の二項積図式を考え、誘導される射 C × (C × C) → (C × C) × C が恒等射であることと、関手 C(−, C) が部分終対象であること、すなわち任意の対象 X について X から C への射が高々一つであることが同値であることを証明している [cli21, 3.1]。
