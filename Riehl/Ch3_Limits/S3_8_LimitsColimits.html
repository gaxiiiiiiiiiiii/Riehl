Emily Riehl, Category Theory in Context §3.8（pp.125–129）の内容を、個人学習のために日本語で書き直した解説。番号（定理3.8.1 など）は本と揃えてある。翻訳ではなく、同じ内容を自分の言葉で再構成したもの。

この節の問い

多変数の関手が与えられたとき、各変数について別々に極限や余極限を取ることを考えるのは自然である。それらが存在すれば、普遍性から、極限は極限と交換し、余極限は余極限と交換することが従う。一方、極限と余極限では普遍性の向きが逆である。そのため、極限と余極限が交換する数少ない場合には、それは普遍性の形式的な議論からは従わず、たいていはその圏での具体的な構成のされ方による。

これを調べるために、2 変数の関手 F : I × J → C を考える。演習1.7.vi により、F は関手 F : I → CJ とも、関手 F : J → CI とも見られる。三つの互いに同型な圏 (CJ)I ≅ CI×J ≅ (CI)J のどれの対象と見るときも、同じ記号 F を使う。

定理3.8.1 — 極限は極限と交換する

極限が存在すると仮定して、lim(i,j)∈I×J F(i, j) が段階的に、しかもどちらの順序でも計算できることを示す。各 i ∈ I について limj∈J F(i, j) が存在するなら、命題3.3.1 により、これらの対象は図式 limj∈J F(−, j) : I → C の値になる。この図式の極限 limi∈I limj∈J F(i, j) が存在するなら、それは lim(i,j)∈I×J F(i, j) と同型である。もう一方の順序の途中の極限も存在するなら、さらに limj∈J limi∈I F(i, j) とも同型である。

定理3.8.1. 図式 F : I × J → C に付随する繰り返し極限 limI limJ F と limJ limI F が C に存在するならば、両者は同型であり、極限 limI×J F を定める。

例. I = • ⇉ • を等化子の図式の添字圏、J = • → • ← • を引き戻しの図式の添字圏とする。I の対象を 0, 1、J の対象を a → b ← c と名付けると、積圏 I × J は次の形をしている。各行が J の形（引き戻しの図式）、各列の 2 本の平行な射が I の形（等化子の図式）である。

定理3.8.1 によると、この形の図式 F の極限は、次の二通りのどちらでも作れる。

  • limI limJ F（先に引き戻し）. 各行の引き戻し P0 = F(0, a) ×F(0, b) F(0, c) と P1 = F(1, a) ×F(1, b) F(1, c) を作る。各列の平行な 2 本の射は、引き戻しの普遍性により平行な 2 本の射 P0 ⇉ P1 を誘導する。その等化子 E を取る。
  • limJ limI F（先に等化子）. 3 つの列それぞれの平行な対の等化子 Ea, Eb, Ec を作る。各行の射は、等化子の普遍性により射 Ea → Eb ← Ec を誘導する。その引き戻し L を取る。

定理3.8.1 により、E と L はどちらも F の極限であり、互いに同型である。

定理3.8.1 の証明. 圏の積は対称 I × J ≅ J × I なので、limI limJ F ≅ limI×J F を示せば十分である。もう一方の limJ limI F ≅ limI×J F は、同じ主張を、変数を入れ替えた図式 J × I ≅ I × J → C に当てはめたものだからである。米田の補題により、二つの対象が SetCop の自然同型な関手を表現することを示せば十分である。

定義3.1.5 により、F ∈ CI×J の極限は F 上の錐の関手を表現する。添字圏を明示するため、この関手を CI×J(ΔI×J(−), F) と書く。対象 c を、頂点 c の錐、すなわち定数関手 ΔI×J(c) から F への自然変換の集合に送る関手である。ここに現れる定数図式の関手は、次の可換図式に収まる。

これを使うと、次の自然同型の列が得られる。

C(−, limI×J F) ≅ CI×J(ΔI×J(−), F)
≅ (CI)J(ΔJ(ΔI(−)), F)
≅ CI(ΔI(−), limJ F)
≅ C(−, limI limJ F)

各同型の理由は次のとおりである。

  • 1 番目は、limI×J F が F の極限であること、すなわち定義3.1.5 の普遍性そのものである。
  • 2 番目は、圏同型 CI×J ≅ (CI)J が充満忠実であることと、上の四角形の可換性による。同型は hom 集合の全単射を与え、その全単射で ΔI×J(c) は ΔJ(ΔI(c)) に、F は J → CI と見た F に対応する。
  • 3 番目は、F を図式 J → CI と見たときの、CI における極限の普遍性である。この極限 limJ F は、各 i で limj∈J F(i, j) を取った図式 I → C であり、関手圏の極限は各点で計算される（命題3.4.9）。
  • 4 番目は、図式 limJ F : I → C の極限 limI limJ F の普遍性である。

米田の補題により、limI×J F ≅ limI limJ F が従う。□

(3.8.2) — 極限関手の交換

定理3.8.1 とその双対により、極限は極限と、余極限は余極限と、同型を除いて交換する。極限と余極限の普遍性に含まれる一意性から、さらに次の自然同型が存在する。極限関手と余極限関手をどう選んでも成り立つ。

すなわち、関手 CI×J → C として limI ∘ limJ ≅ limJ ∘ limI であり、余極限についても同様である。

補題3.8.3 — colim lim から lim colim への標準的な射

一方の変数で極限を、もう一方の変数で余極限を取る操作の関係は、もっと微妙である。これらの操作が交換することはまれである。それでも、比較のための標準的な射は常にある。

補題3.8.3. 双関手 F : I × J → C について、以下に現れる極限と余極限が存在するならば、標準的な射

κ : colimi∈I limj∈J F(i, j) → limj∈J colimi∈I F(i, j)

がある。

射の向きは次のように覚えるとよい。余極限は「そこから出て行く射」で特徴づけられる普遍性で定義され、極限は「そこへ入って来る射」で特徴づけられる普遍性で定義される。κ の定義域は余極限なので、そこから出る射は普遍性で作れる。値域は極限なので、そこへ入る射も普遍性で作れる。

証明. 余極限の普遍性により、κ を定めるには、成分

κi : limj∈J F(i, j) → limj∈J colimi′∈I F(i′, j)　（i ∈ I）

で、I で添字づけられた図式 limj∈J F(−, j) の下の錐をなすものを指定すればよい。極限の普遍性により、各成分 κi を定めるには、さらに成分

κi,j : limj′∈J F(i, j′) → colimi′∈I F(i′, j)　（j ∈ J）

で、J で添字づけられた図式 colimi′∈I F(i′, −) の上の錐をなすものを指定すればよい。κi,j を合成

κi,j : limj′∈J F(i, j′) —πi,j→ F(i, j) —ιi,j→ colimi′∈I F(i′, j)

と定める。ここで πi,j は F(i, −) の極限錐の脚、ιi,j は F(−, j) の余極限錐の脚である。

図式 limj∈J F(−, j) の射と図式 colimi∈I F(i, −) の射は、どちらも I の射 i → i′ と J の射 j → j′ に F を適用した射 F(i, j) → F(i′, j′) から誘導される。そのため、κi,j たちは錐をなして κi を定め、κi たちは錐をなして κ を定める。具体的には、次の 2 つが成り立つ。

  • J の射 g : j → j′ について、colimi′ F(i′, g) ∘ κi,j = κi,j′。π と ι がそれぞれ錐であることから、両辺とも ιi,j′ ∘ F(i, g) ∘ πi,j = ιi,j′ ∘ πi,j′ に等しい。
  • I の射 f : i → i′ について、κi′ ∘ limj F(f, j) = κi。両辺を極限 limj colimi′ F(i′, j) の各脚で比べると、ιi′,j ∘ F(f, j) = ιi,j と、limj F(f, j) の定義 πi′,j ∘ limj F(f, j) = F(f, j) ∘ πi,j から等しい。

□

系3.8.4 — sup inf ≤ inf sup

C を poset の圏 (ℝ, ≤) に特殊化すると、直ちに次の系が得られる。この圏では、極限は下限 inf、余極限は上限 sup であり、射 x → y の存在は x ≤ y を意味する。集合 X, Y を離散圏と見て、関数 f : X × Y → ℝ を双関手と見る。

系3.8.4. 任意の集合 X, Y と任意の関数 f : X × Y → ℝ について、以下の下限と上限が存在するならば

supx∈X infy∈Y f(x, y) ≤ infy∈Y supx∈X f(x, y)

が成り立つ。

証明. poset の圏に射 κ : supX infY f → infY supX f があることが、この不等式を意味する。□

注意3.8.5 — 解析学での直接の証明

実解析の講義で示されるような系3.8.4 の直接の証明は、実は補題3.8.3 の圏論的な証明と同じものである。

  • supX infY f がある量 q 以下であることを示すには、上限の普遍性と呼べる性質により、各 x ∈ X について infY f(x, −) が q 以下であることを示せば十分である。これは余極限の普遍性で κ を成分 κx から定めたことに当たる。
  • 双対に、infY supX f がある量 q 以上であることを示すには、各 y ∈ Y について supX f(−, y) が q 以上であることを示せば十分である。これは極限の普遍性で κx を成分 κx,y から定めたことに当たる。

したがって、各 x ∈ X と y ∈ Y について infY f(x, −) ≤ supX f(−, y) を示せばよい。これは不等式

infY f(x, −) ≤ f(x, y) ≤ supX f(−, y)

の推移律、すなわち射の合成 κx,y = ιx,y ∘ πx,y から従う。

例3.8.6 — 下極限と上極限

拡大実数直線 ℝ̄ = ℝ ∪ {−∞, ∞} に、すべての x ∈ ℝ について −∞ ≤ x ≤ ∞ とする順序を入れる。圏として ℝ̄ は完備かつ余完備である。関数 f : X → ℝ̄ の極限はその下限であり、余極限はその上限である。f の値域が有界なら、これらは通常の実数である。拡大した圏 ℝ̄ で考える利点は、有界性の仮定を気にせずに済み、すべての極限と余極限が存在することである。

関数 x : ℕ → ℝ は実数列 (xn)n∈ℕ を定める。下極限 lim inf と上極限 lim sup は、この数列を、離散圏 ℕ × ℕ で添字づけられた双関手

ℕ × ℕ —+→ ℕ —x→ ℝ̄,　(n, m) ↦ xn+m

と見ることで定義される。

lim infn→∞ xn = supn≥0 infm≥n xm = supn≥0 infm≥0 xn+m = colimn limm xn+m
lim supn→∞ xn = infn≥0 supm≥n xm = infn≥0 supm≥0 xn+m = limn colimm xn+m

2 番目の等号は、m ≥ n を m = n + m′（m′ ≥ 0）と書き直したものである。解析の概念をこのように圏論の言葉に翻訳すると、補題3.8.3 は不等式

lim infn→∞ xn ≤ lim supn→∞ xn

の形で当てはまる。ここで補題3.8.3 の I は外側の n、J は内側の m の離散圏であり、lim sup の式は limn colimm の順になっている。2 変数 (n, m) ↦ xn+m は n と m について対称なので、limm colimn xn+m と同じ値になり、補題3.8.3 の κ の値域と一致する。数列の極限が（ℝ̄ で）存在することと、この不等式が等式であることは同値である。

フィルター圏

Set やそれに関連する圏では、ある種類の極限と余極限について、補題3.8.3 で定義した射が可逆になる。定理3.8.9 はそのような結果で最も有名なものである。網羅的な概観は [BJLS15] にある。

定義3.8.7. 圏 J がフィルター圏（filtered）であるとは、J の任意の有限な図式の下に錐があることである。22

有限な図式とは、有限個の射しか持たない圏で添字づけられた図式である。特に、空な図式の下の錐は J の対象 1 つにすぎないので、フィルター圏は空でない。

例3.8.8. 圏 ω（より一般に、空でない任意の順序数の圏）と、1 つの対象と恒等射でない冪等射を 1 つだけ持つ圏はフィルター圏である。平行な対の圏 • ⇉ •、スパンの圏 • ← • → •、𝟙 以外の離散圏はフィルター圏でない。

本文は理由を述べていないので、それぞれを確かめておく。

  • ω. 有限な図式に現れる対象は有限個なので、その最大のものを t とする。各対象 n ≤ t から t への射はちょうど 1 本あり、射が高々 1 本なので錐の条件は自動的に成り立つ。空な図式には対象 0 を頂点とすればよい。
  • 冪等射 e を持つ 1 対象圏. 対象を ∗ とし、e ∘ e = e とする。どの有限な図式についても、すべての脚を e とする頂点 ∗ の錐が作れる。図式の射 φ は id か e であり、e ∘ id = e、e ∘ e = e なので、錐の条件 e ∘ φ = e が成り立つ。
  • 平行な対 f, g : 0 ⇉ 1. この 2 本の射からなる図式自身の下の錐を考える。頂点 t へ対象 1 から射が出ている必要があるが、1 から出る射は id1 だけなので t = 1 で、脚 u = id1 である。錐の条件 u ∘ f = u ∘ g は f = g を要求するが、これは成り立たない。
  • スパン b ← a → c. 2 対象 b, c からなる射のない図式の下の錐は、b と c の両方から射を受ける対象を要する。しかし b, c から出る射は恒等射だけなので、そのような対象はない。
  • 𝟙 以外の離散圏. 対象がなければ空な図式の下の錐がない。対象が 2 つ以上あれば、スパンと同じ理由で、異なる 2 対象からなる図式の下の錐がない。

22 この定義は、最小の無限基数 ω を正則基数 κ に置き換えて一般化できる。圏が κ-フィルター圏であるとは、射が κ 個より少ない任意の図式の下に錐があることである。

定理3.8.9 — Set ではフィルター余極限は有限極限と交換する

定理3.8.9. Set において、フィルター余極限は有限極限と交換する。

証明の中心にあるのは次の観察である。F : J → Set を、小さなフィルター圏で添字づけられた図式とする。このとき colimj∈J Fj は、余積 ∐j∈J Fj を次の同値関係で割った商である。x ∈ Fj と y ∈ Fk を同一視するのは、J の射 f : j → t と g : k → t で F f(x) = F g(y) となるものがあるとき、かつそのときに限る。より一般に、∐j∈J Fj の要素の有限個の集まりで、colimj∈J Fj で互いに同一視されるものは、ある Ft の共通の要素に送られる。

Set の余極限は一般に、余積を「F f(x) と x を同一視する」関係が生成する同値関係で割った商である（命題3.6.1 の構成）。生成された同値関係では、x と y の同一視に射のジグザグ（向きの交互する射の列）が要る。J がフィルター圏なら、ジグザグに現れる対象と射からなる有限な図式の下に錐が取れるので、すべてを 1 つの対象 t に送ってジグザグを解消できる。上の記述はこうして得られる。

証明. I を有限な圏、J を小さなフィルター圏とする。示すべきことは、任意の関手 F : I × J → Set について、標準的な射

κ : colimj∈J limi∈I F(i, j) → limi∈I colimj∈J F(i, j)

が全単射であることである。補題3.8.3 と比べると、余極限を取る変数が J、極限を取る変数が I になっていて、I と J の役割が入れ替わっている。

全射性. 定義3.2.3 により、右辺の要素は、図式 colimj∈J F(−, j) : I → Set の上の、頂点 ∗ の錐 λ である。I は有限なので、このような錐は、有限個の要素 λi ∈ colimj∈J F(i, j) の族で、有限個の両立条件（I の各射 i → i′ について、λi の像が λi′ であること）を満たすものである。J はフィルター圏なので、十分「大きな」 t ∈ J があって、各 i ∈ I について λi は要素 λ′i ∈ F(i, t) で代表され、しかもこれらの要素が錐

(λ′i : ∗ → F(i, t))i∈I

をなす。ここでフィルター性は二度使われる。まず、各 λi の代表元が住む有限個の対象 ji を共通の t に送る。次に、有限個の両立条件のそれぞれは colim で成り立つ等式なので、上の観察により、ある対象に送れば F の中で成り立つ等式になる。それら有限個の対象をさらに共通の t に送る。この錐は limi∈I F(i, t) の要素を定め、それは左辺の要素を代表する。その要素は κ で、選んだ右辺の要素に送られる。したがって κ は全射である。

単射性. 左辺の 2 要素が、ある j, k ∈ J について、錐

(αi : ∗ → F(i, j))i∈I　と　(βi : ∗ → F(i, k))i∈I

で代表されているとする。これらの κ による像が等しいなら、各 i ∈ I について、αi と βi は colimj∈J F(i, j) で等しいので、上の観察により、ある ti ∈ J があって αi と βi は F(i, ti) で共通の像を持つ。I は有限で J はフィルター圏なので、ある t ∈ J があって、すべての i について αi と βi は F(i, t) で共通の像を持つ。これは、α と β が左辺の同じ要素を代表することを言っている。したがって κ は単射である。□

定理3.8.9 の証明は圏論的なものではない。議論は、集合の圏におけるフィルター余極限の具体的な記述に依存している。しかし、第5章で導入する広いクラスの圏、すなわち代数理論のモデルの圏では、極限とフィルター余極限は集合の圏から創出される（定理5.6.5）。したがって、これらの圏でも有限極限とフィルター余極限は交換する。
