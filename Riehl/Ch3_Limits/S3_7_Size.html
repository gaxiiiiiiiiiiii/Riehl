この節の問い

定義3.2.1 で、圏が完備であるとは、定義域が小圏であるような任意の図式の極限を持つことだった。この節は、なぜ添字圏の大きさをこう制限するのかを説明する。

答えの要点は命題3.7.3 にある。添字圏の大きさを制限せずに極限を要求すると、それを満たす圏は、どの 2 対象の間にも射が高々 1 本しかない圏（前順序）に限られてしまう。その一方で、大きな図式でも極限を持つものはある。その準備として、まず恒等関手の極限を調べる。

補題3.7.1 — 恒等関手の極限と始対象

始対象は空な図式の余極限として定義されたものだった。少し意外なことに、始対象は恒等関手の極限としても特徴づけられる。恒等関手 idC : C → C は C 全体を添字圏とする図式なので、C が小圏でなければ、これは大きな図式の極限の例になる。

idC 上の錐 λ : Δℓ ⇒ idC のデータは、頂点 ℓ ∈ C と、各対象 c ∈ C への脚 λc : ℓ → c の族である。錐の条件は、図式 idC の各射 f : c → d、すなわち C の各射 f について f ∘ λc = λd が成り立つことである。頂点 ℓ もまた C の対象なので、ℓ 自身で添字づけられた脚 λℓ : ℓ → ℓ がある。

補題3.7.1. 任意の圏 C について次が成り立つ。
  • (i) 恒等関手上の任意の錐の頂点は、C の弱始対象である。すなわち、すべての対象 c ∈ C へ少なくとも 1 本の射を持つ。さらに、頂点の対象で添字づけられた錐の脚が恒等射ならば、その錐は極限錐であり、頂点は C の始対象である。
  • (ii) 恒等関手 idC : C → C が極限を持つことと、C が始対象を持つことは同値である。

証明. まず (i) を示し、その結果を使って (ii) の順方向を示す。

(i) 錐 λ : Δℓ ⇒ idC を考える。各対象 c について脚 λc : ℓ → c が ℓ から c への射なので、頂点 ℓ は弱始対象である。

次に、λℓ = idℓ と仮定して、λc が ℓ から c への唯一の射であることを示す。任意の射 f : ℓ → c をとる。f は C の射なので、図式 idC の射 f : ℓ → c でもある。この射における錐の条件は、下の三角形が可換であること、すなわち f ∘ λℓ = λc である。

λℓ = idℓ なら、この等式は f = λc を意味する。したがって ℓ から c への射は λc ただ 1 本であり、ℓ は始対象である。本文の (i) の証明はここまでである。錐 λ が極限錐であることは、(ii) の逆方向の証明で示す「始対象 i からの唯一の射たちがなす錐は極限錐である」を i = ℓ に当てはめれば従う。いま λc は ℓ から c への唯一の射なので、λ はまさにその錐だからである。

(ii) の順方向. λ : Δℓ ⇒ idC が極限錐であると仮定する。(i) により、λℓ = idℓ を示せばよい。上の三角形で f として脚 λc 自身をとる。λc を図式 idC の射 ℓ → c と見ると、錐の条件から

λc ∘ λℓ = λc（すべての c ∈ C について）

が得られる。この等式は、射 λℓ : ℓ → ℓ が錐 λ をそれ自身を通して分解していることを言っている。つまり、λ の各脚に λℓ を前から合成すると、再び λ の脚に戻る。恒等射 idℓ も同じ性質を持つ。λ は極限錐なので、このような分解は一意であり、λℓ = idℓ が結論される。

(ii) の逆方向. C が始対象 i を持つと仮定する。各対象 c について、i から c への唯一の射を ιc : i → c とおく。これらは idC 上の錐 ι : Δi ⇒ idC をなす。錐の条件 g ∘ ιc = ιd（g : c → d）は、両辺がともに i から d への射であり、そのような射は 1 本しかないことから成り立つ。同じ理由で、対象 i における成分 ιi : i → i は恒等射である。

別の錐 λ : Δℓ ⇒ idC が与えられたとする。対象 i における脚 λi : ℓ → i が、λ を ι を通して分解することを示す。すなわち、すべての c について ιc ∘ λi = λc を示す。錐 ι の脚 ιc : i → c は、C の射なので図式 idC の射でもある。したがって、この射における錐 λ の条件が、下の三角形の可換性 ιc ∘ λi = λc そのものである。

一意性を示す。射 h : ℓ → i が λ を ι を通して分解するとき、すべての c について ιc ∘ h = λc である。c = i の成分を見ると、ιi = idi なので h = λi となる。したがって λi は λ を ι を通して分解する唯一の射であり、ι は極限錐、始対象 i は恒等関手の極限である。□

完備性の定義には大きさの制限が入っているので、完備な（大きな）圏が始対象を持つとは限らない。恒等関手 idC の添字圏は C 自身であり、C が小圏でなければ、完備性はこの図式の極限を保証しないからである。

定義3.7.2 — 小圏の濃度

では、C が小圏なら完備性から始対象が得られるかというと、完備な小圏はめったにない。その理由を述べるために、小圏の大きさを正確に定義する。

定義3.7.2. 小圏の濃度（cardinality）とは、その射全体の集合の濃度である。

小さな図式の濃度とは、その添字圏の濃度である。次の結果は、圏が持つ極限や余極限が、たいてい自分より小さい図式のものに限られる理由を説明する。

命題3.7.3（Freyd） — 大きな積を持つ小圏は前順序である

命題3.7.3（Freyd）. 自身の濃度と同じ大きさの対象の族の積を持つ圏は、前順序である。

濃度は定義3.7.2 で小圏についてだけ定義されたので、この命題は小圏についての主張である。前順序とは、どの 2 対象の間にも射が高々 1 本しかない圏のことだった。

証明. 小圏 C の射全体の集合の濃度を κ とする。C が前順序でないと仮定して矛盾を導く。このとき、平行な射の対 f, g : B ⇉ A で f ≠ g となるものがある。

対象 A の κ 個の複製の積、すなわち冪 Aκ を考える（例3.5.4）。積の普遍性により、射 B → Aκ を与えることは、κ で添字づけられた射 B → A の族、すなわち各成分を与えることと同じであり、成分の族が異なれば射も異なる。そこで κ の各部分集合 S について、S に属する添字の成分を f、それ以外の添字の成分を g とする射 B → Aκ をとる。f ≠ g なので、異なる部分集合からは異なる射が得られる。こうして、成分がそれぞれ f または g であるような互いに異なる射 B → Aκ が 2κ 本得られる。Cantor の対角線論法により 2κ > κ なので、

|Hom(B, Aκ)| ≥ 2κ > κ = |mor C|

となる。ところが Hom(B, Aκ) は mor C の部分集合なので、その濃度は |mor C| 以下でなければならない。これは矛盾である。□

C が代わりに濃度 κ の余冪 A ⋅ κ を持つなら、双対の構成で同様の矛盾が得られる。すなわち、射 A ⋅ κ → B は κ で添字づけられた射 A → B の族と同じことであり、平行な射 f ≠ g : A ⇉ B があれば、それが 2κ 本の異なる射を与える。

一方、命題3.6.10 が示すように、前順序であれば、大きさを制限しないすべての極限や余極限を持つことはありうる。poset P が圏としてこの性質を持つことと、P が完備束であることは同値である。

命題3.7.3 の証明から分かるように、2 本の異なる平行な射を持つ圏では、大きな極限や大きな余極限は一般には存在しない。それでも、補題3.7.1 とその双対が示すように、特定の大きな図式は極限や余極限を持ちうる。最後に、集合の大きな族の例を 2 つ考える。一方は積を持ち、他方は持たない。

例3.7.4 — Set における大きな積

例3.7.4. Set では、集合の大きな族のうち積を持つものもあれば、持たないものもある。

すべての集合の積は存在する. すべての集合を対象とする離散図式を考える。この図式の上の錐は、頂点 X と、すべての集合 Y への関数 X → Y の族である。この図式には空集合 ∅ が現れるので、錐は脚 X → ∅ を持つ。値域が空集合である関数は、定義域も空集合のときにしか存在しない。したがって、この図式の上の錐の頂点は必ず空集合である。空集合は Set の始対象なので、頂点 ∅ を持つ錐は 1 つしかない。各脚が空関数 ∅ → Y で決まるからである。こうしてこの図式の上の錐はただ 1 つであり、その錐は自分自身を通して恒等射 id∅ によって一意に分解するので、極限錐である。つまり、すべての集合の積は ∅ である。

空でないすべての集合の積は存在しない. 背理法で示す。空でないすべての集合からなる離散図式の積の錐があり、頂点を P、脚を πX : P → X（X は空でない集合）とする。冪集合 𝒫(P) は ∅ を要素に持つので空でなく、この図式に現れる。そこで脚 π𝒫(P) : P → 𝒫(P) を考える。Cantor の対角線論法により、関数 P → 𝒫(P) は全射でない。実際、D = { p ∈ P | p ∉ π𝒫(P)(p) } は像に入らない。したがって、π𝒫(P) の像に入らない要素 d ∈ 𝒫(P) が少なくとも 1 つある。

𝒫(P) では要素 d を選び、図式に現れる他の空でない集合からは、大域選択公理を使ってそれぞれ要素を 1 つずつ選ぶ。ここで通常の選択公理でなく大域選択公理を使うのは、空でない集合全体は集合でなく類であり、その各要素から一斉に選ぶ必要があるからである。選んだ要素たちは、一点集合 ∗ を頂点とし、各集合 X への脚 ∗ → X がその選んだ要素を指す錐を定める。この錐が π を通して分解するなら、ある関数 u : ∗ → P があって、π𝒫(P)(u(∗)) = d とならなければならない。しかし d は π𝒫(P) の像に入らないので、そのような u はない。これは π が積の錐であることに矛盾する。
