この節の問い

定理3.2.11 は、Set の図式の極限を積の間の等化子として表す公式である。この節では、任意の圏の図式の極限と余極限について同じ公式を証明する。証明は Set の極限の場合に帰着させる。帰着が可能なのは、局所小圏の極限と余極限が、Set の極限によって表現可能に定義されているからである。この節の目的は、まずこの標語の意味を説明し、次に応用として定理3.5.11 を導くことである。

錐の集合としての limJ C(X, F−)

局所小圏 C の小図式 F : J → C と対象 X ∈ C を固定し、合成関手 C(X, F−) := C(X, −) ∘ F : J → Set を考える。これは Set の J 型の図式である。定理3.2.4 により C(X, F−) の極限は存在し、定理3.2.11 がその構成を与える。集合 limJ C(X, F−) の要素は、積 ∏j∈J C(X, Fj) の要素、すなわち射の組 (λj : X → Fj)j∈J であって、J の恒等射でない各射 f : j → k について次の図式が可換になるものである。

すなわち limJ C(X, F−) の要素とは、頂点 X を持つ F 上の錐にほかならない。よって次の同型がある。15

limJ C(X, F−) ≅ Cone(X, F)　　(3.5.1)

この同型は X について自然である。これは演習3.5.i で確かめる。F の極限は関手 Cone(−, F) を表現する対象として定義されていたので、次の定理が従う。

15 この同型は、極限が存在する大きな図式にも拡張される。任意の図式 F : J → C について、limJ C(X, F−) の要素は頂点 X を持つ F 上の錐にほかならない。

定理3.5.2 — 共変表現可能関手は極限を保存する

定理3.5.2. 極限が存在する任意の図式 F : J → C について、極限錐が誘導する標準的な写像は、各 X ∈ C について自然な同型

C(X, limJ F) ≅ limJ C(X, F−)　　(3.5.3)

を定める。したがって共変表現可能関手 C(X, −) : C → Set は、局所小圏 C に存在する任意の極限を保存し、Set の極限に写す。

証明. §3.4 の冒頭で述べたとおり、C(X, −) : C → Set のような関手を極限錐に適用すると、C の極限の像から、Set における図式の像の極限へ向かう標準的な写像が得られる。これが写像 C(X, limJ F) → limJ C(X, F−) を X について自然に定める。

残るのは、この写像が同型であることである。そのためには、この写像が次の可換図式に収まることを示せば十分である。

左上の辺が示したい標準的な写像、右上の辺は極限錐の普遍性（定義3.1.5）を表す自然同型 C(X, limJ F) ≅ Cone(X, F)、中央の横の辺は先ほど示した自然同型 (3.5.1) である。

上の三角形は SetCop の関手の間の自然変換の図式である。その可換性は米田の補題で示せる。米田の補題により、表現対象 limJ F における恒等射の像を比べれば十分だからである。別の示し方もある。三つの写像はいずれも積 ∏j∈J C(X, Fj) への包含と可換であり、その包含はモノ射なので、上の三角形の可換性が従う。

標準的な写像は、二つの同型を含む可換な三角形の一辺なので、同型である。最後に補題3.4.3 により、この写像が可逆であることは、X が表現する共変関手が F の極限を保存することを意味する。□

自然同型 (3.5.3) は極限の表現可能な普遍性（representable universal property of the limit）を表す。局所小圏 C の J 型の図式の極限は、Set に値を取る J 型の図式の極限として表現可能に定義される。

例3.5.4 — 冪

対象 A ∈ C の反復した積を冪（power）または cotensor という。集合 I について、I で添字づけられた A の冪を ∏I A または AI と書く。表現可能な普遍性は次の自然同型で表される。

C(X, AI) ≅ C(X, A)I

すなわち、射 h : X → AI は、各射影 evi : AI → A と合成して得られる I で添字づけられた射の族 hi : X → A によって決まる。Set では、この記法は以前に導入した指数記法と整合する。冪 AI は I から A への関数の集合と同型で、射影 evi : AI → A は各関数を i ∈ I で評価する。

定理3.5.5 — 米田埋め込みは極限を保存し反映する

定理3.5.2 には、明示する価値のある別の読み方がある。F : J → C の極限が表現する反変関手 C(−, lim F) を圏 SetCop の対象と見ると、それは合成図式 よ ∘ F : J → C → SetCop の極限である。この図式の対象は表現可能関手 C(−, Fj) である。これは命題3.4.9 から従う。命題3.4.9 により SetCop の極限は Set で各点ごとに定義されるので、limj∈J C(−, Fj) は X ∈ C での値が limj∈J C(X, Fj) である関手だからである。

簡潔に言えば、米田埋め込み よ : C ↪ SetCop は C に存在するすべての極限を保存する。さらに米田の補題により米田埋め込みは充満忠実なので、補題3.4.5 により よ はすべての極限を反映もする。まとめると次が示された。

定理3.5.5. C を任意の局所小圏とする。
  1. 共変表現可能関手 C(X, −) は、C に存在するすべての極限を保存する。
  2. 共変米田埋め込み よ : C ↪ SetCop は極限を保存し、かつ反映する。すなわち、C の図式上の錐が極限錐であることと、その像が SetCop の極限錐であることは同値である。

共変米田埋め込みは極限を創出はしない。演習3.5.ii を参照。

定理3.5.6 — 反変表現可能関手は余極限を極限に写す

余極限の表現可能な特徴づけは、ここまでの議論を双対化して得られる。F : J → C と X ∈ C を固定し、合成関手 C(F−, X) := C(−, X) ∘ Fop : Jop → Set を考える。定理3.2.4 により極限が存在し、定理3.2.11 がその構成を与える。集合 limJop C(F−, X) の要素は、積 ∏j∈J C(Fj, X) の要素、すなわち射の組 (λj : Fj → X)j∈J であって、J の恒等射でない各射 f : j → k について次の図式が可換になるものである。

すなわち limJop C(F−, X) の要素とは、頂点 X を持つ F 下の錐にほかならない。同型

limJop C(F−, X) ≅ Cone(F, X)

はやはり X について自然であり、次が従う。

定理3.5.6. 余極限が存在する任意の図式 F : J → C について、余極限錐が誘導する標準的な写像は、各 X ∈ C について自然な同型

C(colimJ F, X) ≅ limJop C(F−, X)

を定める。したがって反変表現可能関手 C(−, X) : Cop → Set は、局所小圏 C に存在する任意の余極限を Set の極限に写す。

定理3.5.6 は余極限の表現可能な普遍性（representable universal property of the colimit）を表す。圏 C の J 型の図式の余極限は、Set に値を取る Jop 型の図式の極限として表現可能に定義される。

例3.5.7 — 余積

局所小圏 C の任意の三つの対象 X, Y, Z について、余積の表現可能な普遍性は次の自然同型の形を取る。

C(X ⊔ Y, Z) ≅ C(X, Z) × C(Y, Z)

余積からの射の集合が、hom 集合の対の積として表されている。これは演習2.4.x で出した問いへの答えである。

例3.5.8 — 余冪

対象 A ∈ C の反復した余積を余冪（copower）またはテンソル（tensor）という。集合 I について、I で添字づけられた A の余冪を ∐I A または I · A と書く。表現可能な普遍性は次の自然同型で表される。

C(∐I A, X) ≅ C(A, X)I

すなわち、射 h : ∐I A → X は、各入射 ιi : A → ∐I A と合成して得られる I で添字づけられた射の族 hi : A → X によって決まる。Set では、余冪 ∐I A は定数族の依存和 Σi∈I A と同型であり、それは積 I × A と同型である。

定理3.5.10 — 反変米田埋め込みは余極限を保存し反映する

定理3.5.5 を双対化すると次を得る。

定理3.5.10. C を任意の局所小圏とする。
  1. 反変表現可能関手 C(−, X) は、C の余極限を Set の極限に写す。
  2. 反変米田埋め込み よ : Cop ↪ SetC は Cop の極限を保存し、かつ反映する。すなわち、C の図式下の錐が余極限錐であることと、その像が SetC の極限錐であることは同値である。

定理3.5.11 — 余極限は余積の間の余等化子である

定理3.5.5 と定理3.5.10 を使って、定理3.2.11 を一般化する。定理3.2.11 は Set の極限を積の間の写像の対の等化子として構成した。これを任意の圏に拡張し、双対性の原理により余極限にも拡張する。

定理3.5.11. 任意の小図式 F : J → C の余極限は、余積の間の射の対の余等化子として表せる。ただし、これらの余極限が存在するとする。 特に、小さな余積と余等化子を持つ任意の圏は余完備である。双対に、任意の小図式の極限は、積の間の射の対の等化子 (3.2.12) として表せる。ただし、これらの極限が存在するとする。したがって、小さな積と等化子を持つ任意の圏は完備である。

証明では C が局所小であることを暗に仮定する。より大きな集合論的宇宙に移れば、より大きな圏にも議論を拡張できる。

証明. 図式 F : J → C を取り、C が余等化子と小さな余積を持つとする。注意3.2.13 の構成を双対化して、J の射で添字づけられた余積と J の対象で添字づけられた余積の間に、射 d と c を次のように定める。

f ∈ mor J における d の成分は余積の入射 ιdom f であり、f における c の成分は Ff と余積の入射 ιcod f の合成である。仮定により、d と c の余等化子 C が C に存在する。この C が F の余極限であることを示す。

定理3.5.10(ii) により、米田埋め込み よ : Cop → SetC は余等化子図式 (3.5.12) を SetC の等化子図式に写す。

これは、X を変数とする関手と自然変換の図式である。この等化子図式の各対象に定理3.5.10(i) を適用すると、SetC において同型な次の図式を得る。C(−, X) は余積の入射を積の射影に写す。f を Jop の射と見ると域と余域が入れ替わるので、以下では J の射 f : j → k について dom f = k、cod f = j と読み、写像 C(d, X) を c、写像 C(c, X) を d と書く。

X を固定すると、命題3.4.9 により (3.5.13) は Set の等化子図式である。定理3.2.11 を関手 C(F−, X) : Jop → Set に適用すると、(3.5.13) はその等化子が極限 limJop C(F−, X) を定める図式にほかならない。よって各 X ∈ C について次の同型を得る。

limJop C(F−, X) ≅ C(C, X)

各 X ∈ C について定まるこれらの同型は、Setob C の同型をなす。そこで命題3.4.9 を忘却関手 ev : SetC → Setob C に適用して、C(C, −) が共変関手 C(Fj, −) からなる Jop 型の図式の極限であると結論する。定理3.5.6 により、余等化子 C は F : J → C の余極限である。□

注意3.5.14 — 一般化された要素

定理3.5.11 は直接にも証明できる。C の中で図式 (3.5.12) を構成し、c と d の余等化子が colimJ F を定義する普遍性を持つことを確かめればよい。この直接の証明は、極限を特徴づける双対の設定で見ると、上で取った戦略、すなわち結果をまず Set で確かめてから表現可能性を適用する戦略と、ある意味でよく似ている。その意味を与えるのが一般化された要素の哲学（philosophy of generalized elements）である。これを最初に明確に述べたのは Lawvere [Law05] である。

集合 A の要素は、Set の射 a : ∗ → A と一対一に対応する。Set の写像 f : A → B は合成によって要素に作用する。合成 fa が要素 f(a) を表す。16 任意の圏 C において、対象 A の X 型の一般化された要素（generalized element）とは、余域が A である射 a : X → A のことである。C の射 f : A → B は合成によって X 型の要素に作用する。合成 fa は B の X 型の一般化された要素である。この用語で言えば、反変表現関手 C(−, A) : Cop → Set は、対象 X を A の X 型の一般化された要素の集合に送る。米田埋め込み よ : C ↪ SetCop は充満忠実なので、A の代わりに、あらゆる型 X にわたる A の一般化された要素の関手 C(−, A) を考えても、A についての情報は失われない。

16 関数の標準的な記法が、通常の合成の順序の由来である。

特に、平行な射の対 f, g : A ⇉ B が等しいことを示すには、f と g が一般化された要素に同じ関数を誘導することを示せば十分である。また、頂点 A を持つ錐が極限錐であることを示すには、あらゆる型の一般化された要素について、誘導される関数が Set の極限錐を定めることを示せば十分である。この議論が極限の表現可能な普遍性を確立する。この「図式なしで済ませる」原理をより高度な文脈に応用した例が [Lei08] にある。

この節の残りでは、一般化された要素の哲学の非形式的な例示として、有限積と等化子が終対象 ∗ と引き戻しの反復から構成できることを示す。

補題3.5.15 — 引き戻しからの積

補題3.5.15. 終対象 ∗ を持つ任意の圏において、引き戻しの図式 は A と B の積 A × B を定める。より一般に、I で添字づけられた対象の族 (Ai)i∈I の積は、射の族 (! : Ai → ∗)i∈I が定める図式の広い引き戻し（wide pullback）として構成できる。

証明. 射の族 (! : Ai → ∗)i∈I からなる図式の上の、頂点 X を持つ錐は、I で添字づけられた射の族 (λi : X → Ai)i∈I というデータで与えられる。図式のすべての射の余域が終対象なので、可換性の条件はない。同じデータが、対象の族 (Ai)i∈I の上の頂点 X を持つ錐を定める。よって二つの極限は同型である。□

したがって、引き戻しと終対象を持つ任意の圏は、すべての二項積を持ち、反復によってすべての有限積を持つ。

補題3.5.16. 二項積を持つ任意の圏において、引き戻しの図式 は平行な対 f, g : A ⇉ B の等化子を定める。

Hom(X, B × B) ≅ Hom(X, B) × Hom(X, B)

定理3.5.17 — 有限極限

図式が有限（finite）であるとは、その添字圏の射が有限個であることをいう。補題3.5.15 と補題3.5.16 から次が従う。

定理3.5.17. 引き戻しと終対象を持つ任意の圏は、すべての有限極限を持つ。双対に、押し出しと始対象を持つ任意の圏は、すべての有限余極限を持つ。
