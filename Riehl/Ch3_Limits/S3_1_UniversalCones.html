第3章の導入

実数直線 ℝ という一つの空間から、位相空間論はおびただしい数の空間を作り出す。ℝ 同士の積を取ればユークリッド空間 ℝn ができる。連続写像の対 f, g : ℝn → ℝm が一致する点の集まりとして、球面 Sn−1 のような部分空間ができる。球面の対蹠点を同一視する商として実射影空間 ℝPn ができる。円板を境界の球面に沿って貼り合わせる操作を繰り返せば、トーラス、Möbius の帯、Klein の壺、そして任意の胞体複体ができる。どの場合も、新しくできた対象は「ある集合に、ある特定の位相を入れたもの」である。この章の主題は、これらの位相がすべて同じ一つの仕組みで定まることの説明である。新しい空間は、位相空間の圏の中のある図式の極限または余極限として、普遍性によって特徴づけられる。

極限と余極限は任意の圏で定義できる。下限と上限、自由積、直積、直和、核、余核、ファイバー積、融合自由積、列の逆極限、合併、そして要素の圏までもが、その特別な場合である。章の構成は次のとおり。

  • §3.1 極限と余極限の抽象的な定義と、特定の形の図式に対する用語
  • §3.2 集合の圏における極限の具体的な構成。米田の補題により、集合での構成が任意の圏での一般公式の証明に足りる
  • §3.3 図式の圏の上の極限関手・余極限関手。自然同型な図式は同型な極限を持つ、という Eilenberg と Mac Lane が自然性を導入する動機になった結果
  • §3.4 極限を保つ・反映する・創る関手。ある圏の極限を別の圏の極限から構成できる場面の認定
  • §3.5 極限と余極限の表現可能性による記述と、単純な極限から一般の極限を組み立てる構成の任意の圏への拡張
  • §3.6 集合・空間・圏の圏が完備かつ余完備であることの証明。代数的な圏の多くも完備かつ余完備だが、グラフの圏と体の圏は例外で、証明は §5.6 に送られる
  • §3.7 大きさに上限のない図式の極限を持つ圏がほとんどない理由
  • §3.8 極限と余極限の相互作用。極限同士、余極限同士は可換だが、極限と余極限は一般に可換でない。例外の代表として、集合の圏で有限極限とフィルター余極限が可換であることを証明する

この節の問い

圏 C における J 型の図式とは、関手 F : J → C のことである。この節の目標は、図式の極限と余極限という互いに双対な概念を定義することにある。極限は図式の「上」にある普遍的な錐、余極限は図式の「下」にある普遍的な錐として定義される。したがって最初の仕事は、錐とは何かを述べることである。

定義3.1.1 — 定数関手

錐を自然変換として述べるために、一つの対象だけを見る図式が要る。それが定数関手である。

定義3.1.1. 圏 J, C と対象 c ∈ C に対し、定数関手 Δc : J → C は J のすべての対象を c に、すべての射を恒等射 idc に送る。定数図式関手 Δ : C → CJ は、対象 c を定数関手 Δc に、射 f : c → c′ を各成分が f である定数自然変換 Δf : Δc ⇒ Δc′ に送る。

定義3.1.2 — 錐

図式 F の各対象 Fj へ、一つの対象 c から射を一本ずつ伸ばし、それらが図式の射と整合するようにしたものが錐である。整合性を「Δc から F への自然変換」と言い切るのがこの定義の要点である。

定義3.1.2. 図式 F : J → C 上の、頂点（summit または apex）c ∈ C を持つ錐（cone）とは、定数関手を域とする自然変換 λ : Δc ⇒ F のことである。自然変換の成分 (λj : c → Fj)j∈J を錐の脚（leg）と呼ぶ。

成分ごとに書き下すと次のようになる。

  • 頂点 c を持つ F 上の錐のデータは、J の対象 j で添字づけられた C の射の族 λj : c → Fj である
  • 射の族 (λj : c → Fj)j∈J が F 上の錐を定めるための必要十分条件は、J の各射 f : j → k について次の三角形が C で可換なことである

Δc は J の射をすべて idc に送るので、自然性の四角形の上辺は恒等射になり、四角形が三角形に潰れる。これが (3.1.3) である。

双対に、頂点（nadir）c を持つ F 下の錐とは自然変換 λ : F ⇒ Δc のことで、脚は成分 (λj : Fj → c)j∈J である。自然性の条件は、J の各射 f : j → k について次の三角形が可換なことを言う。

図式の下の錐は余錐（cocone）とも呼ばれる。F : J → C 下の錐は、反対圏で見た F : Jop → Cop 上の錐にほかならない。ただし本書では「上」「下」という言い方のほうが像を結びやすいとして、こちらを用いる。

具体例として、poset 圏 (ℤ, ≤) で添字づけられた図式 F を見る。n ≤ m を表す唯一の射の F による像を fn,m : Fn → Fm と書く。頂点 c を持つ F 上の錐は射の族 (λn : c → Fn)n∈ℤ であって、各 n ≤ m について λn, λm, fn,m のなす三角形が可換になるものである。

頂点 c を持つ F 下の錐は射の族 (λn : Fn → c)n∈ℤ であって、各 n ≤ m について λn, λm, fn,m のなす三角形が可換になるものである。図は (3.1.4) の矢印を上下に裏返したものになる。

極限は普遍的な錐である

F の極限とは、F 上の錐のうち普遍的なもの、余極限とは F 下の錐のうち普遍的なものである。第2章で見たとおり、普遍性には二通りの等価な捉え方がある。極限は、ある反変関手の表現として定義することもできるし、その関手の要素の圏の終対象として定義することもできる。双対に、余極限はある共変関手の表現であり、同じことだがその要素の圏の始対象である。表現可能性による定義がつねにそうであるように、極限と余極限はどんな圏に値を取るどんな図式についても考えることができるが、個々の場合にそれが存在するかどうかは別の問題である。

定義3.1.5 — 極限と余極限 I（表現として）

頂点を動かしながら「頂点 c を持つ錐の集合」を眺めると、それは c について反変な集合値関手になる。この関手を表現する対象が極限である。

定義3.1.5（極限と余極限 I）. 図式 F : J → C に対して関手

Cone(−, F) := Hom(Δ(−), F) : Cop → Set

がある。この関手は c ∈ C を、頂点 c を持つ F 上の錐の集合に送り、射 f : c → d を、頂点 d の錐 μ を脚に f を前合成した頂点 c の錐 μ·Δf に変える関数 f∗ : Cone(d, F) → Cone(c, F) に送る。
F の極限とは、Cone(−, F) の表現である。米田の補題により、極限は対象 lim F ∈ C と、自然同型

C(−, lim F) ≅ Cone(−, F)

を定める普遍的な錐 λ : Δ lim F ⇒ F の組からなる。この錐を極限錐と呼ぶ。
双対に、c を頂点 c を持つ F 下の錐の集合に送る関手 Cone(F, −) := Hom(F, Δ(−)) : C → Set があり、F の余極限とは Cone(F, −) の表現である。米田の補題により、余極限は対象 colim F ∈ C と、自然同型

C(colim F, −) ≅ Cone(F, −)

を定める普遍的な錐 λ : F ⇒ Δ colim F の組からなる。この錐を余極限錐と呼ぶ。

関手 Cone(−, F) は、関手圏 CJ の hom 関手 Hom(−, F) を Δ で引き戻したものである。Hom(Δc, F) が集合をなすことは先験的には保証されないが、J が小さく C が局所小であれば CJ は局所小になり、頂点を固定した錐の集合が確かに集合になる。§3.7 までは、考える極限と余極限はすべて小圏で添字づけられているとする。

「表現」の中身を思い出すと、極限錐 λ が定める自然同型 C(c, lim F) ≅ Cone(c, F) は、射 g : c → lim F を錐 λ·Δg に送る写像である。つまり極限の普遍性とは、頂点 c を持つどんな錐も、ただ一つの射 c → lim F を通して極限錐から得られる、ということである。

定義3.1.6 — 極限と余極限 II（錐の圏の終対象として）

命題2.4.8 により、関手の表現はその要素の圏の終対象と同じことだった。Cone(−, F) の要素の圏を具体的に書き下すと、それは錐を対象とし、錐の間の「頂点の射で脚が整合するもの」を射とする圏になる。

定義3.1.6（極限と余極限 II）. 図式 F : J → C に対して、極限とは F 上の錐の圏、すなわち ∫Cone(−, F) の終対象である。F 上の錐の圏の対象は、任意の頂点を持つ F 上の錐である。錐 λ : Δc ⇒ F から錐 μ : Δd ⇒ F への射は、C の射 f : c → d であって各 j ∈ J について μj·f = λj を満たすものである。

言い換えると、錐の射とは頂点の間の写像であって、域の錐の各脚が、この写像を経由して余域の錐の対応する脚を通るものである。F 上の錐の圏の終対象は、極限対象 lim F ∈ C と、指定された極限錐 λ : Δ lim F ⇒ F を定める。

双対に、余極限とは F 下の錐の圏 ∫Cone(F, −) の始対象である。F 下の錐の圏の対象は任意の頂点を持つ F 下の錐で、錐 λ : F ⇒ Δc から錐 μ : F ⇒ Δd への射は、各 j ∈ J について μj = f·λj を満たす射 f : c → d である。錐の射とは頂点の間の写像であって、余域の錐の各脚が、この写像を経由して域の錐の対応する脚を通るものである。F 下の錐の圏の始対象は、余極限対象 colim F ∈ C と、指定された余極限錐 λ : F ⇒ Δ colim F を定める。

複数の形の図式が同時に現れるときなど、形を強調したいときは limJ F, colimJ F と書く。特別な記法を使わないときもある。ある錐が「極限錐」であると言うのは、その頂点がどう書かれていようと、頂点が極限であると主張することである。

命題3.1.7 — 極限と余極限の本質的一意性

固定した図式の極限や余極限は、しばしば定冠詞つきで「その極限」と呼ばれる。次の命題により、極限は一意な同型を除いて定まるからである。

命題3.1.7（極限と余極限の本質的一意性）. 共通の図式 F 上の任意の二つの極限錐 λ : Δℓ ⇒ F と λ′ : Δℓ′ ⇒ F に対し、極限錐の脚と可換な同型 ℓ ≅ ℓ′ がただ一つ存在する。

この結果は、極限対象が非自明な自己同型を持つことを禁じてはいない。λ : Δℓ ⇒ F が極限錐で f : ℓ ≅ ℓ が ℓ の任意の自己同型なら、λ·Δf : Δℓ ⇒ F もまた極限錐である。しかし命題3.1.7 により、指定された極限錐 λ と可換な ℓ の自己同型は恒等射だけである。

証明. 極限錐 λ : Δℓ ⇒ F と λ′ : Δℓ′ ⇒ F はそれぞれ、F 上の錐の圏の終対象を定める。補題1.6.16 により、任意の圏の終対象たちは可縮な亜群をなす。とくにこれらの対象は錐の圏で一意に同型であり、それはすなわち、錐の脚と可換な ℓ と ℓ′ の間の同型がただ一つ存在するということである。□

注意3.1.8 — 極限図式と余極限図式

図式と、その上の極限錐を合わせたデータを極限図式と呼び、図式と、その下の余極限錐を合わせたデータを余極限図式と呼ぶ。J で添字づけられた図式とその上の錐は、(3.1.4) に見えるように、合わせて圏 J◁ で添字づけられた一つの図式を定める。J◁ は J を充満部分圏として含み、それに始対象を自由に付け加えた圏である。双対に、J で添字づけられた図式とその下の錐は、J に終対象を自由に付け加えた圏 J▷ で添字づけられた図式を定める。演習3.6.vi でこの圏のより明示的な構成を与える。

特定の形の極限図式・余極限図式には特別な名前がある。以下、順に見ていく。

定義3.1.9 — 積

射のない添字圏、つまり対象の集まりだけを図式と見たとき、その極限が積である。

定義3.1.9. 積（product）とは、恒等射しか持たない離散圏で添字づけられた図式の極限である。

離散圏 J で添字づけられた C の図式は、j ∈ J で添字づけられた対象の集まり (Fj)j∈J にすぎない。この図式上の錐は J で添字づけられた射の族 (λj : c → Fj)j∈J で、それ以上の制約は課されない。極限はふつう ∏j∈J Fj と書かれ、極限錐の脚

(πk : ∏j∈J Fj → Fk)k∈J

は（積の）射影（projection）と呼ばれる。普遍性の主張は、射影との合成が自然同型

C(c, ∏j∈J Fj) ≅ ∏k∈J C(c, Fk) ≅ Cone(c, F)

を定めるということである。左の同型は g ↦ (πk·g)k∈J で、右の同型は「離散圏上の錐とは脚の族そのもの」という観察である。

例3.1.10 — 空間の積

空間の対 X, Y の積は、連続な射影関数 πX : X × Y → X, πY : X × Y → Y を備えた空間 X × Y であって、次の普遍性を満たすものである。連続写像 f : A → X, g : A → Y を持つ任意の空間 A に対し、次の図式を可換にする連続関数 h : A → X × Y がただ一つ存在する。

A を一点空間に取る。一点空間は台集合関手 U : Top → Set を表現するので、全単射

Top(∗, X × Y) ≅ Top(∗, X) × Top(∗, Y)

は、X × Y の点が台集合の直積の点とちょうど対応することを言っている。

残るのは集合 X × Y に入れる位相の決定である。A として、集合 X × Y にさまざまな位相を入れた空間を取ってみると、普遍性は X × Y の位相を「射影 πX, πY が連続になる中で最も粗い位相」に定めるほかないことを強いる。粗い（coarse）とは開集合と閉集合が少ないという意味で、その反対語は細かい（fine）である。

同様に、任意の族 (Xj)j∈J の積は、台集合の積に、各射影 πk : ∏j Xj → Xk が連続になる最も粗い位相を入れて定義される。より直感的な「箱位相」、すなわち各 Xj の基本開集合の積を基本開集合とする位相は、添字集合が有限なら積位相と一致するが、J が無限のときは定義3.1.9 の普遍性を満たさない。

定義3.1.11 — 終対象

定義3.1.11. 終対象は、添字圏が空である積の特別な場合と見なせる。

空な図式上の錐は、頂点である対象一つだけで、それ以外のデータを持たない。頂点の間のどんな射も空な錐の射になる。したがって空な図式上の錐の圏は、圏 C 自身と同型であり、空な図式の極限とは定義1.6.14 の意味での終対象にほかならない。

例3.1.12 — 終圏

対象一つとその恒等射だけからなる圏 𝟙 は終圏であり、Cat と CAT の終対象である。

定義3.1.13 — 等化子

平行な二本の射が一致する場所を、対象の側から普遍的に切り出したものが等化子である。

定義3.1.13. 等化子（equalizer）とは、平行対（parallel pair）の圏 • ⇉ • で添字づけられた図式の極限である。平行対の圏は対象2つと、平行な非恒等射2本を持つ。

この形の図式は、圏 C における平行な射の対 f, g : A ⇉ B にすぎない。頂点 C を持つこの図式上の錐は、射の対 a : C → A と b : C → B であって fa = b かつ ga = b を満たすものである。この二つの等式は、添字圏の二本の非恒等射それぞれが課す自然性の条件 (3.1.3) にあたる。合わせると fa = ga を主張しており、射 b はこの共通の合成に等しいほかない。したがって平行対 f, g : A ⇉ B 上の錐は、fa = ga を満たす一本の射 a : C → A で代表される。

等化子 h : E → A は、この性質を持つ射のうち普遍的なものである。次の極限図式を等化子図式と呼ぶ。

普遍性の主張は、fa = ga を満たす任意の a : C → A に対し、a の h を通る分解 k : C → E がただ一つ存在するということである。

例3.1.14 — 核

群の準同型 φ : G → H と、G のすべての元を H の単位元に送る自明な準同型 e : G → H の等化子は φ の核 ker φ であり、極限錐の脚は包含 ι : ker φ ↪ G である。

準同型の対 φ, ψ : G ⇉ H の等化子は、φ(g) = ψ(g) を満たす元 g ∈ G のなす部分群である。H が可換群なら、これは準同型 φ − ψ : G → H の核になる。

等化子が G の部分群を定めることは偶然ではない。等化子から、それが等化する平行対の域への写像は、つねにモノ射（monomorphism）である。演習3.1.iv を参照。

定義3.1.15 — 引き戻し

共通の余域を持つ二本の射 f : B → A, g : C → A に対し、「f と g で A に送ると一致する B の点と C の点の対」を普遍的に集めたものが引き戻しである。

定義3.1.15. 引き戻し（pullback）とは、余スパン（cospan）の極限である。余スパンとは、共通の余域を持つ二本の非恒等射からなる poset 圏 • → • ← • で添字づけられた図式のことである。

この形の図式の像を定める射を f, g と書くと、頂点 D を持つ錐は、添字圏の対象一つにつき一本ずつの三本の射からなり、次の図式の二つの三角形が可換になる。

二つの三角形は、添字圏の二本の非恒等射が課す二つの自然性の条件 (3.1.3) を表す。脚 a は、gc と fb が共通の合成を持つことを主張しているだけである。したがって余スパン B →f A ←g C 上の錐のデータは、より簡潔に、可換な四角形を定める射の対 B ←b D →c C として記述できる。

引き戻し、すなわち f と g 上の普遍的な錐は、可換な四角形 fh = gk であって次の普遍性を持つものである。任意の可換な四角形 (3.1.16) に対し、その脚の、引き戻し錐の頂点を通る分解がただ一つ存在する。

記号「⌟」は、四角形 gk = fh が単に可換なだけでなく引き戻し、すなわち極限図式であることを示す。引き戻し P はファイバー積（fiber product）とも呼ばれ、B ×A C と書かれることが多い。引き戻しと積の正確な関係は §3.2 と §3.5 で扱う。補題3.5.15 などを参照。

終対象 ∗ を持つ圏では、射 f : B → A と点 a : ∗ → A の引き戻し

は、写像 f の a 上のファイバーを定める。

例3.1.18 — 円周への商写像のファイバー

空間の圏で、実数 t を複素平面の単位円 S1 の点 e2πit に送る連続な商写像 ρ : ℝ → S1 を考える。次の図式の引き戻し

写像のファイバーが域の部分空間を定めることは偶然ではない。モノ射 B ↣ A の任意の写像 C → A に沿った引き戻しは、モノ射 B ×A C ↣ C を定める。演習3.1.v を参照。

例3.1.19 — 整数の掛け算の引き戻し

可換群の写像 n : ℤ → ℤ は元 n ∈ ℤ と対応するのだった。ℤ が忘却関手 U : Ab → Set を表現するからである。写像 n と m のなす余スパンについて、引き戻しの元は nx = my を満たす整数の対 x, y である。

この記述から、m と n がともに 0 ではないと仮定すると、引き戻しは可換群 ℤ と同型であり、引き戻し錐の脚

定義3.1.21 — 逆極限

左へ左へと続く射の列を、その「左端」で止める対象が逆極限である。

定義3.1.21. 圏 ωop で添字づけられた図式の極限を、塔（tower）または射の列の逆極限（inverse limit）と呼ぶ。

この例のために、「逆極限」という語は任意の形の極限を指して使われることもある。ωop で添字づけられた図式は、対象と射の列

⋯ → F3 →f3,2 F2 →f2,1 F1 →f1,0 F0

に、表示されない合成と恒等射を加えたものである。この図式上の錐は、このデータを形 (ω + 𝟙)op の図式に延長したものである。具体的には、錐は「いちばん左」の新しい対象と、すべての三角形を可換にする射からなる。

逆極限はしばしば lim← Fn と書かれ、終錐である。ω の代わりに任意の極限順序数 α を取っても同様である。後続順序数の反対圏で添字づけられた図式の極限に興味が乏しい理由は、演習3.1.vii で説明される。

定義3.1.23 — 余極限側の特別な形

定義3.1.9, 3.1.11, 3.1.13, 3.1.15, 3.1.21 はそれぞれ双対化して、次を定める。

定義3.1.23.
  • 余積（coproduct）∐j∈J Aj とは、離散圏 J で添字づけられた図式 (Aj)j∈J の余極限である。余極限錐の脚 (ιk : Ak → ∐j∈J Aj)k∈J は余積の包含（coproduct inclusion）と呼ばれる。この写像はしばしばモノ射になるが、つねにそうとは限らない。演習3.1.ix を参照
  • 始対象とは、空な図式の余極限である
  • 余等化子（coequalizer）とは、平行対の圏 • ⇉ • で添字づけられた図式の余極限である。平行な写像の対 f, g : A ⇉ B の余等化子は、hf = hg を満たす普遍的な写像 h : B → C である。次の余極限図式を余等化子図式と呼ぶ。この形の図式はフォーク（fork）とも呼ばれる
  • 押し出し（pushout）とは、スパン（span）の余極限である。スパンとは poset 圏 • ← • → • で添字づけられた図式のことである。定義3.1.15 の約束を双対化して、記号「⌜」は可換な四角形が押し出し、すなわち余極限図式であることを示す。押し出しは写像 f と g の下の普遍的な可換四角形である
  • 順序数 ω で添字づけられた図式の余極限を列余極限（sequential colimit）または順極限（direct limit）と呼ぶ。図式

    F0 → F1 → F2 → F3 → ⋯

    の余極限はしばしば lim→ Fn と書かれ、このデータの形 ω + 𝟙 の図式への普遍的な延長である。「順極限」という語は任意の形の余極限を指して使われることもある

定義3.1.23 で導入した各余極限は、対応する極限概念を添字づける圏の反対圏で添字づけられている。圏 ω と圏 • ← • → • が余極限図式の添字に使われて極限図式の添字には使われない理由は、演習3.1.vii で説明される。

極限への射と余極限からの射

極限と余極限を特徴づける普遍性の形は、極限対象への写像や余極限対象からの写像を定義しなければならないときに大いに役立つ。たとえば多変数の微積分では、連続関数 f : ℝn → ℝm を、射影 πi : ℝm → ℝ との合成で定まる成分関数 f1, …, fm : ℝn → ℝ を通して調べる。この分解は Top における積 ℝm の普遍性に訴えている。線形代数では、線形写像 A : ℝn → ℝm をまず各 1 ≤ i ≤ m について線形な成分 Ai : ℝn → ℝ に分解し、さらに各 1 ≤ j ≤ n について線形な成分 Ai,j : ℝ → ℝ に分解する。各 Ai,j はあるスカラー ai,j ∈ ℝ の掛け算である。この分解は、有限次元ベクトル空間が Vectℝ において積であると同時に余積でもあることに訴えている。

注意3.1.27 — 積と余積の普遍性

余積を持つ任意の圏 C において、写像 f : ∐i∈I Ai → X は、I で添字づけられた写像の族 (fi : Ai → X)i∈I と自然に全単射で対応する。写像 f の i′ 成分 fi′ は、余極限錐の i′ 番目の脚である包含 ιi′ : Ai′ → ∐i∈I Ai に沿った制限として定まる。

双対に、積を持つ任意の圏において、写像 g : X → ∏j∈J Bj は J で添字づけられた写像の族 (gj : X → Bj)j∈J と自然に全単射で対応する。写像 g の j′ 成分 gj′ は、極限錐の j′ 番目の脚である射影 πj′ : ∏j∈J Bj → Bj′ との合成として定まる。

二つの普遍性を組み合わせると、余積から積への写像

を定めるには、順序対 (i′, j′) ∈ I × J ごとに写像 f(i′,j′) : Ai′ → Bj′ を定めれば十分である。つまり余積から積への一本の写像は、添字集合の積で添字づけられた成分写像の行列で決まる。以後は、積や余積を添字づける束縛変数と、一般の成分を添字づける変数に同じ記号を使い、プライムを省く。たとえば f : ∐i∈I Ai → ∏j∈J Bj は成分写像 f(i,j) = πj·f·ιi : Ai → Bj で与えられる、と書く。

ある種の圏では、この行列表示をさらに推し進められる。圏 Ab, RMod, ChR には、任意の対象の対の間に零準同型がある。すると有限個の対象 Ai に対して、成分が零準同型か恒等射のいずれかである「単位行列」

∐i∈I Ai → ∏i∈I Ai, 成分は (i,i) で idAi、それ以外で 0

で符号化される写像を考えることに意味があり、これらの圏ではこの写像が同型になる。単位行列が有限余積と有限積の間の同型を定めることは、任意のアーベル圏で成り立つ。定義E.5.1 を参照。このような文脈では、同型な有限余積と有限積 ∐i∈I Ai ≅ ∏i∈I Ai を ⨁i∈I Ai と書き、直和（direct sum）と呼ぶ。

積と余積の普遍性を組み合わせると、有限直和の間のすべての写像は成分写像の行列で表され、期待どおり、合成の行列は「行列の積」で定まる。

ここで ∑j g(j,k) f(i,j) : Ai → Ck は次の合成として定義される。

Ai →(idAi) ⨁j∈J Ai →⨁j g(j,k) f(i,j) ⨁j∈J Ck →(idCk) Ck

最初の写像は Ai を J 個のコピーの直和へ対角に送る写像で、最後の写像は Ck の J 個のコピーの直和から Ck へ足し合わせる写像である。直和を持つ圏では、固定した対象の対の間の hom 集合は可換モノイドになる。

補題3.1.28 — 極限への射・余極限からの射の一致

普遍性の一意性の部分を使うと、始点が余極限対象、または終点が極限対象であるような図式の可換性を証明できる。これは補題1.6.17 の一般化である。

補題3.1.28. 極限対象への平行な射の対が等しいための必要十分条件は、極限錐の脚との合成が等しいことである。双対に、余極限対象からの平行な射の対が等しいための必要十分条件は、余極限錐の脚との合成が等しいことである。

証明. 図式 F : J → C の極限を余域とする平行な射の対 f, g : X ⇉ lim F を考える。極限錐は自然同型 C(X, lim F) ≅ Cone(X, F) を誘導し、これは元 f と g を錐 λ·Δf と λ·Δg に送る。この写像は同型なので、f = g であることと、錐 λ·Δf と λ·Δg が等しいことは同値である。二つの自然変換が等しいのはちょうど成分が等しいときなので、この二つの錐が一致することと、すべての j ∈ J について λjf = λjg であることは同値である。これで主張の同値が示された。□

極限の見つけ方

ここまでの例は、興味深い数学的対象の中に極限と余極限がどれほど遍在しているかを示している。では、特定の図式が極限や余極限を持つことをどう証明し、存在するならどう構成するのか。一般的な戦略は二つある。

第一は推測して検証することである。(3.1.20) に示したような、極限錐または余極限錐であろうと予想される錐は、しばしば初等的な議論で適切な普遍性を持つことが示せる。著者の経験では、特定の圏で望みの普遍性が満たされることの証明のほとんどはこの方法で進む。最初の一歩は、ある構成が求める対象を定めるのではないかと直感すること、次の一歩は普遍性が成り立つことを検証することである。

第二の戦略は、より複雑な図式の極限を、構成の理解しやすいより単純な図式の極限から組み立てることである。次の節では、集合の圏でこの見方を探り始める。
