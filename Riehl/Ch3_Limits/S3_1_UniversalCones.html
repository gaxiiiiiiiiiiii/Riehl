3.1 普遍錐としての極限と余極限

Emily Riehl, Category Theory in Context §3.1（pp.82–92）の内容を、個人学習のために日本語で書き直した解説。番号（命題3.1.7 など）は本と揃えてある。翻訳ではなく、同じ内容を自分の言葉で再構成したもの。

圏 C における形 J の図式とは、関手 F : J → C のことだった。この節では、図式の極限と余極限を導入する。極限は図式の上の普遍錐、余極限は図式の下の普遍錐として定義される。まず錐が何かを説明することから始める。

定義3.1.1 — 定数関手

定義3.1.1. 圏 J, C と対象 c ∈ C に対し、定数関手 Δc : J → C は、J のすべての対象を c に、すべての射を恒等射 idc に送る。定数図式関手 Δ : C → CJ は、対象 c を定数関手 Δc に、射 f : c → c′ を定数自然変換 Δf : Δc ⇒ Δc′ に送る。Δf の各成分は f そのものである。

定義3.1.2 — 錐と余錐

直感的には、図式 F の上の錐とは、一つの対象 c から図式の各点へ伸びる脚の束で、図式の射と整合するものである。

定義3.1.2. 図式 F : J → C の上の、頂点 c ∈ C をもつ錐とは、定数関手 Δc を域とする自然変換 λ : Δc ⇒ F のことである。自然変換の成分 (λj : c → Fj)j∈J を錐の脚という。明示的には次のとおり。
  • 頂点 c の上の錐のデータは、J の対象 j で添字づけられた射の族 λj : c → Fj である
  • 射の族 (λj : c → Fj)j∈J が錐をなすのは、J の各射 f : j → k について次の三角形が C で可換になるとき、かつそのときに限る

双対に、F の下の、底 c をもつ錐とは、自然変換 λ : F ⇒ Δc であり、脚は成分 (λj : Fj → c)j∈J である。自然性は、J の各射 f : j → k について次の三角形が可換であることを主張する。

下の錐は余錐とも呼ばれる。F : J → C の下の錐は、F : Jop → Cop の上の錐にほかならない。ただし「上」「下」という言い方のほうが直感に訴える。

例として、前順序集合の圏 (ℤ, ≤) で添字づけた図式 F を考える。n ≤ m の唯一の射の F による像を fn,m : Fn → Fm と書く。頂点 c の上の錐は、射の族 (λn : c → Fn)n∈ℤ であって、各 n ≤ m について λn, λm, fn,m のなす三角形（(3.1.3) の形）が可換になるものである。底 c の下の錐も同様に、族 (λn : Fn → c)n∈ℤ で対応する三角形が可換になるものである。

定義3.1.5 — 極限と余極限（その一：表現）

極限は最も簡潔には「図式 F の上の普遍錐」、余極限は「F の下の普遍錐」として述べられる。第2章で見たとおり、この普遍性には二つの等価な理解の仕方がある。極限は、ある反変関手の表現として、あるいはその要素の圏の終対象として定義できる。双対に、余極限はある共変関手の表現であり、等価に、その要素の圏の始対象である。表現による定義がつねにそうであるように、極限と余極限はどんな圏に値を取るどんな図式についても考えられるが、個々の場合にそれが存在するとは限らない。

定義3.1.5（極限と余極限 I）. 図式 F : J → C に対し、関手
Cone(−, F) ≔ Hom(Δ(−), F) : Cop → Set
がある。これは c ∈ C を「頂点 c の上の錐の集合」に送り、射 f : c → d を、頂点 d の錐 μ を脚の前合成で頂点 c の錐 μ·Δf に変える関数 f∗ : Cone(d, F) → Cone(c, F) に送る。
F の極限とは Cone(−, F) の表現である。米田の補題により、極限は対象 lim F ∈ C と極限錐 λ : Δ lim F ⇒ F の組からなり、自然同型
C(−, lim F) ≅ Cone(−, F)
を定める。

双対に、関手 Cone(F, −) ≔ Hom(F, Δ(−)) : C → Set は c を「底 c の下の錐の集合」に送る。F の余極限とは Cone(F, −) の表現である。米田の補題により、余極限は対象 colim F ∈ C と余極限錐 λ : F ⇒ Δ colim F の組からなり、自然同型 C(colim F, −) ≅ Cone(F, −) を定める。

脚注1: 図式 F の上の、頂点を固定した錐が集合をなすことを保証するには、J が小さく C が局所小であれば十分である（このとき CJ は局所小になる）。§3.7 まで、扱う極限・余極限はすべて小さい圏で添字づけられているものとする。

定義3.1.6 — 極限と余極限（その二：終対象）

命題2.4.8 を適用すると、極限と余極限は、適切な錐の圏における終対象・始対象としても定義できる。

定義3.1.6（極限と余極限 II）. 図式 F : J → C に対し、極限とは、F の上の錐の圏 ∫Cone(−, F) の終対象である。この圏の対象は任意の頂点をもつ上の錐であり、錐 λ : Δc ⇒ F から錐 μ : Δd ⇒ F への射は、各 j ∈ J について μj·f = λj を満たす射 f : c → d である。言い換えると、錐の射とは頂点の間の写像であって、域の錐の各脚がこの写像を通って余域の錐の対応する脚を経由して分解するものである。

錐の圏の終対象は、極限対象 lim F ∈ C と、指定された極限錐 λ : Δ lim F ⇒ F を定める。双対に、余極限とは F の下の錐の圏 ∫Cone(F, −) の始対象である。この圏の射は、底の間の写像 f : c → d であって各 j で μj = f·λj を満たすもの。始対象は余極限対象 colim F と指定された余極限錐 λ : F ⇒ Δ colim F を定める。

形 J の図式 F の極限・余極限は、複数の図式の形が関わるときなど、強調のために limJ F や colimJ F と書くことがある。特別な記法を使わない場合もある。錐が「極限錐である」と言うのは、その頂点が（どう表記されるにせよ）極限であると主張することである。

命題3.1.7 — 極限・余極限の本質的一意性

次の命題により、固定した図式の極限・余極限を指すのに定冠詞「the」を使うのが普通である。これらの対象は一意な同型を除いて well-defined だからである。

命題3.1.7（極限と余極限の本質的一意性）. 共通の図式 F の上の任意の二つの極限錐 λ : Δℓ ⇒ F と λ′ : Δℓ′ ⇒ F に対し、極限錐の脚と可換になる同型 ℓ ≅ ℓ′ がただ一つ存在する。

この結果は、極限対象が自明でない自己同型をもつことを禁じない。λ : Δℓ ⇒ F が極限錐で f : ℓ ≅ ℓ が ℓ の任意の自己同型なら、λ·Δf : Δℓ ⇒ F もまた極限錐である。ただし命題3.1.7 は、指定した極限錐 λ と可換になる ℓ の自己同型は恒等射だけであることを含意する。

証明. 極限錐 λ : Δℓ ⇒ F と λ′ : Δℓ′ ⇒ F は、いずれも F の上の錐の圏の終対象を定める。補題1.6.16 により、任意の圏の終対象たちは可縮亜群をなす。とくに、これらの対象は錐の圏で一意に同型である。すなわち、錐の脚と可換になる同型 ℓ ≅ ℓ′ がただ一つ存在する。□

注意3.1.8 — 極限図式・余極限図式

図式に、その上の極限錐を添えたデータを極限図式、図式にその下の余極限錐を添えたデータを余極限図式という。J で添字づけた図式とその上の錐は、合わせて、J に始対象を自由に付け加えた圏 J◁ で添字づけた図式を定める（J はその充満部分圏になる）。双対に、J で添字づけた図式とその下の錐は、J に終対象を自由に付け加えた圏 J▷ で添字づけた図式を定める。

脚注2: 圏 J◁ のより明示的な構成は演習3.6.vi にある。

特定の形の極限図式・余極限図式には固有の名前がある。以下、順に見ていく。

定義3.1.9 — 積

定義3.1.9. 積とは、恒等射だけをもつ離散圏で添字づけた図式の極限である。離散圏 J で添字づけた C の図式は、単に対象の族 (Fj ∈ C)j∈J にすぎない。この図式の上の錐は、これ以上の制約のない射の族 (λj : c → Fj)j∈J である（三角形の条件を課す非恒等射が J にないため）。極限は ∏j∈J Fj と書かれ、極限錐の脚 (πk : ∏j∈J Fj → Fk)k∈J を（積の）射影という。普遍性は、射影との合成が自然同型
C(c, ∏j∈J Fj) ≅ ∏k∈J C(c, Fk) ≅ Cone(c, F)
を定めることを主張する。

二項の積 X × Y の普遍性を図にすると次のようになる。射影 πX, πY をもつ X × Y に対し、任意の対象 A と射 f : A → X, g : A → Y が与えられると、πX·h = f かつ πY·h = g を満たす射 h : A → X × Y がただ一つ存在する。

例3.1.10 — 空間の積

二つの空間 X, Y の積は、連続な射影 πX : X × Y → X, πY : X × Y → Y を備えた空間 X × Y で、上の普遍性を満たすものである。すなわち、連続写像 f : A → X, g : A → Y をもつ任意の空間 A に対し、両三角形を可換にする連続関数 h : A → X × Y がただ一つ存在する。

A を一点空間に取ると、一点空間は台集合関手 U : Top → Set を表現するので、全単射 Top(∗, X × Y) ≅ Top(∗, X) × Top(∗, Y) は「X × Y の点は、X と Y の台集合の直積の点に対応する」ことを述べる。残るは X × Y の集合上の位相の定義である。A を、さまざまな位相を入れた集合 X × Y に取ると、この普遍性は X × Y を「射影 πX, πY が連続になる最も粗い位相」を台集合の直積に入れたものとして強制する。同様に、空間の族 (Xj)j∈J（無限でもよい）の積は、台集合の直積に、各射影 πk : ∏j Xj → Xk が連続になる最も粗い位相を入れて定義される。より直感的な「箱位相」（基本開集合が各 Xj の基本開集合の積）は、有限の添字集合では積位相と一致するが、添字集合が無限だと定義3.1.9 の普遍性を満たさない。

脚注3: 「最も粗い」とは「開集合・閉集合が最も少ない」の意。反対語は「最も細かい」で「開集合・閉集合が最も多い」。

定義3.1.11 — 終対象

定義3.1.11. 終対象は、添字圏が空である積の特別な場合とみなせる。空図式の上の錐は、頂点となる対象そのものにほかならず、追加のデータはない。頂点の間の任意の射が空錐の射を定める。よって空図式の上の錐の圏は、もとの圏 C 自身と同型であり、空図式の極限は定義1.6.14 の意味での終対象である。

例3.1.12 — 終圏

対象1つとその恒等射だけからなる圏 1 は終圏であり、Cat あるいは CAT における終対象である。

定義3.1.13 — 等化子

定義3.1.13. 等化子とは、平行対——2対象と2本の平行な非恒等射をもつ圏 • ⇉ •——で添字づけた図式の極限である。この形の図式は、単に平行な射の対 f, g : A ⇉ B である。頂点 C の上の錐は、fa = b かつ ga = b を満たす射の対 a : C → A, b : C → B からなる（この2式は2本の非恒等射が課す自然性条件 (3.1.3)）。両式は合わせて fa = ga を主張し、b はこの共通の合成に等しい。よって平行対 f, g : A ⇉ B の上の錐は、fa = ga を満たす一本の射 a : C → A で表される。
等化子 h : E → A は、この性質をもつ普遍的な射である。普遍性は、fa = ga を満たす任意の a : C → A が h を通って一意に分解する（k : C → E がただ一つ）ことを主張する。

例3.1.14 — 核

群準同型 φ : G → H と、G のすべての元を H の単位元に送る自明な準同型 e : G → H の等化子は、φ の核であり、極限錐の脚は包含 ι : ker φ ↪ G である。一般に、準同型の対 φ, ψ : G ⇉ H の等化子は、φ(g) = ψ(g) を満たす元 g ∈ G のなす部分群である。H がアーベル群なら、これは準同型 φ − ψ : G → H の核である。等化子が G の部分群を定めるのは偶然ではない。等化する平行対の域への、等化子からの射はつねに単射である（演習3.1.iv）。

定義3.1.15 — 引き戻し

定義3.1.15. 引き戻しとは、余スパン——共通の余域をもつ2本の非恒等射からなる前順序圏 • → • ← • で添字づけた図式——の極限である。この形の図式を C で表す射を f, g とすると、頂点 D の上の錐は、添字圏の各対象に一本ずつ、計3本の射からなり、下の図式の両三角形が可換になるものである。中央の脚は gc と fb が共通の合成をもつことを主張するので、余スパン B →f A ←g C の上の錐は、可換正方形を定める射の対 B ←b D →c C としてより簡潔に書ける。

引き戻し、すなわち f と g の上の普遍錐は、可換正方形 fh = gk であって次の普遍性をもつものである。任意の可換正方形（頂点 D）が与えられると、その脚が引き戻し錐の頂点を通って一意に分解する。記号「⌟」は、正方形 gk = fh が単なる可換正方形ではなく引き戻し（極限図式）であることを示す。引き戻し P はファイバー積とも呼ばれ、しばしば B ×A C と書かれる。

終対象 ∗ をもつ圏では、次の引き戻しは写像 f : B → A の、a 上のファイバーを定める。

例3.1.18 — 円周への商写像のファイバー

空間の圏で、実数 t を単位円周 S¹ ⊂ ℂ の点 e2πit に送る連続な商写像 ρ : ℝ → S¹ を考える。余スパン ℝ →ρ S¹ ←1 ∗（∗ は点 1 ∈ S¹ を選ぶ）の引き戻しは、ρ の 1 上のファイバーであり、離散部分空間 ℤ ⊂ ℝ である。写像のファイバーがその域の部分空間を定めるのは偶然ではない。単射 B ↣ A の、任意の写像 C → A に沿った引き戻しは単射 B ×A C ↣ C を定める（演習3.1.v）。

例3.1.19 — ℤ の乗法写像の引き戻し

アーベル群の写像 n : ℤ → ℤ は、ℤ が忘却関手 U : Ab → Set を表現するので、元 n ∈ ℤ に対応する。写像 n, m のなす余スパンについて、引き戻しの元は nx = my を満たす整数の対 (x, y) である。m, n が共に零でなければ、引き戻しはアーベル群 ℤ に同型で、引き戻し錐の脚は ma = nb が n と m の最小公倍数になるような一意の整数 a, b で定まる。

脚注4: 正確には、ここで述べた普遍性は整数の対 (a, b) を符号の整合的な取り方を除いてしか定めない（演習3.1.viii）。

定義3.1.21 — 逆極限

定義3.1.21. 圏 ωop で添字づけた図式の極限を、塔あるいは射の列の逆極限という。この例にちなみ、「逆極限」という語が任意の形の極限を指すのに使われることもある。ωop で添字づけた図式は、対象と射の列
⋯ → F3 → F2 → F1 → F0
（合成と恒等射は表示しない）である。この図式の上の錐は、このデータを形 (ω + 1)op の図式へ拡張したもの、すなわち「いちばん左」に新しい対象を、すべての三角形が可換になるように付け加えたものである。逆極限はしばしば lim← Fn と書かれ、終錐である。ω の代わりに任意の極限順序数 α を置いても同様のことが成り立つ。

脚注5: 後続順序数の反対圏で添字づけた図式の極限にあまり関心がない理由は、演習3.1.vii が説明する。

例3.1.22 — 形式的べき級数

体 𝕜 と n ∈ ℕ に対し、次数 n までの多項式のなす環を 𝕜[x]/(xn+1) と書く。形式的べき級数の環 𝕜[[x]] は、最高次の項を忘れる商写像による ωop-図式

⋯ → 𝕜[x]/(x³) → 𝕜[x]/(x²) → 𝕜[x]/(x)
の逆極限として定義される。

定義3.1.23 — 双対概念（余積・始対象・余等化子・押し出し・逐次余極限）

定義3.1.23. 定義3.1.9・3.1.11・3.1.13・3.1.15・3.1.21 を双対化して、次を定義する。
  • 余積 ∐j∈J Aj は、離散圏 J で添字づけた図式 (Aj)j∈J の余極限。余極限錐の脚 (ιk : Ak → ∐j∈J Aj)k∈J を余積の包含という（これらは、つねにではないがしばしば単射である。演習3.1.ix）
  • 始対象は空図式の余極限
  • 余等化子は平行対 • ⇉ • で添字づけた図式の余極限。平行対 f, g : A ⇉ B の余等化子は、hf = hg を満たす普遍的な写像 h : B → C。この形の図式はフォークとも呼ばれる
  • 押し出しはスパン——前順序圏 • ← • → • で添字づけた図式——の余極限。記号「⌜」は、可換正方形が押し出し（余極限図式）であることを示す。押し出しは写像 f, g の下の普遍的な可換正方形である
  • 順序数 ω で添字づけた図式 F0 → F1 → F2 → ⋯ の余極限を逐次余極限あるいは順極限といい、しばしば lim→ Fn と書く

定義3.1.23 の各余極限は、対応する極限概念の添字圏の反対圏で添字づけられている。なぜ余極限図式には ω や • ← • → • を使い、極限図式には使わないかは演習3.1.vii が説明する。

例3.1.24 — 8の字と輪環面

8の字、すなわち二つの円のウェッジ S¹ ∨ S¹ は、基点なしの空間の図式 S¹ ← ∗ → S¹ の押し出しとして、あるいは基点つき空間の圏における S¹ の自分自身との余積として定義できる。さらに Top での押し出し図式

は輪環面 T ≅ S¹ × S¹ を定める。写像 aba⁻¹b⁻¹ は、S¹ ∨ S¹ で一方の円を一周し、次に他方を一周し、再び一方を逆向きに、最後に他方を逆向きに回るループである。

例3.1.25 — 余核

群準同型 φ : G → H と自明な準同型 e : G → H の対の余等化子は余核を定める。これは φ の像が生成する正規部分群による H の商である。

例3.1.26 — 集合の和

集合と包含の列 X0 → X1 → X2 → ⋯ の余極限は、その和 ⋃n≥0 Xn と理解できる。たとえば CW 複体は、その n-骨格（次元 n 以下の円板を貼り付けて作る部分空間）の余極限である。

普遍性の使い方

極限と余極限を特徴づける普遍性の形は、極限対象への写像や余極限対象からの写像を定義せよと言われたときに有用である。たとえば多変数微積分では、連続関数 f : ℝn → ℝm を、射影 πi : ℝm → ℝ との合成で定まる成分関数 f1, …, fm : ℝn → ℝ に分解して調べると便利である。この分解は、Top における積 ℝm の普遍性に訴えている。線型代数では、線型写像 A : ℝn → ℝm を、まず成分 Ai : ℝn → ℝ に、次に各成分をスカラー倍で定まる Ai,j : ℝ → ℝ に分解する。これらは、有限次元ベクトル空間が Vectℝ で積であり余積でもあることに訴えている。

注意3.1.27 — 積と余積の普遍性

注意3.1.27. 余積をもつ任意の圏 C では、写像 f : ∐i∈I Ai → X は、写像の族 (fi : Ai → X)i∈I と自然に1対1対応する。f の成分 fi は、余極限錐の脚である包含 ιi : Ai → ∐i∈I Ai に沿った制限で定まる。双対に、積をもつ圏では、写像 g : X → ∏j∈J Bj は写像の族 (gj : X → Bj)j∈J と1対1対応し、成分 gj は射影 πj との合成で定まる。

両方の普遍性を合わせると、余積から積への写像は成分の行列で定まる。

すなわち、余積から積への一本の写像は、添字集合の積で添字づけられた成分写像の行列で決まる。ある種の圏では、この行列表示をさらに進められる。Ab, RMod, ChR は、任意の対象の対の間に零準同型をもつ。有限個の対象 Ai に対し、成分が零準同型か恒等射である「単位行列」で符号化された写像 ∐i∈I Ai → ∏i∈I Ai を考えると、これらの圏ではこの写像は同型になる。この文脈では、同型な有限余積と有限積 ∐i∈I Ai ≅ ∏i∈I Ai を ⨁i∈I Ai と書き、直和と呼ぶ。積と余積の普遍性を合わせると、有限直和の間のすべての写像は成分写像の行列で表され、合成の行列は「行列の積」で定まる。すなわち、⨁i Ai →(f(i,j)) ⨁j Bj →(g(j,k)) ⨁k Ck の合成の (i, k) 成分は ∑j g(j,k) f(i,j) : Ai → Ck である。

脚注6: 以降、積・余積を添字づける束縛変数と、一般の成分を添字づける変数に同じ記号を使い、プライムで文を混雑させないようにする。たとえば f : ∐i∈I Ai → ∏j∈J Bj は成分写像 f(i,j) = πj·f·ιi : Ai → Bj で与えられる。
脚注7: 「単位行列」は、任意のアーベル圏で有限余積と有限積の間の同型を定める（定義E.5.1）。
脚注8: 直和をもつ圏では、固定した対象の対の間の hom 集合は可換モノイドになる。

補題3.1.28

補題3.1.28. 極限対象への平行な写像の対は、極限錐の脚との合成が等しいとき、かつそのときに限り等しい。双対に、余極限対象からの平行な写像の対は、余極限錐の脚との合成が等しいとき、かつそのときに限り等しい。

証明. 平行な写像の対 f, g : X ⇉ lim F（余域は図式 F : J → C の極限）を考える。極限錐は自然同型 C(X, lim F) ≅ Cone(X, F) を誘導し、元 f, g をそれぞれ錐 λ·Δf, λ·Δg に送る。この写像は同型なので、f = g であることは錐 λ·Δf = λ·Δg と同値である。二つの自然変換が等しいのは成分が等しいときちょうどなので、これらの錐が一致するのは、すべての j ∈ J について λjf = λjg であることと同値である。□

極限・余極限の存在をどう示すか

上の例は、極限と余極限が興味深い数学的対象の中に遍在することを示している。では、ある図式が極限や余極限をもつことをどう証明し、存在すればどう構成するのか。一般的な戦略は二つある。一つは推測して検証する方法である。(3.1.20) のような、極限錐・余極限錐の候補は、しばしば初等的な議論で適切な普遍性をもつことを示せる。もう一つは、より複雑な図式の極限を、理解しやすい簡単な図式の極限から構成する方法である。次節では、集合の圏でこの見方を探り始める。

脚注9: 著者の経験では、ある圏で所望の普遍性が満たされることの証明は、たいていこの「推測して検証する」やり方で進む。まず、ある構成が求める対象を定めそうだと直感し、次にその普遍性が成り立つことを確かめる。

節末問題

和訳・言い換えのみ。解答・方針は載せない。

  1. 3.1.i. 前順序集合 (P, ≤) に値を取る図式 F : J → P を考える。命題3.6.10 を先取りして、極限と余極限を順序の言葉で特徴づけよ。
  2. 3.1.ii. 一対の極限錐 λ : Δℓ ⇒ F と λ′ : Δℓ′ ⇒ F のそれぞれの普遍性を使い、頂点の間の、錐の脚と可換になる一意な同型 ℓ ≅ ℓ′ を直接構成して、命題3.1.7 を証明せよ。
  3. 3.1.iii. F ∈ CJ の上の錐の圏が、定数関手 Δ : C → CJ と関手 F : 1 → CJ から作るコンマ圏 Δ↓F に同型であることを証明せよ。双対性により、F の下の錐の圏がコンマ圏 F↓Δ であることを論じよ。
  4. 3.1.iv. E →h A ⇉f,g B が等化子図式なら、h は単射であることを証明せよ。
  5. 3.1.v. 引き戻し正方形において f が単射なら、その対辺 k も単射であることを証明せよ。
  6. 3.1.vi. 右の正方形が引き戻しである可換な長方形を考える。左の正方形が引き戻しであることと、長方形全体が引き戻しであることが同値であることを示せ（引き戻しの合成と消去）。
  7. 3.1.vii. J が始対象をもつなら、J で添字づけた任意の関手の極限は、その関手の始対象での値であることを示せ。この双対を、後続順序数で添字づけた図式の余極限の記述に適用せよ。
  8. 3.1.viii. 正整数の対 (a, b) が (3.1.20) の普遍性を満たすなら、対 (−a, −b) も同じ普遍性を満たすことを示せ。この観察が「引き戻しが ill-defined である」ことを意味しない理由を説明せよ。
  9. 3.1.ix. 零対象をもつ圏で、余積錐の脚が分裂単射であることを証明せよ。この結果を他の圏論的な文脈に拡張できるか。
  10. 3.1.x. 定義1.3.12 で導入した圏の積 C × D が、圏の圏における積を定めることを証明せよ。添字づけられた圏の族の積を同様に定義せよ。
  11. 3.1.xi. 群・アーベル群・可換環の圏における余積は何か。
  12. 3.1.xii. E : I ≃ J が小圏の間の圏同値を定め、図式 F : J → C を考える。F の上の J 型の錐の圏が、FE の上の I 型の錐の圏と同値であることを示し、この同値を使って F の極限と FE の極限の関係を記述せよ。
