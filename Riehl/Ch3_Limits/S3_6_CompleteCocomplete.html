この節の問い

定理3.5.11 や定理3.5.17 のように、一般の極限と余極限の構成を少数の単純なものに帰着させる定理は、圏が完備または余完備であること、すなわちすべての小さな極限または余極限を持つことを証明するとき、また関手が連続または余連続であること、すなわちすべての小さな極限または余極限を保存することを証明するときに役に立つ。証明は少数の場合の確認に帰着する。この節では、さまざまな圏における極限と余極限の構成を述べる。構成が主張どおりの普遍性を持つことの証明は、多くの場合読者に委ねる。その後、集合論の構成を適切な構造を持つ圏の内部に移し替えることで、これらの極限と余極限が何に使えるかを示す。

よく知られた具体的な圏の多くは完備かつ余完備である。Set、Top、Set∗、Top∗、Cat、Group、Ab、Ring、RMod などがそうである。ここでは最初の 5 つだけを扱う。残りの代数的な圏については、圏論的普遍代数の一般的な結果を特殊化すると完備かつ余完備であることが証明できる。これは定理5.6.12 で扱う。

命題3.6.1 — Set は余完備である

最初の例では、仕事の半分はすでに済んでいる。定理3.2.4 により Set は完備である。

命題3.6.1. 圏 Set は余完備である。

証明. 定理3.5.11 により、Set が余積と余等化子を持つことを示せば十分である。余積は非交和で与えられる。平行な関数の対 f, g : A ⇉ B の余等化子は、各 a ∈ A について f(a) ∼ g(a) とする関係が生成する同値関係 ∼ による商集合 B/∼ である。□

命題3.6.2 — Top は完備かつ余完備である

命題3.6.2. 空間の圏 Top は完備かつ余完備であり、台集合関手 U : Top → Set は連続かつ余連続である。

証明. 台集合関手 U : Top → Set は一点空間 ∗ に表現される。したがって定理3.5.2 により、Top に極限があるなら、それは台集合の図式の極限に位相を入れたものでなければならない。これは例3.1.10 で直積の場合に論じたとおりである。

名前が示すとおり、空間の族 Xα の積は、直積集合 ∏α Xα に直積位相を入れたものである。直積位相とは、各射影 πβ : ∏α Xα → Xβ が連続になる最も粗い位相である。連続写像の対 f, g : X ⇉ Y の等化子は、台集合の等化子 E ⊂ X に部分空間位相を入れたものである。部分空間位相は、包含 E ↪ X が連続になる最も粗い位相と言い換えることもできる。

双対に、Top の余極限は台集合の図式の余極限に位相を入れたものだと予想できる。定理4.5.2 により、余極限はこのように構成されなければならない。余積は、非交和 ∐α Xα に、各入射 ιβ : Xβ → ∐α Xα が連続になる最も細かい位相を入れたものである。各空間 Xα の開基の非交和が ∐α Xα の開基になる。連続写像の対 f, g : X ⇉ Y の余等化子は、まず各点 x ∈ X について f(x) ∼ g(x) とする関係が生成する同値関係による集合の商 Y/∼ を作り、次に Y/∼ に商位相を入れたものである。商位相では、Y/∼ の部分集合が開であることと、その Y における逆像が開であることが同値である。これは商写像 q : Y ↠ Y/∼ が連続になる最も細かい位相である。

定理3.5.11 とその双対により、Top はすべての小さな極限と余極限を持つ。以上の明示的な構成から、さらに忘却関手 U : Top → Set がそれらを保存することも分かる。□

例3.6.3 — Top の極限・余極限の一般形と p 進ソレノイド

Top の任意の極限と余極限は、命題3.6.2 の証明で述べた方法で構成できる。すなわち、台集合の図式の極限または余極限を作り、極限錐または余極限錐の脚が連続になるような最も粗い位相（極限の場合）または最も細かい位相（余極限の場合）を入れる。

例として、対象が円周 S1 で、生成する射がどれも「p 乗写像」、すなわち定義域の円周を値域の円周に一様に p 回巻きつける被覆写像であるような図式 ωop → Top を考える。

この図式の逆極限が p 進ソレノイドである。

例3.6.4 — 配置空間

空間 X の n 点の（順序なしの）配置空間とは、X の相異なる n 点の集まりを点とし、二つの配置の点の間に全単射があって対応する各点の対が「近い」とき二つの配置を「近い」とみなす位相を入れた位相空間である。

より正式には、n 点の順序付き配置の空間は直積空間 Xn の部分空間であり、「太い対角線」の補集合

PConfn(X) := {(x1, …, xn) ∈ Xn | i ≠ j ならば xi ≠ xj}

である。対称群 Sn は座標の置換によって Xn に作用し、この作用は部分空間 PConfn(X) ⊂ Xn に制限される。図式 PConfn(X) : BSn → Top の余極限が n 点の配置空間

Confn(X) := colim (BSn → Top)

を定める。演習3.6.i でその台集合を記述する。

命題3.6.5 — スライス圏の完備性と余完備性

Set と Top の完備性と余完備性から Set∗ と Top∗ の完備性と余完備性が従う。これは次の一般的な結果の特別な場合である。17

命題3.6.5. C が完備かつ余完備ならば、任意の c ∈ C について、スライス圏 c/C と C/c も完備かつ余完備である。

証明. 二つの主張は双対なので、c/C について示せば十分である。命題3.4.8 により、C が完備かつ余完備なら、c/C はすべての極限とすべての連結な余極限を持ち、それらは忘却関手 Π : c/C → C が創出する。したがって c/C は完備であり、余完備性を示すには c/C が余積を持つことを示せば残りはない。空な余積は始対象であり、c/C はそれを持つ。恒等射 idc が始対象である。空でない集合で添字づけられた余積は、補題3.5.15 の構成を双対化して、始対象の下の広い押し出しとして構成できる。この証明は余積の構成も教えている。対象の族 c → xα の余積は、c から、これらの射が C において定める図式の広い押し出しへの射である。18□

17 演習3.4.iv で、Set∗ と Top∗ がスライス圏であることを説明している。

18 C が具体圏で、c が台集合関手 U : C → Set を表現し、したがって c/C ≅ ∫U が「基点付き対象」の圏であるときは特に、余積は通常の「⊔」の代わりに記号「∨」で書かれることが多い。例3.1.24 を参照。

Cat の極限の候補

次に、圏の図式の極限を考える。例2.1.5 の (ix) と (x) により、関手 ob, mor : Cat ⇉ Set は順序数圏 𝟙 と 𝟚 に表現される。定理3.5.5(i) により、どちらの関手も極限を保存する。したがって、圏の図式の極限が存在するなら、その対象集合は対象集合の図式の極限でなければならず、その射集合は射集合の図式の極限でなければならない。さらに、定義域・値域・恒等射も保存される。これらの写像はそれぞれ、例2.2.9 により、表現可能関手の間の自然変換として表せるからである。圏 𝟛 を使う同様の議論により、合成も保存される。以上の観察から、任意の圏の積と、任意の平行な関手の対の等化子の候補が得られ、次が証明できる。

例3.6.7 — 要素の圏は引き戻しである

Cat の余極限

小圏の圏は余完備でもある。Cat の余積の構成は簡単である。任意の圏は、その連結成分の余積として一意に表せる。補題3.5.16 により、押し出しを構成すれば十分である。しかし Cat の押し出しは、対応する極限の場合よりかなり複雑になりうる。

注意3.6.9 — CAT は余完備でない

対照的に、局所小圏の圏 CAT は余完備でない。CAT は Cat と同じように構成される余積を持つが、局所小圏のある種の小さな余極限は、固定した対象の対の間に集合に収まらないほど多くの射を生み出す。例として、集合に収まらないほど多くの対象を持ち、各対象が一つの非恒等自己射で生成される自己射を持ち、相異なる対象の間には射がない圏 E を考える。この圏は局所小である。hom 集合は空であるか、自然数のモノイド ℕ と同型だからである。次の押し出しを作る。

この押し出しは E のすべての対象を一つの対象につぶす。この対象は E の各対象ごとに相異なる非恒等自己射を持ち、さらにそれらの自己射の有限個の合成もすべて持つ。E は集合に収まらないほど多くの対象を持つので、P は局所小でない。実際、CAT はこのコスパンの押し出しを含まない。

完備性と余完備性は同値不変である

最後の例の類を考える前に、圏の完備性と余完備性が同値不変であることに注意する。特に、前順序集合が完備かつ余完備であることと、その骨格である poset が完備かつ余完備であることは同値である。

命題3.6.10 — poset の完備性と完備束

命題3.6.10. poset P が圏として完備かつ余完備であることと、P が完備束であること、すなわち任意の部分集合 A ⊂ P が下限（最大下界）と上限（最小上界）を両方持つことは同値である。

証明. 任意の poset または前順序集合において、図式の極限はその対象の下限であり、図式の余極限はその対象の上限である。図式に射があるかどうかは関係ない。前順序集合ではすべての図式が可換だからである。特に、定義域を共有する射の任意の集まりは、その値域で添字づけられた対象を持つ任意の図式の上の錐を定める。□

極限と余極限は何の役に立つか

ここまでの準備のもとで、これらの極限と余極限はいったい何の役に立つのかと問うのは自然である。少数の単純な極限の構成の一つの用途は、一般の圏の内部で同値関係の概念を定義することである。単純な余極限と組み合わせると、一般の射をその像を通して分解することの圏論的な類似物が定義できる。他の重要な応用は §4.7 にあり、そこでは極限と余極限を使って関手を定義する。

例3.6.11 — 核対・同値関係・像分解

有限極限と有限余極限を持つ任意の圏において、任意の射 f : X → Y の、その像を通した分解を構成できる。これは集合の間の関数の像分解の一般化である。射 f : X → Y の核対とは、f の f 自身に沿った引き戻しである。

これらの射はモノ射 (s, t) : R ↣ X × X を定めるので、対象 R はつねに積 X × X の部分対象である。19 核対は X の上の関係を定め、それは X の一般化された要素の上の関係を誘導する。X の一般化された要素の対 x, x′ : Z ⇉ X は、fx = fx′ のときちょうど同一視される。20

19 値域 c を持つモノ射は対象 c の部分対象を定める。定義4.7.8 を参照。

20 Barry Fawcett はこの種の構成が至るところにあることを認めて、「圏論はこう教える。A について学ぶには、A から出る［または A に入る］射の対を調べよ」と書いている [Faw86]。

核対が定める部分対象は、次の圏論的な意味で、つねに同値関係である。

(i) 反射律の射 ρ がある。ρ : X → R は s と t の両方の切断であり、すなわち対角射の分解

を定める。すなわち sρ = idX = tρ である。

(ii) 対称律の射 σ がある。σ : R → R は tσ = s かつ sσ = t を満たす。

(iii) 推移律の射 τ がある。τ の定義域は、t の s に沿った引き戻しである。

この図式は、R を定める引き戻しの上の錐を定める。fs = ft と上の四角形の可換性から f s s̃ = f t s̃ = f s t̃ = f t t̃ だからである。したがって射 τ が誘導される。

τ は sτ = s s̃ かつ tτ = t t̃ を満たす。

有限極限を持つ圏 C における同値関係とは、部分対象 (s, t) : R ↣ X × X に、(i)、(ii)、(iii) の図式に示した仕方で射 s, t と可換になる射 ρ, σ, τ を備えたものである。同値関係の射 s, t : R ⇉ X の余等化子が存在するとき、それは商対象 e : X ↠ X/R を定める。Set では X/R は X の要素の R 同値類の集合である。核対として生じる同値関係については、一意な分解

がある。C が Grothendieck トポス（§E.4）やより一般に正則圏であるような良い状況では、射 m はモノ射であり、この分解が射 f の像分解を定める。モノ射 X/R ↣ Y は像 X/R を Y の部分対象として同定する。

    • (iii) 単位行列は、余積から積への標準的な写像 I : A ∨ B → A × B を定める。その成分は恒等写像か零写像である。注意3.1.27 を参照。スマッシュ積 A ∧ B は、この写像の、零対象への一意な写像に沿った押し出しとして定義される。 集合と部分関数の圏における A ∧ B の公式を与えよ。
  • 3.6.iv — クイバー（quiver）とは、二つの対象 A, V と平行な射の対 s, t : A ⇉ V を持つ圏から Set への関手である。二つのそのような関手の間の自然変換がクイバーの準同型である。したがってクイバーの圏 Quiver は、平行対の圏から Set への共変（または反変）関手の圏と同値である。
    • (i) クイバーの圏 Quiver が完備かつ余完備であることを証明し、その極限と余極限の構成法を説明せよ。
    • (ii) 各頂点に指定された自己辺を持つ反射的クイバーの圏 rQuiver も、同じ理由で完備かつ余完備である。自由な（walking）矢印のそれ自身との積を Quiver と rQuiver の両方で計算せよ。
    • (iii) グラフの圏 Graph が完備でも余完備でもないことを示す明示的な例を見つけよ。自由な（walking）辺のそれ自身との積を計算するか、そのような積が存在しないことを論じよ。
  • 3.6.v — 二重圏（double category）とは Cat における内部圏であり、その基本データは圏と関手の図式 で与えられる。演習3.2.ii を参照。この定義を、次のものを含むより初等的なデータと操作に展開せよ。
    • 対象と「水平射」。C0 の対象と射
    • 「垂直射」と「正方形」。C1 の対象と射
    これらは、圏 C0 と C1 の内部で定義される定義域・値域・恒等射・合成と、図式 (3.6.12) に現れる関手によって定義される定義域・値域・恒等射・合成を備えている。21
  • 3.6.vi — 小圏 J について、Cat における押し出し が、J 型の図式の上の錐と下の錐の形を表す圏 J◁ と J▷ を定めるように、関手の対 i0, i1 : J ⇉ J × 𝟚 を定義せよ。さらに、関手 s と n が定める対象が、それぞれ J◁ の始対象と J▷ の終対象であることを示せ。注意3.1.8 にこれらの圏の非形式的な記述がある。
  • 3.6.vii — k が n を割り切るとき、かつそのときに限り k ≤ n とする順序関係を入れた自然数の poset における極限と余極限を記述せよ。
  • 3.6.viii — 有限集合と単射の圏から位相空間の圏への反変関手 PConf•(X) : Finmonoop → Top で、n 要素の集合を例3.6.4 で構成した空間 PConfn(X) に送るものを定義せよ。この関手が、n 要素の集合を空間 Confn(X) に送る同様の関手を誘導しない理由を説明せよ。
  • 3.6.ix — [Gro58] に従い、ファイバー空間（fiber space）p : E → B を Top の射と定める。ファイバー空間の写像は可換な四角形である。したがってファイバー空間の圏は図式圏 Top𝟚 と同型である。B 上のファイバー空間と、値域成分が恒等射であるような写像からなる、充満でない部分圏 Top/B ⊂ Top𝟚 にも関心がある。次を証明せよ。
    • (i) ファイバー空間の写像 は、(3.1.17) で定義した、点 b ∈ B′ 上のファイバーから、その像 f(b) ∈ B 上のファイバーへの標準的な写像を誘導する。
    • (ii) ファイバー空間の積のファイバーは、ファイバーの積である。
    射影 πB : B × F → B は B 上の自明なファイバー空間を定める。この定義は任意の空間 F について意味を持つ。
    • (iii) 自明なファイバー空間 B × F → B のファイバーが F と同型であることを示せ。
    • (iv) B 上の二つの自明なファイバー空間（ファイバーは異なっていてよい）の間の Top/B における同型射を特徴づけよ。
    • (v) B 上のファイバー空間にその連続切断の集合を対応させる割り当てが関手 ΠB : Top/B → Set を定めることを証明せよ。
    • (vi) 射が引き戻しの四角形であるような、ファイバー空間の充満でない部分圏 Top𝟚pb を考える。ファイバー空間にその連続切断の集合を対応させる割り当てが関手 Π : (Top𝟚pb)op → Set を定めることを証明せよ。
    • (vii) いま導入した「切断」関手たちの作用が、B 上のファイバー空間 p と q の間の写像 g、および f : B′ → B に沿った引き戻しに関して、どのように整合するかを記述せよ。
