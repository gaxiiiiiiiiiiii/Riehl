この節の問い

極限は、どんな形の図式についても、どんな圏の中でも定義できる。しかし定義が書けることと、その普遍性を持つ対象が存在することは別である。この節は、値を集合の圏に取る図式に話を絞り、添字圏が小さいという大きさの制約のもとで、極限がつねに存在することを構成的に証明する。この一般的な構成を特別な形の図式に当てはめると、集合の積、等化子、引き戻し、列の逆極限の具体的な計算が得られる。これらの公式は §3.5 で、より一般の圏における極限と余極限の計算に使う一般的な結果の直感を与える。

定義3.2.1 — 小図式、完備、余完備

定義3.2.1. 図式が小さい（small）とは、その添字圏が小圏であることをいう。圏 C が完備（complete）とは、C に値を取るすべての小図式の極限を持つことであり、余完備（cocomplete）とは、すべての小図式の余極限を持つことである。

完備な圏とは「すべての小さな極限を持つ」圏である。Set が完備であることを示すために、小図式 F : J → Set を取る。極限とは、集合 X を頂点 X の F 上の錐の集合に送る関手の表現

Set(X, lim F) ≅ Cone(X, F)

である。ここで X を固定した一点集合 ∗ に特殊化する。∗ は恒等関手 idSet : Set → Set を表現するので、

(3.2.2) lim F ≅ Set(∗, lim F) ≅ Cone(∗, F).

この節の考え方は、(3.2.2) を極限の明示的な構成的定義として採用することである。構成の各所で、∗ が Set の恒等関手を表現するという事実を使い、要素 x ∈ X と射 x : ∗ → X を同一視する。例2.1.5(i) で見たとおりこの対応は自然なので、関数 f : X → Y を要素に適用した値 f(x) ∈ Y は、合成 fx : ∗ → Y に対応する。

定義3.2.3 — 小さな集合値極限

極限の候補として、頂点が一点集合である錐の集合を取る。この集合から各 Fj への関数は、錐からその j 番目の脚を読み出すものとする。

定義3.2.3（小さな集合値極限）. 任意の小図式 F : J → Set に対し、

lim F := Cone(∗, F)

を頂点 ∗ を持つ F 上の錐の集合として定義する。F 上の極限錐の脚は、J の対象 j で添字づけられた関数 λj : lim F → Fj であって、錐 μ : Δ∗ ⇒ F を、その j 番目の脚 μj : ∗ → Fj を集合 Fj の要素と見たものに送る。

λj(μ) := μj ∈ Fj

この脚の族が F 上の錐を定めることを確かめるには、J の各射 f : j → k について次の三角形が可換なことを見ればよい。

集合 lim F の任意の要素 μ : Δ∗ ⇒ F について、

Ff(λj(μ)) = Ff(μj) = Ff·μj = μk = λk(μ).

中央の等号は、μ : Δ∗ ⇒ F が錐であることから従う。これで錐 λ : Δ lim F ⇒ F が定まった。

定理3.2.4 — Set は完備である

Set がすべての小さな極限を持つことを示すには、定義3.2.3 で構成した錐が普遍性を持つことを示せばよい。

定理3.2.4. 圏 Set は完備である。すなわち、すべての小さな極限を持つ。

定義3.2.3 と定理3.2.4 の大きさの仮定は本質的である。J が小さければ SetJ は局所小で、とくに Cone(∗, F)、すなわち ∗ における定数図式から F への自然変換の集まりは集合になる。§3.7 で、Set が大きな極限のうち一部は持つが、すべては持たないことを示す。

証明. λ : Δ lim F ⇒ F が普遍的な錐であることを示す。任意の頂点 X を持つ錐 ζ : ΔX ⇒ F を取り、ζ が関数 f : X → lim F を通して λ から一意に分解することを示す。

X の各要素 x を関数 x : ∗ → X と見ると、錐 ζ を x で引き戻した錐 ζ·Δx : Δ∗ ⇒ F がある。f(x) ∈ lim F = Cone(∗, F) をこの錐 ζ·Δx と定義する。極限錐 λ の脚の定義から、

λj(f(x)) = λj(ζ·Δx) = (ζ·Δx)j = ζj·x

なので、錐 ζ は f を通して錐 λ から分解する。この計算は同時に、定義 f(x) = ζ·Δx が必然であることも示している。分解 ζ = λ·Δf が成り立つためには、f(x) ∈ lim F は j 成分が ζj·x であるような頂点 ∗ の錐でなければならず、それは ζ·Δx にほかならない。これで分解の一意性が示され、lim F が F の極限を定めることが確かめられた。□

例3.2.5 — 集合の積

定義3.2.3 をさまざまな図式に当てはめて、集合の極限を計算する。

定理3.2.4 により、集合 J の要素 j で添字づけられた集合 Aj の積は、この集合の集まりの上の、頂点 ∗ を持つ錐の集合である。J で添字づけられた離散図式上の頂点 ∗ の錐とは、各集合から要素を一つずつ選んだ J-組にすぎない。したがって Set における圏論的な積は、通常のデカルト積と一致する。

∏j∈J Aj := {(aj ∈ Aj)j∈J}

例3.2.6 — 終対象

Set の終対象は、空図式上の頂点 ∗ を持つ錐の集合である。そのような錐のデータは頂点の選択だけからなるので、錐はただ一つしかない。これは終対象が一点集合であることの再証明になっている。

例3.2.7 — 等化子

平行な関数の対 f, g : X ⇉ Y に対し、その等化子は頂点 ∗ を持つ錐の集合、すなわち fx = gx を満たす写像 x : ∗ → X の集合である。見慣れた記法で書けば、等化子は次の集合 E である。

E := {x ∈ X | f(x) = g(x)}

例3.2.9 — 引き戻し

関数の余スパン B →f A ←g C の引き戻しの要素は、この図式上の頂点 ∗ を持つ錐、すなわち次の可換な四角形である。

この形の錐のデータは、f(b) = g(c) を満たす要素の対 b ∈ B, c ∈ C である。したがって引き戻しは次の集合として定義される。

B ×A C := {(b, c) ∈ B × C | f(b) = g(c)}

例3.2.10 — G-集合の固定点

左 G-集合 X : BG → Set の極限は、頂点 ∗ を持つ錐の集合である。写像 x : ∗ → X が X 上の錐を定めるための必要十分条件は、すべての g ∈ G について次の三角形が可換なこと、すなわち g·x = x がすべての g ∈ G について成り立つことである。

したがって lim X ≅ XG、すなわち X の G-固定点の集合である。

引き戻しは積の等化子である

いま述べたデータが等化子図式 (3.2.12) の域を定める。(λj)j∈J は積 ∏j∈ob J Fj の要素である。条件のほうが余域と平行な写像の対を定める。錐の条件を表す等式は、∏f∈mor J F(cod f) の要素の対を同一視するものであることに注意する。

残るのは (3.2.12) の平行な射 c と d の定義である。∏j∈ob J Fj の要素 (λj)j を、F 上の頂点 ∗ の錐の脚と思う。c はこれを要素 (λcod f)f ∈ ∏f∈mor J F(cod f) に送り、d は要素 (Ff(λdom f))f ∈ ∏f∈mor J F(cod f) に送る。等化子は、この二つの要素が等しくなる ∏j∈ob J Fj の部分集合であり、それは錐の両立条件を満たす写像の組 (λj : ∗ → Fj)j∈J の集合にほかならない。これと、例3.2.5・例3.2.7 で与えた Set の積と等化子の明示的な記述を合わせて、limJ F が c と d の等化子であることの証明が完成する。□

注意3.2.13 — c と d の圏論的な定義

定理3.2.11 の等化子図式の写像は、積 ∏f∈mor J F(cod f) の普遍性を使って圏論的にも定義できる。注意3.1.27 により、c と d を定めるには成分関数、すなわち f ∈ mor J で添字づけられた射影 πf との合成を定めれば必要十分である。c の成分は、上の三角形に示すように、それ自身が射影である。

すなわち、添字 f ∈ mor J における c の成分は、積 ∏j Fj から対象 cod f ∈ J で添字づけられた成分への射影である。

写像 d の f における成分は、下の四角形に示すように、積 ∏j Fj から対象 dom f ∈ J で添字づけられた成分へ射影し、写像 Ff : F(dom f) → F(cod f) と合成して定める。

これらの関数の要素への作用を見れば、圏論的な記述が定理3.2.11 の証明で述べた明示的な記述と一致することが確かめられる。

注意3.2.13 は、定理3.2.11 の主張を Set 以外の圏に一般化するために使う。双対性の原理により、この一般化は余極限を構成する公式も与える。定理3.5.11 を参照。

例3.2.14 — 冪等射の分裂

冪等射（idempotent）とは、ある対象の自己射 e : A → A で e·e = e を満たすものである。Set における冪等射の極限は頂点 ∗ を持つ錐の集合、すなわち ea = a を満たす a ∈ A の集合である。これは冪等射 e の固定点の集合で、しばしば Ae と書かれる。

別のやり方として、定理3.2.11 を演習3.2.iii の簡略化した形で適用すると、極限 Ae は次の等化子として構成される。

e·e = e なので、写像 e は平行対上の錐を定める。等化子の普遍性により、e はただ一つの写像 r を通して s から分解する。

分解 e = sr を、冪等射を分裂させる（split）という。ここで srs = es = s が成り立つので、rs と idAe はどちらも、錐 s : Ae → A の s を通した分解を与える。一意性により rs = idAe なので、Ae は A のレトラクトである。

逆に、任意のレトラクトの図式 B →s A →r B, rs = idB は A 上の冪等射 sr を生じ、この冪等射は B によって分裂する。読者は、次が等化子図式であることを確かめてみるとよい。演習3.4.vi を参照。

節末問題

原文は英語。以下は和訳・言い換え。

  • 3.2.i — 関数 f : X → Y のグラフを、Set の積と等化子を使って圏論的に記述し、f のグラフを通した分解を構成せよ。X × Y の部分対象として、グラフが (1, f) : X ↣ X × Y と同型であることを示せ。Set が余積と余等化子も持つこと（命題3.6.1）を先取りして、余グラフの双対的な記述を与え、それが X ⊔ Y の、ファイバーが空でない Y で添字づけられた分割を定めると見なせることを説明せよ。
  • 3.2.ii — 小圏は、Set の中の特定の図式として定義し直せる。データは、示唆的な名前を付けた集合の対と関数 と、まだ定義していない「合成関数」からなる。このデータを含む引き戻しを使って、合成関数の域となる合成可能な射の対の集合を定義し、圏の公理を Set の可換図式として定式化せよ。Set を引き戻しを持つ圏 E に置き換えると、これは E の内部圏を定める。
  • 3.2.iii — 任意の小図式 F : J → Set について、等化子図式 (3.2.12) を修正して、第二の積を非恒等射だけで添字づけた少し小さな等化子図式 が得られることを示せ。さらに、第二の積の添字集合を「原子的な」射、すなわち非恒等射の合成として分解できない非恒等射だけに絞れることを論ぜよ。
  • 3.2.iv — 局所小な圏 C の任意の射の対 f : a → b, g : c → d について、f から g への可換な四角形の集合 Sq(f, g)（左辺 f、右辺 g、上辺 a → c、下辺 b → d の可換四角形全体）を、Set における引き戻しとして構成せよ。
  • 3.2.v — 演習3.2.iv を一般化して、任意の小圏 J、局所小な圏 C、平行な関手の対 F, G : J ⇉ C について、F から G への自然変換の集合 Hom(F, G) が Set の小さな極限として定義できることを示せ。（ヒント: Hom(F, G) を極限とする図式は、J の射を対象とし、J の各射 f : x → y に対して射 idx → f と idy → f を持つ圏 J§ で添字づけられる。）
  • 3.2.vi — 任意の小圏 J、局所小な圏 C、平行な関手の対 F, G : J ⇉ C について、次が等化子図式であることを示せ。 これは演習3.2.v で構成した図式に定理3.2.11 を適用して得られる等化子図式ではなく、Hom(F, G) を Set の極限として表す第二の公式である。
  • 3.2.vii — 任意の小図式 F : C → Set の極限が、要素の圏からの標準的な射影 Π : ∫F → C の切断を定める関手 C → ∫F の集合と同型であることを証明せよ。この極限の記述を使って、極限錐を定義せよ。
