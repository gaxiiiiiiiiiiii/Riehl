この節の問い

この節では、関手と極限・余極限の関わり方を調べる。手始めに、関手 F : C → D と C の引き戻しの図式を考える。関手は可換性を保つので、C の引き戻しの四角形の像は D の可換な四角形になる。

右の四角形で、Ff と Fg は元の余スパンの D における像であり、Fp と Fq は、その余スパン上の極限錐の像である。一般に、図式上の錐の像は図式の像の上の錐になるが、極限錐の像が極限錐になるとは限らない。ただし D に Ff と Fg の引き戻しが存在すれば、元の図式の極限の像から像の図式の極限への canonical comparison map がある。この射は、Ff と Fg がなす余スパン上の錐の射である。

この観察は一般化できる。J 型で C に値を取る図式 K : J → C の F による像は、J 型で D に値を取る図式 FK : J → D である。同様に、C の図式上の任意の錐 λ : Δc ⇒ K の F による像は、D の対応する図式上の錐 Fλ : ΔFc ⇒ FK である。この錐は、自然変換 λ を F で whiskering して得られる（注意1.7.6）。

F·Δc = ΔFc なので、whiskering した自然変換は、頂点 Fc を持つ FK 上の錐 Fλ を定める。記法が示唆するとおり、錐 Fλ の脚は (Fλj : Fc → FKj)j∈J である。

λ が極限錐でも、Fλ が極限錐とは限らない。図式 FK の極限が存在するとき、錐 Fλ を D の極限錐から分解する canonical comparison map κ : F lim K → lim FK がある。余極限についても双対的なことが言える。演習3.4.i を参照。

定義3.4.1 — 極限の保存・反映・創出

関手が定義域と余域の極限・余極限をどう仲介するかを述べる言葉を導入する。

定義3.4.1. 図式 K : J → C について、関手 F : C → D が
  • K の極限を保存する（preserves）とは、K 上の任意の極限錐の像が、合成した図式 FK 上の極限錐になることをいう
  • K の極限を反映する（reflects）とは、K 上の錐であって、その F による像が図式 FK の極限錐になるものが、すべて K 上の極限錐であることをいう
  • K の極限を創出する（creates）とは、FK が D で極限を持つならば K も極限を持ち、そのうえで K 上の錐が極限錐であることとその F による像が極限錐であることが同値になることをいう12

12 三つの条件のうち三番目がもっとも微妙である。F が K の極限を創出するなら F はそれを反映もするが、F が K の極限を保存することが要求されるのは FK の極限が存在する場合に限られる。

ふつうは、ある種類の図式、例えば特定の形や大きさの図式の極限を保存・反映・創出する関手、という言い方をする。定義3.4.1 を双対化すると、関手がある種類の余極限を保存・反映・創出することの意味が得られる。「保存する」「反映する」「創出する」という言葉はもっと広い意味でも使われる。例えば演習1.5.iv は、充満忠実な関手が同型を保存・反映・創出することを示している。

注意3.4.2 — 上の階と下の階

これらの言葉の感覚をつかむには、次の比喩が役に立つ。関手 F : C → D は「上の階」（圏 C）から「下の階」（圏 D）への写像である。上の階の図式、すなわち関手 K : J → C は、F と合成して得られる下の階の図式の上にある。

この比喩で言えば、F が極限を保存するとは、上の階の極限錐がすべて下の階の極限錐に写ることである。F が極限を反映するとは、下の階の極限錐に写る上の階の錐がすべて上の階の極限錐であることである。F が極限を創出するとは、下の階に極限錐があるというだけで上の階に極限錐が存在し、そのうえで極限が保存も反映もされることである。引き戻しの図式の場合、情報の受け渡しは次のようになる。

定義3.4.1 のどの条件も、あらかじめ極限が存在することを要求していない。要求しているのは、C または D で極限錐が一つ見つかったときに、別のある極限錐が存在することである。問題の極限が存在するとわかっている状況では、関手が極限を保存することを別の形で特徴づけられる。

補題3.4.3 — comparison map による特徴づけ

補題3.4.3. J 型の極限を持つ圏の間の関手 F : C → D を考える。F が J 型の図式 K の極限を保存するのは、canonical comparison map κ : F(limJ K) → limJ FK が同型であるとき、かつそのときに限る。

証明. 演習3.4.i。□

定義3.4.4 — 被覆と層

極限を保存する関手の重要な族は次の節と次の章に現れる。ここでは、極限の保存が重要な仮定になる例を一つ挙げる。

定義3.4.4. X を位相空間とし、X の開集合が包含によってなす poset を 𝒪(X) と書く。I で添字づけられた開集合の族 Ui ⊂ U が U を被覆する（cover）とは、集合 Ui と、二つずつの共通部分 Ui ∩ Uj からの包含とがなす図式の余極限が U であることをいう。前層 F : 𝒪(X)op → Set が層（sheaf）であるとは、F がこれらの余極限を保存する、すなわち Set の極限に写すことをいう。13

定理3.2.11 を適用すると、層であるという仮定は、U の任意の開被覆 {Ui}i∈I について次が等化子図式であることを意味する。

13 U は 𝒪(X) において余積 ∐i∈I Ui とも同型である。しかし層の条件を述べるには、U を二つずつの共通部分からの包含 Uj ↩ Ui ∩ Uj ↪ Ui を含む図式の余極限として記述する必要がある。

以下の補題は、極限や余極限を反映・創出する関手の一般的な例を与える。

補題3.4.5 — 充満忠実関手は極限を反映する

補題3.4.5. 充満忠実な関手は、その余域に存在する任意の極限と余極限を反映する。

証明. 図式 K : J → C 上の錐 λ : Δc ⇒ K が極限錐であるとは、K 上の他の任意の錐 μ : Δx ⇒ K が λ をただ一通りに通して分解することである。充満忠実な関手 F : C → D を取り、錐 Fλ : ΔFc ⇒ FK がこの性質を持つと仮定する。

K 上の錐 μ : Δx ⇒ K を取る。その像 Fμ : ΔFx ⇒ FK は FK 上の錐なので、ある射 h : Fx → Fc をただ一通りに通して Fλ から分解する。F は充満なので h = Fg を満たす射 g : x → c がある。各 j について F(λj·g) = Fλj·h = Fμj であり、F は忠実なので λj·g = μj である。したがって μ は g を通して λ から分解する。μ を分解する射 g′ がもう一つあれば、Fg′ も Fμ を Fλ から分解するので、Fλ の普遍性の一意性から Fg′ = Fg となり、忠実性から g′ = g である。これで λ が極限錐であることが示された。余極限についても同様である。□

補題3.4.6 — 圏同値は極限を保存・反映・創出する

補題3.4.6. 任意の圏同値は、その定義域または余域に存在する任意の極限と余極限を保存し、反映し、創出する。

証明. 圏同値 F : C → D は充満忠実なので、補題3.4.5 により極限と余極限を反映する。残る二つの主張には、次の観察を使う。C の任意の図式 K と、その像の上の任意の錐 μ : Δd ⇒ FK について、μ は F の像にある錐と同型である。

実際、F は本質的全射なので、ある対象 x ∈ C と同型 f : Fx ≅ d がある。μ に同型 f を前合成すると、頂点が F の像にある同型な錐 μf : ΔFx ⇒ FK が得られる。F は充満忠実なので、この錐の脚 (μj·f : Fx → FKj)j はそれぞれ x → Kj の射にただ一通りに持ち上がり、Fν = μf を満たす C の錐 ν : Δx ⇒ K を定める。持ち上げた脚の族が錐の条件を満たすことも、F の忠実性から従う。

保存. C の極限錐 λ : Δc ⇒ K の像を考える。像の上の任意の錐 μ : Δd ⇒ FK について、上で構成した同型な錐 μf のただ一つの持ち上げ ν : Δx ⇒ K を取る。λ は極限錐なので、ν はただ一つの射 g : x → c を通して λ から分解する。F は充満忠実なので、Fg は錐 Fν = μf の Fλ を通したただ一つの分解を与える。これを f−1 と合成した Fg·f−1 が、元の錐 μ の Fλ を通したただ一つの分解である。よって圏同値は極限を保存する。

創出. C の図式 K と、D における極限錐 μ : Δd ⇒ FK を取る。上で構成した同型な錐 μf : ΔFx ⇒ FK も極限錐であり、その持ち上げ ν : Δx ⇒ K は、Fν = μf が極限錐で、圏同値は極限を反映するので、K の極限錐である。したがって K は極限を持つ。K 上の錐が極限錐であることとその像が極限錐であることの同値は、すでに示した保存と反映から従う。よって圏同値は極限を創出する。余極限についても同様である。□

定義3.4.7 — 厳密な創出

極限や余極限の創出には「邪悪な」（evil）厳密化がある。この厳密化は、圏同値ではふつう成り立たないが、他の圏論的な場面には現れる。

定義3.4.7. 関手 F : C → D がある種類の図式について極限を厳密に創出する（strictly creates）とは、その種類の任意の図式 K : J → C と FK : J → D 上の任意の極限錐について、
  • その錐の K 上の錐への持ち上げがただ一つ存在し、
  • しかもその持ち上げが C の極限錐である
ことをいう。

連結な圏

圏 J が連結（connected）であるとは、J が空でなく、J の台となる quiver において任意の二つの対象が射の有限のジグザグで結ばれることをいう。図式が連結であるとは、その添字圏が連結であることをいう。

命題3.4.8 — スライス圏の忘却関手

命題3.4.8. 任意の対象 c ∈ C について、忘却関手 Π : c/C → C は極限と連結な余極限を厳密に創出する。したがって圏 c/C は、C が持つ任意の極限と連結な余極限を持つ。

この結果の一般化が演習3.4.ii にある。

証明. c/C の J 型の図式を与えることは、関手 K : J → C と、頂点 c を持つ錐 κ : Δc ⇒ K の組を与えることと同じである。図式 (K, κ) : J → c/C と忘却関手 Π : c/C → C の合成は K である。

極限. K が C で極限錐を持つなら、その錐が (K, κ) 上の c/C の錐にただ一通りに持ち上がり、しかも持ち上げが極限錐であることを示す。C の極限錐 λ : Δℓ ⇒ K を取る。錐 κ : Δc ⇒ K は、ただ一つの射 t : c → ℓ を通して極限錐 λ から分解する。J が平行対の圏

の場合、この手順は次のようになる。

このデータは、λ を持ち上げる (K, κ) 上の c/C の錐を与え、その頂点は対象 t : c → ℓ である。持ち上げはこれしかない。c/C の錐の脚は c/C の射なので、頂点 s : c → ℓ は λj·s = κj をすべての j について満たさなければならず、そのような s は λ の普遍性から t に限られる。

この錐が c/C の極限錐であることは直接確かめられる。c/C における (K, κ) 上の錐は、頂点 s : c → x と脚 μj : x → Kj であって μj·s = κj を満たすものからなる。C で μ は λ からただ一つの射 u : x → ℓ を通して分解する。u·s と t はどちらも κ を λ から分解するので u·s = t となり、u は c/C の射 (x, s) → (ℓ, t) である。構成から、Π : c/C → C はこの極限を保存する。

連結な余極限. J が連結で、K が C で余極限錐 μ : K ⇒ Δp を持つとする。このデータが (K, κ) の下の c/C の錐にただ一通りに持ち上がり、しかもそれが余極限錐であることを示す。まず、余極限の対象 p を忘却関手 Π : c/C → C に沿って持ち上げる。対象 j ∈ J を一つ選び、持ち上げた対象を合成

と定める。これは錐 κ : Δc ⇒ K の脚と余極限錐 μ : K ⇒ Δp の脚の合成である。J は連結なので、合成 μj·κj : c → p は j の選び方によらない。実際、射 f : j → k について μk·κk = μk·Kf·κj = μj·κj であり、任意の二つの対象はこのような射のジグザグで結ばれる。持ち上げた余錐の脚 μj は c/C の射でなければならないので、頂点はこの合成に限られる。

次に、(K, κ) : J → c/C の下の錐、すなわち頂点 s : c → x と脚 νj : Kj → x であって νj·κj = s を満たすものが与えられたとする。台となる C の錐は、ただ一つの射 u : p → x を通して p から分解する。このとき u·μj·κj = νj·κj = s なので、この分解は c/C の分解にただ一通りに持ち上がる。対象 c は図式 K の「反対側」にあり、錐の分解に必要な可換性の条件には関与しないからである。以上で、Π : c/C → C が連結な余極限を厳密に創出することが示された。□

命題3.4.9 — 関手圏の極限は各点で計算される

最後の結果は、関手圏が極限と余極限を値の圏から「各点ごとに」受け継ぐことを示す。関手圏に値を取る図式 F : J → CA について、関手 lim F : A → C は、対象 a ∈ A で limj∈J F(j, a) を取るものとして、この極限が存在するときに定義できる。これは関数についてのなじみ深い操作に似ている。例えば、アーベル群の準同型の有限個の族 fj : A → C の和は、a ∈ A で C における和 ∑j fj(a) を取る準同型である。

この結果を正確に述べるために、小さな添字圏 A の対象を、極大な離散部分圏 ob A ↪ A と見る。

命題3.4.9. A が小さいとき、忘却関手 ev : CA → Cob A はすべての極限と余極限を厳密に創出する。したがって
  1. CA は、C が持つ任意の極限と余極限を持ち、
  2. これらの極限と余極限は「各点で定義される」。すなわち、各 a ∈ A について評価関手 eva : CA → C は、C に存在するすべての極限と余極限を保存する。

証明. ev : CA → Cob A がすべての極限と余極限を厳密に創出することを示す。図式 F : J → CA を取り、各 a ∈ A について図式 F(−, a) : J → C が極限 limj∈J F(j, a) を持つと仮定する。同型 Cob A ≅ ∏ob A C と演習3.4.v により、この仮定は図式 ev·F : J → Cob A が極限を持つことと同値である。

極限の対象. ob A で添字づけられた対象の族 limj∈J F(j, a) は、関手 A → C に延びる。この関手は、F の変数を入れ替え（演習1.7.vi）、命題3.3.1 の極限関手と合成して得られる。14

これで、ob A で添字づけられた C の極限の対象の族を持ち上げる対象 limJ F ∈ CA が構成された。

14 命題3.3.1 の主張で述べたとおり、limJ F を定義するには、各 a ∈ A について J 型の図式 F(−, a) が極限を持つことだけを仮定すればよい。

極限錐. 次に、ob A で添字づけられた C の極限錐の族を持ち上げる極限錐 λ : Δ(limJ F) ⇒ F を構成する。この錐の脚は CA の射、すなわち自然変換 λj : limJ F ⇒ Fj であり、各 a ∈ A での成分はすでに決まっている。a ∈ A を固定して j ∈ J を動かすと、射 λj,a : limj∈J F(j, a) → F(j, a) は a で添字づけられた C の J 型の極限錐の脚である。A の射 f : a → a′ は J 型の図式の間の自然変換 F(−, a) ⇒ F(−, a′) を与え、命題3.3.1 と同じようにこれを使って limJ F の f への作用を定める。この定め方により、錐の脚 λj は A について自然になる。

普遍性. 最後に、錐 λ が極限錐の普遍性を持つことを示す。対象 X ∈ CA と、頂点 X を持つ F 上の J 型の錐 μ : ΔX ⇒ F が与えられたとき、CA の射 α : X ⇒ lim F を通したただ一つの分解を構成したい。評価関手 ev : CA → Cob A と合成した後ではそのような分解があり、それが各 a ∈ A での自然変換 α の成分を定める。射 f : a → a′ における自然性は、C における極限 limj∈J F(j, a′) の普遍性の一意性から従う。残りの要請、すなわち α が μ の λ を通した分解であることと、その性質を持つ α がただ一つであることは、どちらも Cob A で確かめられる。自然変換が等しいのは、その成分がすべて等しいとき、かつそのときに限るからである。以上で証明が完了する。□

C がある極限や余極限を持たなければ、Cob A もそれを持たず、逆も成り立つ（演習3.4.v）。定義3.4.1 で注意したとおり、関手が極限や余極限を厳密に創出するという条件は、余域の圏にそれらが存在しなければ空虚に成り立つ。したがって C がある極限や余極限を持たない場合、命題3.4.9 は、対応する極限や余極限が CA に存在するかどうかについても、それがどう構成されるかについても何も述べない。

例3.4.10 — 各点的でない極限

図式の圏における各点的でない極限と余極限の例として、次の対象と射を持つ poset を考える。

この poset では n ≤ w, n ≤ e, s ≤ w, s ≤ e であり、比較不能な対象の二項積（交わり）や二項余積（結び）は存在しない。例えば w と e の下界は n と s で、そのうち最大のものはない。

この poset の射の圏、すなわち射 x ≤ y を対象とし、x ≤ x′ かつ y ≤ y′ のときに射 (x ≤ y) → (x′ ≤ y′) がただ一つある圏も、二項積と二項余積のうちいくつかは持つがすべては持たず、持つもののうちいくつかは各点的でない。

  • 射 n → w と n → e の積は、n 上の恒等射である。対象 (x ≤ y) からこの二つへの射があるのは、x ≤ n かつ y ≤ w, y ≤ e のときであり、x ≤ y と合わせると x = y = n に限られる。この積は、n を含む w と e の交わりと考えられる。終域の成分 n は、存在しない積 w ∧ e の代わりに現れている
  • 射 n → e と s → e の余積は、e 上の恒等射である。これは e の中での n と s の結びと考えられる。始域の成分 e は、存在しない結び n ∨ s の代わりに現れている

  • 3.4.ii — 命題3.4.8 を一般化して、任意の関手 F : C → Set について、射影関手 Π : ∫F → C が次を満たすことを示せ。
    1. C が持ち F が保存するすべての極限を厳密に創出する。
    2. C が持つすべての連結な余極限を厳密に創出する。
  • 3.4.iii — 次の二つがともに成り立てば、F : C → D がある種類の図式について極限を創出することを証明せよ。
    1. C はそれらの極限を持ち、F はそれを保存する。
    2. F : C → D は同型を反映する。

  • 3.4.v — 圏の積 ∏i∈I Ci を考える。
    1. 各射影関手 πk : ∏i∈I Ci → Ck が極限を保存することを示せ。
    2. 射影関手 πk : ∏i∈I Ci → Ck が共同で極限を創出する（jointly create limits）ことを示せ。すなわち、任意の図式 F : J → ∏i∈I Ci について、各成分の図式 πkF : J → Ck が極限を持つならば、それらの極限が F の極限の成分を定める。
