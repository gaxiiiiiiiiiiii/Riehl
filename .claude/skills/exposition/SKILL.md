書き上げたら2つ確認し、それからユーザーに読んでもらう。演習ファイルはそのあと。

- **収録漏れ** — 本文の節にある項目（定義・主張・例・Remark・図・数学的な内容のある脚注・節末問題）を列挙し、その一つ一つが HTML に現れることを確認する
- **形式** — 外部リソースへの参照が無いこと、ライト/ダークの両方で読めること、タグが閉じていること

## 規約

解説資料は、その節の内容を日本語で過不足なく解説する独立した文書です。演習ファイルとは無関係に、それだけ読んで節の内容がわかるものにしてください。

収録範囲は節にあるもの全部です。本の順序に沿って、節の動機・定義・主張（番号の有無を問わない）とその証明・例・数学的な内容のある脚注・節末問題を並べます。演習ファイルに載せるかどうかで取捨しないでください（演習ファイルが例や Remark を載せないのは、あちらの都合です）。節が章の冒頭にあるときは、章の導入も含めます。

書き方:

- **翻訳ではなく、数学の解説を書く。** 節を理解したうえで、定義・主張・証明の中身を自分で説明し直します。原文の文章を訳したり、訳したものの語句を置き換えたりするのではありません（本の日本語版を作るのが目的ではなく、本を読むための個人的な学習ノートです）
- 証明も、本文にあるものは省かずに解説する。ただし本文が図で示す計算は、図を再現したうえで「どの要素をどう追うか」を文章で補う
- 冒頭に記号表を置く。記号・型・意味を並べる（Lean 側の対応物は書かない）
- 英文を引用するときは和訳を主にする
- 節末問題は和訳・言い換えを載せる。解答・方針・ヒントは書かない
- 番号（定義2.1.4 など）は本と揃える

書かないこと:

- Lean・Mathlib への言及、演習ファイルの構成や読む順序の指示。この文書は Lean と無関係です
- 節末問題の解答、証明のヒント、難易度の示唆（どの主張が自明で、どれが実質的かなど）

形式:

- 自己完結の単一 HTML（外部リソース・CDN 不使用）、ライト/ダーク両対応
- 可換図式は inline SVG で描く。ASCII アートは使わない。矢尻は `marker` で描き、文字色は `currentColor` を継承させてテーマに追従させる。`max-width: 100%` で横スクロールを出さない
- 数式は Unicode 記法で書き、数式レンダリングライブラリは使わない
